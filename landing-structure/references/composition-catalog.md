# 构图词汇表

> 本文件是结构描述工具，用于在 Page Flow 中标注每个模块的信息骨架。
> 不涉及视觉参数——颜色、字体、间距、动效由设计环节决定。

---

## Hero 构图

| 构图 | 结构 | 适用场景 |
|---|---|---|
| Split（分栏） | 文案区与视觉主体左右各占约 50% | 有明确产品界面可展示 |
| 居中堆叠 | 标题居中 → CTA → 视觉主体在下方占满宽度 | 需要宽幅展示的内容（Dashboard、视频） |
| 全幅沉浸 | 大幅媒体占满视口，文案叠加在上层 | 视觉冲击力强的品牌表达 |
| Editorial | 超大标题占据主视觉位置，辅助元素作配角 | 文案本身就是最大卖点（概念型产品） |
| Product Showcase | 产品居中放大，文案在上方或环绕 | 需要突出产品形态 |
| 交互先行 | 可操作的交互元素（搜索框、代码编辑器）作为主体 | "先试后买"的开发者工具、AI 产品 |

## Section 构图

| 构图 | 结构 | 信息密度 |
|---|---|---|
| Bento Grid | 不等尺寸卡片组成网格，面积编码优先级 | 高 |
| Feature Zigzag | 左图右文 → 右图左文交替，每行一个功能 | 中 |
| Icon Grid | 等宽网格（3×2 或 4×2），每格图标 + 标题 + 一句描述 | 中 |
| Sticky Scroll | 左侧文案列表，右侧视觉区随选中项切换 | 高 |
| Stats Section | 3-4 个大号数字横排，每个下方简短标注 | 低（段间过渡） |
| Timeline | 垂直或水平连线，3-5 个步骤节点 | 中 |
| Before / After | 左右或上下对比，分割线区分 | 中 |
| Statement | 居中大段文案（1-2 句），搭配单一辅助视觉 | 低（呼吸区） |
| Comparison Table | 多列对比表格，横轴为对比对象，纵轴为对比维度 | 高 |
| Carousel | 多张同类卡片水平排列，可左右滑动 | 中 |
| Logo Wall | Logo 横排 + 一句概括文案（"被 N 家公司信赖"） | 低（即时信誉） |

## 构图选择参考

> 以下是行业常见搭配，不是唯一解。选择构图时优先考虑"这个模块要传达的信息类型最适合什么结构"，而非对照表格。

| 信息类型 | 常见构图 |
|---|---|
| 产品界面展示 | Split、居中堆叠 |
| 功能列举（3-6 项） | Icon Grid、Bento Grid |
| 功能深度展示 | Zigzag、Sticky Scroll |
| 流程说明 | Timeline |
| 效果对比 | Before / After |
| 数据指标 | Stats Section |
| 品牌宣言 / 过渡 | Statement |
| 可试用的产品 | 交互先行 |
| 竞品 / 方案对比 | Comparison Table |
| 多项同类内容展示 | Carousel |
| 即时信誉 / 信任过渡 | Logo Wall |
