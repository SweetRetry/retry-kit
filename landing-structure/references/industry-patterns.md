# 行业落地页模式

> 不同行业的落地页有不同的模块偏好和 CTA 风格。
> 以下是调研验证的行业参考组合，不是模板——实际使用时根据产品上下文调整。
> 其中涉及时效性经验时，优先提炼方向性规则；没有可验证来源时，不要复述具体百分比。

---

## SaaS

```
Hero（产品截图 + 利益标题）
→ Social Proof（Logo 墙 + 数字）
→ Features（Bento Grid / Zigzag）
→ How It Works（3 步 Timeline）
→ Testimonials（带量化结果）
→ Pricing（对比表）
→ FAQ
→ 尾部 CTA
```

- CTA 风格："免费试用 — 无需信用卡"/"预约 Demo"
- 总模块数：通常保持中等长度，不宜过长
- 关键规则：Features 必须呼应 Pain/Solution 中提出的问题
- Pricing 放在社会证明之后——先证明价值再谈价格

## 开发者工具

```
Hero（交互先行：代码示例 / 试用入口）
→ 能力范围（支持的语言/格式/平台）
→ How It Works（代码片段 + 步骤）
→ Interactive Demo / Playground
→ Quick Start（复制粘贴即可运行）
→ Social Proof（GitHub Stars / 生产使用量）
→ FAQ
→ 尾部 CTA
```

- CTA 风格："获取 API Key"/"Launch Playground"/"Start Building"（用具体动词，不用"Get Started"）
- 语言规则：用技术语言，不用营销话术。开发者拒绝抽象描述
- 关键规则：有 Playground/Demo 往往比纯说明文案更容易推动试用
- Social Proof 用 GitHub Stars、生产使用量等可验证指标，不用空洞 Logo 墙

## DTC / 电商

```
Hero（Product Showcase：产品即主角）
→ 成效数据（Stats Section）
→ 成分/材质介绍（Bento Grid）
→ Before / After（真实对比照）
→ 专家背书（Statement）
→ CTA + 风险消除（退款保证 / 免邮）
```

- CTA 风格："立即购买 — 28 天无效全额退款"/"免费领取试用装"
- 关键规则：稀缺性和紧迫性信号对 DTC 有效（限时优惠可显著提升转化），但必须基于真实条件
- 移动端关键：电商大量转化发生在移动端，按钮必须足够大且易点击
- 信任信号：Before/After 对比照 + 专家背书是 DTC 的核心信任组合

---

## 移动应用

```
Hero（应用截图 + 应用商店徽章）
→ 核心功能（Icon Grid，聚焦用户结果）
→ 应用内截图 / 视频 Demo（Carousel）
→ Social Proof（应用商店评分 + 真实下载反馈）
→ 下载 CTA（同时展示 iOS + Android 徽章）
→ FAQ
```

- CTA 风格：直接链接应用商店
- 关键规则：干扰元素越多，下载决策越容易被打断
- 视频：优先使用短时长、能快速传达使用方式的应用内操作视频
- 应用商店评分是移动应用最核心的信任信号，必须突出展示
