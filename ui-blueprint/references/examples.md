## Example 4: State Variants

**User request**: "设计一个用户邀请功能，要覆盖所有状态"

### State 1: Default (empty form)

```
┌─────────────────────────────────┐
│ 邀请团队成员                   ✕ │
├─────────────────────────────────┤
│                                 │
│  ┌───────────────────────────┐  │
│  │ colleague@company.com     │  │
│  └───────────────────────────┘  │
│  权限：选择权限 ▾                │
│                                 │
│  输入邮箱后按回车添加            │
│                                 │
├─────────────────────────────────┤
│              [取消]  [发送邀请]  │
│                      (disabled)  │
└─────────────────────────────────┘
```

### State 2: Input in progress

```
┌─────────────────────────────────┐
│ 邀请团队成员                   ✕ │
├─────────────────────────────────┤
│                                 │
│  [alice@company.com ✕]          │
│  ┌───────────────────────────┐  │
│  │ bob@comp...               │  │
│  └───────────────────────────┘  │
│  权限：编辑者 ▾                  │
│                                 │
├─────────────────────────────────┤
│              [取消]  [发送邀请(1)]│
└─────────────────────────────────┘
```

### State 3: Submitting

```
┌─────────────────────────────────┐
│ 邀请团队成员                   ✕ │
├─────────────────────────────────┤
│                                 │
│  [alice@company.com]            │
│  [bob@company.com]              │
│  权限：编辑者                    │
│  (表单锁定)                     │
│                                 │
├─────────────────────────────────┤
│              [取消]  [⟳ 发送中…] │
└─────────────────────────────────┘
```

### State 4: Success

```
┌─────────────────────────────────┐
│ 邀请团队成员                   ✕ │
├─────────────────────────────────┤
│                                 │
│            ✅                    │
│        邀请已发送                │
│   已向 3 位成员发送邀请邮件       │
│                                 │
├─────────────────────────────────┤
│    [完成]  继续邀请更多成员       │
└─────────────────────────────────┘
```

### State 5: Partial failure

```
┌─────────────────────────────────┐
│ 邀请团队成员                   ✕ │
├─────────────────────────────────┤
│ ⚠ 2 封发送成功，1 封失败         │
│                                 │
│  invalid-email    邮箱格式无效 ✕  │
│                                 │
├─────────────────────────────────┤
│        [忽略并关闭]  [修正并重试] │
└─────────────────────────────────┘
```
