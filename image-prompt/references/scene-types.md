# 场景类型速查

每个场景只列 Claude 不一定知道的**避坑要点**和**推荐技术参数**。关键词不必查表——根据场景自然选择即可。

---

## 人像 Portrait
- **避坑**：多人合影极易出错，尽量 1-2 人；手部保持简单（托腮、握物）；不要过度描述五官细节
- **推荐**：85mm f/1.4 / 135mm f/2 / 2:3 竖版

## 产品摄影 Product
- **避坑**：Logo 文字用双引号但仍有失败率；写材质光学特性（"frosted glass catching light"）而非泛写；避免多产品复杂排列
- **推荐**：100mm macro / f/8-f/11 / 1:1 或 4:5

## 风景 Landscape
- **避坑**：写"具体地貌+具体光照时刻"比 "beautiful landscape" 好 10 倍；前中后景分层是关键；避免同时要求多种天气效果
- **推荐**：16-35mm / f/11 / 16:9 或 21:9

## 美食 Food
- **避坑**：蒸汽写 "wispy steam rising" 而非 "hot"；食物写质感而非温度（"crispy golden crust"）；45° 和俯拍最安全
- **推荐**：50mm / 90mm macro / f/2.8-f/4 / 4:5 竖版

## 建筑 Architecture
- **避坑**：明确建筑风格名称比描述形状准确；室内写清视角（正面/角落/门口看入）；对称构图最安全
- **推荐**：24mm tilt-shift / f/8 / 16:9 或 3:2

## 概念艺术 Concept Art
- **避坑**：写设计意图比堆细节好（"battle-worn paladin armor with dented shoulder plates"）；角色用 T-pose 或 3/4 视角；环境加 scale reference
- **推荐**：wide angle / 16:9 宽幅

## 时尚 Fashion
- **推荐**：85mm / 50mm / f/2-f/4 / 2:3 竖版 / high contrast

## 静物 Still Life
- **推荐**：90mm / f/5.6 / 1:1 或 4:5 / 伦勃朗侧光或单一柔光源

## 微距 Macro
- **推荐**：100mm macro / f/2.8 / ring flash / 1:1

## 航拍 Aerial
- **推荐**：24mm / f/5.6 / top-down 或倾斜 45° / 1:1 或 16:9

## 街拍 Street
- **推荐**：35mm / 50mm / f/2 / high ISO grain / 3:2

## 动物 Wildlife
- **避坑**：写动作瞬间（捕食、飞翔）和眼神质量，而非百科描述
- **推荐**：400mm telephoto / f/5.6 / fast shutter / 3:2

## UI 素材 UI Assets
- **推荐**：正交/等距投影 / 透明背景 / 1:1 / 高饱和度

## 抽象 Abstract
- **推荐**：无特定镜头参数 / 1:1 或宽幅 / 光本身可作主体
