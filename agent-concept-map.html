Agent 概念关系图

实线 = 调用 / 数据流；虚线 = 观测 / 评估（旁路）。
eval 的输入：observer 数据 + thread / artifact 内容 + golden / 人工反馈。 
flowchart TD
    subgraph RUN["运行层"]
        AGENT["AGENT
指令 · 模型 · 工具 · 权限"]
        SESSION["SESSION
运行期边界 · 凭证/快照"]
        RUNTIME["RUNTIME
agent loop · 工具执行"]
        MODEL["MODEL
推理引擎 · 无状态"]
        TOOL["TOOL
工具调用 · 能力边界"]
    end
    subgraph CONTENT["内容层"]
        MEMORY["MEMORY
长期记忆 · 检索源 · workspace"]
        THREAD["THREAD
turn → step → tool call
持久 · 可寻址 · 可回放"]
        CW["CONTEXT WINDOW
瞬时视图 · token 预算"]
        ARTIFACT["ARTIFACT
产物 · 附件 · 持久化"]
    end
    subgraph SIDE["观测与评估（旁路）"]
        OBSERVER["OBSERVER
trace · metrics · logs"]
        EVAL["EVAL
评分 · 反馈改进"]
        GOLDEN["GOLDEN
基准 · dataset · 人工反馈"]
    end

    AGENT -->|实例化| SESSION
    AGENT -->|绑定模型| MODEL
    AGENT -->|绑定工具集| TOOL
    SESSION -->|绑定约束| RUNTIME
    RUNTIME -->|调用推理| MODEL
    RUNTIME -->|调用| TOOL
    RUNTIME -->|写入 step/记录| THREAD
    TOOL -->|结果写回| THREAD
    THREAD -->|截取组装| CW
    MEMORY -->|检索注入| CW
    CW -->|输入| MODEL
    MODEL -->|写回新 turn| THREAD
    RUNTIME -->|生成产物| ARTIFACT
    TOOL -->|产出/返回| ARTIFACT
    THREAD -->|挂载/引用| ARTIFACT

    OBSERVER -.->|观测| SESSION
    OBSERVER -.->|观测| RUNTIME
    OBSERVER -.->|观测| THREAD
    OBSERVER -.->|提供数据| EVAL
    EVAL -.->|评估内容/过程| THREAD
    EVAL -.->|结果评估| ARTIFACT
    EVAL -.->|评估反馈| RUNTIME
    EVAL -.->|反馈改进| AGENT
    GOLDEN -.->|提供标准| EVAL
