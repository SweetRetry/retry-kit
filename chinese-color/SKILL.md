# 中国传统色

526 种中国传统色数据库，支持色彩查询、配色方案推荐与 shadcn/ui token 映射。

## 数据源

**`references/index.json`** — 单文件全量索引（526 条）：

```json
{"乳白": {"group": "yellow", "oklch": "oklch(0.96 0.032 97.3)"}, ...}
```

- key = 色名，`group` = 色系，`oklch` = CSS OKLCH 字符串（L 明度 0–1、C 色度、H 色相 0–360）
- **色系**（11 个）：`orange`(102) · `red`(101) · `pink`(65) · `green`(48) · `yellow`(43) · `blue`(43) · `gray`(42) · `brown`(41) · `cyan`(34) · `black`(4) · `purple`(3)

## 查询工作流

所有查询只读 `references/index.json`。

- **按色名查询**：模糊匹配 key（色名），返回匹配项的 group + oklch。
- **按色系查询**：筛选 `group` 字段，按 oklch 中 L 值从高到低排序。
- **按近似色查询**：用户给出颜色值（hex/rgb/oklch），转换为 OKLCH 后，计算与全部记录的欧氏距离，返回最接近的 5 个。

## 配色方案推荐

根据用户设计场景，遵循主色/辅色/强调色/中性色/背景色五角色模型，从数据库中挑选色彩组合。

### 输出格式

```
## 配色方案：{方案名称}

**适用场景**：{场景描述}

| 角色 | 色名 | oklch | 用途说明 |
|------|------|-------|----------|
| 主色 | 朱砂 | oklch(0.57 0.216 26.1) | 品牌主色、CTA 按钮 |
| 辅色 | 月白 | oklch(0.93 0.024 209.5) | 背景、大面积填充 |
| 强调色 | 鸦青 | oklch(0.40 0.009 228.7) | 标题文字 |
| 中性色 | 银灰 | oklch(0.62 0.019 55.6) | 正文、次要信息 |
```

### 场景预设

- **国风/古典**：红系 + 棕系 + 黄系暖调，如朱砂、赭石、鹅黄
- **文人雅致**：青系 + 灰系 + 绿系冷调，如霁青、银灰、竹篁绿
- **现代中式**：低饱和暖色 + 高对比强调，如檀色 + 月白 + 鸦青
- **自然清新**：绿系 + 青系 + 浅黄背景，如蔻梢绿、秋波蓝、乳白
- **热烈喜庆**：红系 + 金黄强调 + 深色文字，如银朱、佛手黄、玄青

## shadcn/ui Design Token 映射

用户要求将配色方案落地为 shadcn/ui 的 `globals.css` 时，按以下规则映射。

### 映射规则

| Token | 选色策略 |
|-------|---------|
| `--background` | 配色方案中的**背景色**（极浅色，L ≥ 0.90） |
| `--foreground` | 从数据库选**深色**（L ≤ 0.35），保证与 background 对比度 ≥ 7:1 |
| `--card` / `--popover` | **辅色**中的浅色，比 background 略有色彩倾向 |
| `--primary` | 配色方案中的**主色** |
| `--primary-foreground` | 与 primary 同色系的极深色（L ≤ 0.25） |
| `--secondary` | 配色方案中的**中性色**（低饱和） |
| `--accent` | 配色方案中的**强调色**（通常为对比色系） |
| `--accent-foreground` | 与 accent 高对比的浅色 |
| `--muted` / `--border` / `--input` | 中间明度色（L 0.55–0.75），用于分隔和次要 UI |
| `--ring` | 同 primary，用于 focus 状态 |
| `--destructive` | 从红系选取；若主色已为红系，选更深或更饱和的红系色以区分 |
| `--chart-1` ~ `--chart-5` | 从方案中按角色依次取色：主色、辅色、强调色、中性色、背景色 |
| `--sidebar-*` | 背景取方案辅色，primary 取比主色更深一级的同色系色 |

### Dark Mode 规则

- **保持品牌色相**：`--primary` 保持相近 H 值，从同色系中选 L 值更高的色
- **背景**：从同色系选极深色（L ≤ 0.25），保留色彩倾向而非纯黑
- **暖色强调**：若 light 模式 accent 为高饱和暖色（H < 60），dark 模式可平移到同色系较低饱和的邻近色，降低暗底刺激感
- **所有颜色必须从数据库中选取**，不可手动调参

### 输出格式

输出完整 `globals.css`，结构遵循 shadcn/ui 标准，每个 token 值后用注释标注中国传统色名：

```css
@import "tailwindcss";

@custom-variant dark (&:is(.dark *));

:root {
  --background: oklch(...);  /* 色名 */
  /* ... 全部 token */
}

.dark {
  --background: oklch(...);  /* 色名 */
  /* ... 全部 token */
}
```

## 注意事项

- 色彩数据来自 `references/index.json`，不要编造不存在的色名
- 推荐配色时，所有颜色必须从数据库中选取，oklch 值必须与 references 中完全一致，不可修改精度
- 如用户需要的颜色不在库中，先推荐最接近的传统色，再说明差异
- 推荐配色时验证 WCAG AA 对比度（正文 ≥ 4.5:1，标题 ≥ 3:1）
