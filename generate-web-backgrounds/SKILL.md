# Web Background Prompt

创作视觉环境素材，不设计使用它的网页。最终只交付一份自包含的生图 prompt；画幅、分辨率、
model 和生成参数交给 generation 入口。

Background 依靠跨越画框的连续场、节奏或材质关系成立，而不是依赖必须完整看见的主角或戏剧高潮。
它可以进入 hero、section、封面或沉浸式页面，但 prompt 不推测标题位置、CTA、组件布局或固定安全区。

## 1. 锁定 Background Grammar

从用户的主题、情绪、题材、品牌线索和参考图中确定四件事：

- **生成机制**：用一个动词短语说明整幅画面如何形成，如折叠、折射、扩散、堆叠、漂移、
  波相或明暗迁移。
- **视觉系统**：只选一个主系统——材质场、结构场、光色场、有机场、空间场；只有用户明确要求
  人物、物体或故事时才选具象场景。
- **作者性矛盾**：只设一个直接可见、无需寓意解释的非叙事矛盾，如严密秩序中的局部断裂、
  硬几何承载柔软光晕、人工精度被有机噪声轻微侵蚀。
- **裁切不变量**：指出中心、边缘或部分形体被切掉后仍成立的尺度、曲率、疏密、节奏或图底关系。

输入开放时直接选择一个鲜明机制，不输出一组平均方案。优先从结构场、有机场或光色场判断；
glass、chrome ribbon、orb 和普通风景照只有在题材需要时才使用，不作为安全默认值。

完成标准：上述四项各有一个明确答案，且任何一项都不依赖新增主体、故事或网页布局才能成立。

## 2. 把机制铺成连续视觉场

- 让形体或重复结构从画框外进入并再次离开，允许一个局部视觉峰值，其余区域保持低频变化。
- 用大尺度曲面、疏密变化、边缘裁切或空间纵深组织画面；高细节、亮部和饱和色集中出现。
- 具象主体必须嵌入环境节奏，与前后景共同构成场，而不是在中央孤立展示。
- “创作者调性”落实为准确取景、克制选择、可辨认的材质语言和一点未被立刻解释完的陌生感。
  人物、手、工具、工作室或创作过程只在用户明确要求时出现。

完成标准：缩成缩略图时先读成环境、场或节奏；横向、纵向和局部裁切都不会让画面失去全部意义。

## 3. 让质感服从物理关系

- 使用一个主色域、一个辅助色域和少量局部高光；多色变化来自材质、光照或生成机制。
- 用户要求适配 dark website 时，降低平均亮度但保留完整明度跨度，不把整张图统一压暗。建立三个可读层级：
  约一半至三分之二的深色环境用于衔接，足够宽的中间调负责读出主要形体，少量明确高光负责生命力与注意力。
  暗部必须有材质和轮廓，不能大面积死黑；主体不能与页面背景融成同一灰阶。
- 明确尺度、材质行为、光源方向和空间关系，用可观察细节取代“高级、未来、梦幻”等形容词。
- 让材料按自身规律响应光：glass 有厚度、折射与 caustic，silk 有连续褶皱和柔长 specular，
  chrome 有窄亮反射与清楚曲率，雾有体积散射，emissive core 有局部 bloom 与环境回光。
- Gradient 只在承担空间、光照、材质或情绪职责时使用；单色能保留同等信息时使用单色。

完成标准：暂时忽略颜色后，仍能从结构关系辨认这幅画；替换关键形体或材质会改变作品身份。适配暗色
网站时，灰度图中仍能清楚区分深色环境、中间调主体与局部高光，不依赖提高全图曝光获得可读性。

## 4. 为后续 Pseudo-motion 预留静态分层

用户说明素材将用于 image-to-video、动态 background 或 loop 首帧时，生图 prompt 仍然只描述静态画面。
在同一静帧中建立至少两个可分离景深层，优先使用三层：

1. **稳定锚点层**：承担主要视觉重量的大形体、地貌、装置或统一主体群，轮廓与材质稳定。
2. **前景分离层**：少量边缘清楚的小元素或柔焦遮挡，与锚点保持可辨认的轮廓和距离。
3. **后景环境层**：云、雾、远处光带、水面反光或低频纹理，使用宽阔、连续且不抢焦点的形态。

只描述各层在静帧中的位置、尺度、轮廓、遮挡和材质，不写摇曳、漂移、呼吸、视差、固定镜头、
循环方式或其他动作。控制遮挡交界，避免大量细碎元素粘在锚点轮廓上；降低细密 moiré、高频格栅、
密集粒子、复杂透明叠色和重 film grain，为后续处理保留干净素材。不要写时长、关键帧、motion blur、
video prompt 或 negative video prompt。

完成标准：只看生成图即可清楚指出前景、稳定锚点和后景的边界；prompt 中没有任何对象将如何运动的指令。

## 5. 写成交付 Prompt

沿用用户语言，按以下结构输出多行自然语言 prompt。每个 label 只承担一种职责；用户未说明后续动态化时
删除“分层关系”整行，其他没有实际内容的行同样删除。

```text
【创意核心】
背景机制：生成整幅画面的视觉规则及其连续变化。
核心形态：主形体、重复单元或环境层次，以及最值得凝视的关系。
作者性约束：一个可见的视觉矛盾，不解释象征意义。
空间与构图：尺度、疏密、裁切、图底关系与局部视觉峰值。

【视觉表现】
艺术方向：统一的摄影、3D、插画、mixed media 或其他媒介逻辑。
光线与色彩：主辅色域、光源方向、深色环境／中间调主体／局部高光的明度职责。
材质与质感：关键材料如何响应光，以及可见的表面细节。
情绪氛围：克制、反差、陌生感或时间状态如何形成意境。
分层关系：前景、稳定锚点和后景在静帧中的位置、轮廓、遮挡与分离方式，不描述动作。
素材边界：纯背景素材，不含可读文字、Logo、按钮、卡片、浏览器框或拟真 UI。
```

完成标准：最终只有一份 prompt；生成机制、作者性矛盾、裁切不变量和材质行为均可直接被图像模型执行，
每项信息只出现一次。

## 交付门槛

交付前逐项通过：

- 用一句动词短语即可复述生成机制。
- 画面身份来自明确的尺度、曲率、疏密、结构或材质关系，而非可任意替换的装饰形状。
- 连续场之外还有一个可见的作者性矛盾，且没有堆叠多个互相竞争的视觉系统。
- 去掉抽象审美形容词后，prompt 仍然具体、可观察、可执行。
- 画面不依靠居中英雄物体、宏大奇观、象征物或剧情才能成立。
- “创作者调性”没有被替换成人物或创作行为，除非用户明确要求。
- 适配 dark website 时没有把“暗色”误写成全图低曝光；灰度下仍有清楚的深、中、亮三级关系。
- 后续动态化分支满足第 4 节完成标准：只增加静态分层，不出现视频动作或循环措辞。

全部通过后直接输出 prompt，不附带解释、备选方案或生成参数。
