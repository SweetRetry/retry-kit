# 极简风格 (Minimal) 约束规范

## 设计哲学

1. **减法即设计：** 容器默认透明，留白即内容。减法测试——移除后核心功能不受影响，则该元素冗余。
2. **排版即层级：** 字重极端对比（extralight vs bold）建立信息层级，而非色彩或装饰。
3. **克制即品质：** 动效位移 ≤10px，色彩 90% 无彩色，投影为零——克制本身传递自信。
4. **呼吸即节奏：** 桌面端 40%+ 留白，让内容在空间中自然呼吸。

---

## 色彩原则

- **单色主导**：界面 90% 无彩色，通过 `bg-background` / `bg-card` / `bg-muted` 表达灰阶层级
- **单一强调色**：全局仅一种品牌色（`--primary`），仅用于 Primary Action
- **OLED 安全**：Dark Mode 使用 `oklch(0.145 0 0)`（≈#1A1A1A），禁止纯黑

---

## 暗色模式深度策略

投影在暗色背景上不可见。暗色模式下使用**亮度层级**替代投影：

| Level | 用途 | 亮度 |
|-------|------|------|
| Level 0 (Base) | 页面底色 | `oklch(0.145 0 0)` |
| Level 1 (Card) | 卡片/分组 | `oklch(0.205 0 0)` |
| Level 2 (Overlay) | 弹出层/下拉 | `oklch(0.269 0 0)` |

越接近用户的层，背景色越亮。严禁暗色模式下使用 `box-shadow`。

---

## 视觉模式

| 模式 | 核心约束 | 适用 |
|------|----------|------|
| **透明容器优先** | 卡片首选 `bg-transparent border-none shadow-none`；留白 >128px 时引入 `bg-secondary/30` | 博客、关于页、内容落地页 |
| **排版比例** | 超大标题 + 极端字重对比（`text-6xl md:text-8xl font-extralight` vs `font-bold`） | Hero、个人网站、时尚品牌 |
| **Bento 网格** | 非对称网格，不等分区块创造节奏。Gap 16-24px · Radius 12-24px · Padding 24-32px | 作品集、功能展示、产品矩阵 |
| **发丝分割线** | `h-px bg-border/20`，重要内容前留白更大；可搭配 `max-w-[120px]` 短线装饰 | 长页面、多段落文章 |
| **渐隐揭示** | 纯透明度过渡，位移严格 ≤10px，拒绝夸张滑入 | 内容渐进揭示、FAQ、时间线 |

## 动效常量

```ts
const microMotion  = { type: "spring", stiffness: 260, damping: 20 };
const revealMotion = { duration: 0.3, ease: [0.16, 1, 0.3, 1] };
```

- 入场编排 stagger: `0.06s`，入场位移: `y: 8`
- 位移上限 ≤10px，时长上限 <400ms

## 关键约束速查

| 维度 | 规范 |
|------|------|
| 留白率 | 桌面端 40%+，移动端 15-20% |
| 圆角 | `rounded-md` (6px) 或 `rounded-lg` (8px) |
| 动效位移 | ≤10px |
| 动效时长 | <400ms |
| 色彩 | 90% 无彩色，全局仅 1 种强调色 |
| 投影 | 禁用 |
| 对比度 | WCAG AA ≥4.5:1 |

---

## 质量标杆

好的 Minimal 界面像一首留白的诗——每个元素的存在都有分量，删去任何一个都会破坏平衡。Notion 的编辑器是标杆：什么都没有，但什么都不缺。字重对比（extralight 标题 vs bold 关键词）创造的戏剧性，比任何色彩和动效都强烈。

---

## 品味陷阱

- **空洞留白**：40% 留白不是把元素缩到角落——留白是围绕内容的呼吸空间，不是"没东西放"
- **无差别透明**：透明容器是默认，但当内容密度需要视觉分组时必须果断引入背景
- **微弱到看不见**：`border/20` 分割线在某些屏幕上不可见——测试实际设备，确保视觉韵律可感知
- **伪极简**：只是删掉了装饰但没有用排版建立层级 = 信息扁平化，不是极简
