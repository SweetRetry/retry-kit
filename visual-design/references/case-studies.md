# 案例参数拆解

真实产品的视觉决策推理链。重点不是抄参数，而是学**决策逻辑**。

---

## Linear — 效率工具的克制美学

**推理链**：目标用户是开发者 → 效率是核心 → 高密度 + 边框层级（方案 A）→ 品牌色极度克制（暗底上的一点靛蓝 = 视觉签名）→ 营销站用大排版低密度做区分，登录后切回高密度。

**关键参数**：`rounded-md` 全局统一 · Inter + JetBrains Mono · 入场 4px / 200ms · 8pt 网格严格执行

## Notion — 设计不抢内容注意力

**推理链**：核心是写作 → 设计服务内容而非自身 → 极致纯粹（方案 B：留白 + 透明）→ 品牌人格通过手绘插画注入 → 严格限制在空状态/引导页（占比 < 5%）→ 稀缺性保证每次出现都有惊喜。

**关键参数**：`rounded-sm` · System serif 标题 + System sans 正文 · 几乎无动效

**注意**：Notion 的 serif 标题是刻意的内容编辑器特例（文档即内容，排版风格本身是产品功能），不可作为"Tool 场景可用 serif"的依据。通用 SaaS/Dashboard 仍禁用 serif。

## Spotify — 路由分隔两种情绪

**推理链**：「情感体验 vs 高效管理」两种不可调和的需求 → 用 Tab/路由天然分隔 → 沉浸模式（Now Playing）用动态取色 + 低密度 → 列表模式用紧凑高密度。

**关键参数**：方案 C 背景色阶梯 · 封面主色提取作为页面氛围色 · 播放页有过渡动效，列表页无

## Apple 产品页 — 产品即展品

**推理链**：品牌核心是「产品即艺术」→ 视觉服务于产品展示 → Scroll-driven 让产品讲故事 → 支持/文档页不需要同样处理 → 按页面类型切换风格是合理的。

**关键参数**：全屏沉浸型 Hero（暗底 + `text-7xl font-light`）· 产品本身提供色彩，背景极度克制

## Raycast — 视觉技法必须解决功能问题

**推理链**：效率工具必须快 → 纯效率缺乏差异化 → Glassmorphism 同时解决深度感知 + 工作流视觉连续性（功能性，非装饰性）→ Squircle 连续圆角统一了插件生态的视觉信任。

**关键参数**：Squircle 全局统一 · 零延迟响应，用速度中和玻璃材质的「重感」

**注意**：Raycast 的 glassmorphism 是 macOS native 浮层的功能性模拟，本质是系统材质语言，不代表 glassmorphism 作为通用 Brand 技法仍然有效。通用 Brand 页面的深色底首选 Grain Texture + Mesh Gradient，全页面 glassmorphism 已过气。

**字体说明**：Raycast 产品本体使用系统字体栈（Inter / SF Pro），这是 macOS native 应用的惯例。Brand 场景禁用 Inter 的规则适用于 Web UI，不适用于 native 应用字体决策——两者不冲突，不可互相作为依据。

---

## 可迁移原则

1. **路由分隔风格** — Tab/路由/登录墙是天然的风格边界，比页面内混搭简单一个数量级
2. **品牌记忆点 = 一个独特的参数选择** — 一种颜色在一种背景上，比十种花哨效果更有力
3. **辅助元素稀缺 = 惊喜** — 5% 出现频率比 30% 更有效
4. **技法必须解决功能问题** — 纯装饰性技法不值得实现成本
5. **一致性 > 品味纯度** — 产品内部的参数一致比单个参数的最优选择更重要
