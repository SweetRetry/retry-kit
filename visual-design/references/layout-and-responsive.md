# 布局、响应式与媒体

## 内容宽度详解

### 各页面类型的 max-width 选择

| 页面类型 | max-width | Tailwind | 推理 |
|----------|-----------|----------|------|
| 落地页 / 品牌页 | 1024px | `max-w-5xl` | 阅读舒适 + 留白充裕，居中后两侧留白产生品牌感 |
| Dashboard / 应用 | 无限制 | `flex-1` | 功能优先，屏幕利用率 > 留白美学 |
| 阅读 / 设置页 | 672px | `max-w-2xl` | 最佳阅读行宽 60–80 字符 |
| 全宽展示（12 列 grid） | 1280px | `max-w-7xl` | 足够放 12 列 grid 且不会过宽 |

### 内容区与浏览器窗口的 padding 关系

```
px-4       →  移动端（< 640px）
sm:px-6    →  平板（640–1023px）
lg:px-8    →  桌面（≥ 1024px）
```

- 这是容器外层 padding，内部 section 的 padding 另算
- `mx-auto` 居中容器时，这个 padding 防止内容贴边

### 全出血（full-bleed）vs 约束内容区

- **默认**：所有内容在 `max-w-*` 容器内
- **全出血例外**：Hero 背景色/图片、分隔色带、页脚可以全宽
- 实现：外层 `w-full` 背景 + 内层 `max-w-* mx-auto` 内容

```tsx
// 全出血背景 + 约束内容
<section className="w-full bg-muted">
  <div className="max-w-5xl mx-auto px-4 sm:px-6 lg:px-8 py-20">
    {/* 内容 */}
  </div>
</section>
```

## 网格系统

### 12 列 grid 常用分栏

| 比例 | 列数 | 用途 |
|------|------|------|
| 1 + 1 | 6 + 6 | 左右对称布局（Hero B 型、对比展示） |
| 1 + 2 | 4 + 8 | Sidebar + 主内容（应用页面） |
| 2 + 1 | 8 + 4 | 主内容 + 侧边信息 |
| 3 等分 | 4 + 4 + 4 | Feature 卡片、定价卡 |
| 4 等分 | 3 + 3 + 3 + 3 | 指标卡片、Logo 墙 |

### Grid vs Flexbox 选择

| 场景 | 选择 | 原因 |
|------|------|------|
| 二维布局（行+列对齐） | `grid` | 行列同时控制 |
| 一维排列（单行或单列） | `flex` | 更简单 |
| 不等分 Bento | `grid` + `col-span-*` | 跨列能力 |
| 导航 / 按钮组 | `flex` + `gap-*` | 灵活间距 |

### Gap 值

遵循 SKILL.md §IV 的间距语义：
- `gap-2` ~ `gap-4`：同一组件内
- `gap-6` ~ `gap-8`：同一区域
- `gap-12`+：不同区域

## 响应式策略

### 断点

使用 Tailwind 默认断点，不自定义：

| 断点 | 宽度 | 典型设备 |
|------|------|----------|
| `sm` | 640px | 大屏手机横屏 |
| `md` | 768px | 平板竖屏 |
| `lg` | 1024px | 平板横屏 / 小笔记本 |
| `xl` | 1280px | 桌面 |

### 移动端标题

| 级别 | 移动端最小值 | 桌面值 |
|------|-------------|--------|
| H1 | `text-3xl`（1.875rem） | `text-5xl` ~ `text-7xl` |
| H2 | `text-xl`（1.25rem） | `text-2xl` ~ `text-3xl` |
| H3 | `text-lg`（1.125rem） | `text-lg` ~ `text-xl` |

### 平板中间态（md: 768px – lg: 1024px）

Agent 最容易忽略的断点。桌面布局直接缩到平板会溢出或挤压，移动端布局放到平板又太空旷。

| 场景 | 处理 |
|------|------|
| 双栏布局 | `md:grid-cols-2`（保持双栏），`lg:grid-cols-3` 在桌面扩为三栏。不要在 md 就堆成单栏 |
| Sidebar | `md` 下折叠为图标栏（`w-14`），`lg` 展开完整 Sidebar |
| 卡片网格 | `grid-cols-1 md:grid-cols-2 lg:grid-cols-3`，平板保持 2 列 |
| Hero 标题 | `text-3xl md:text-5xl lg:text-7xl`，平板用中间档，不跳级 |
| 间距 | 平板用标准档（`py-16~20`），不直接用桌面的宽松档 |

### 导航模式切换

| 桌面 | 移动端 | 选择依据 |
|------|--------|----------|
| Sidebar（固定左侧） | Bottom tab bar | 应用型产品（Dashboard, SaaS） |
| Sidebar（固定左侧） | Hamburger 菜单 | 内容型产品（文档, CMS） |
| 顶部导航 | Hamburger 菜单 | 落地页 / 营销页 |

- 二选一，不混用

### 触控适配

- 间距在移动端放大一档：`gap-4` → `gap-6`
- 触控目标 ≥ 44×44px（WCAG 要求）
- 列表行高移动端 ≥ `h-12`

### 内容策略

- 移动端可隐藏装饰元素（背景图案、浮动装饰），核心信息必须保留
- 左右分栏在移动端变为上下堆叠：`grid-cols-1 lg:grid-cols-2`
- 表格在移动端用卡片堆叠替代，或 `overflow-x-auto` 横滚

## 图片与媒体

### 宽高比

| 用途 | 比例 | 说明 |
|------|------|------|
| Hero 图 | 16:9 或 3:2 | 宽幅视觉冲击 |
| 产品截图 | 16:10 | 接近真实屏幕比例 |
| 头像 | 1:1 | 圆形或圆角方形 |
| 卡片缩略图 | 4:3 | 紧凑且通用 |

- 始终声明 `aspect-ratio`，防止 CLS（Cumulative Layout Shift）

### object-fit

| 图片类型 | 值 | 原因 |
|----------|------|------|
| 照片 / 插图 | `object-cover` | 填满容器，允许裁切 |
| 截图 / UI | `object-contain` | 完整展示，不裁切 |

### 暗底叠加（Hero 背景图上放文字）

```
bg-gradient-to-t from-background/80    → 底部渐隐
bg-black/50                            → 全面暗化
```

- 叠加后文字对比度仍需 ≥ 4.5:1

### 图标

- 一个项目一套库：Lucide / Phosphor / Heroicons，不混用
- 图标尺寸遵循设计系统的 size token

### 插图风格

- 与品牌调性一致：效率工具不用卡通风格，儿童产品不用极简线条
- 同一页面内插图风格统一（线条粗细、着色方式、透视角度）
