# 视觉模式库

构图骨架参考。选择适合当前场景的模式，具体参数由风格档位（SKILL.md Step 2）决定。

---

## Hero 变体

### A. 居中大标题
```
[大留白]
    H1（居中，特大）
    副标题（居中，次级色，较窄）
    CTA 按钮组（居中，1 primary + 1 ghost）
[大留白]
```
适合：标题字数 ≤ 5 词的品牌宣言页、发布页
**限制**：Brand 场景标题超过 5 词时禁用——改用 B（左文右图）或 C（全屏沉浸）

### B. 左文右图
```
[留白]
    [左半] H1 + 副标题 + CTA（左对齐）
    [右半] 产品截图 / 插图
[留白]
```
适合：产品展示、功能介绍

### C. 全屏沉浸
```
[全屏深色背景]
    H1（居中，极大，轻字重）
    副标题（可选）
    背景：渐变 / 产品渲染图 / 视频
```
适合：品牌宣言、发布页、表现风场景

### D. 数据驱动
```
[浅底]
    H1（左对齐或居中，偏小）
    指标卡片组（3–4 个）
        数字（Mono 大字）
        Label（小字，全大写）
```
适合：Dashboard 首页、SaaS 概览页
**档位**：Tool 场景专用

## Feature Section 变体

相邻 section 必须用不同构图，禁止连续 3 个结构相同的 section。

### 交替左右
```
Section 1: [左文] [右图]
Section 2: [左图] [右文]  ← 镜像
Section 3: [居中图 + 下方描述]  ← 换构图
```

### Bento Grid
```
[主卡，面积 ≥ 2x 其他卡] [副卡]
[副卡]                    [副卡]
```
主卡必须存在，确立视觉焦点。实现参数：`grid-cols-[2fr_1fr]`，主卡 `row-span-2`。

### 单栏大图
```
H2 + 描述（居中，较窄）
[间距]
全宽产品截图 / Demo（视觉焦点）
```
截图是主角，文字是引导。

## 应用类页面

### Dashboard Shell
```
[Sidebar | 主内容区]
  Logo      Topbar（面包屑 / 页面标题 / 操作）
  导航项     页面内容
  用户菜单
```
Sidebar 与主区用 border 或背景色差分隔，选一种全局统一。

### 设置页
```
[单栏，居中，较窄]
  H2（页面标题）
  Section 分组：H3 + 表单字段
  [分隔]
  下一个 Section
  底部：Save 操作
```

### 空状态
```
[居中，较大留白]
  图标（低存在感）
  标题
  描述
  CTA（唯一）
```
整体视觉权重要低，引导用户行动才是目的。

---

## 模式选择原则

1. 每屏一个视觉高潮，通常是 Hero 或主 CTA 区
2. 密集区之后跟低密度区，制造呼吸感
3. 表现风场景优先考虑 Hero C（全屏沉浸）+ Bento Grid 的组合
4. Tool 场景优先考虑 Hero B（左文右图）或 Hero D（数据驱动）+ 交替左右 Feature Section；Hero A（居中）仅在标题 ≤ 5 词时可用于 Brand，Tool 场景不使用居中 Hero
