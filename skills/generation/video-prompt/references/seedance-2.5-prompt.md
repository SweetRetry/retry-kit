# Seedance 2.5 Prompt Reference

只在目标入口明确为 Seedance 2.5 时使用。素材解释、信息顺序、格式与能力限制以本文件为准；其余内容与连续性原则见 `video-prompt` 主文档。

官方依据：[提示词指南](https://docs.volcengine.com/docs/82379/2607689?lang=zh)、[输入任务教程](https://docs.volcengine.com/docs/82379/2607688?lang=zh)。

## 1. 素材引用与任务意图

- `@` 是 prompt 中引用上传素材的 literal 前缀。按上传顺序写 `@图片1`、`@视频1`、`@音频1`；英文入口按当前 UI 实际解析的 token 写 `@image1`、`@video1`、`@audio1`。
- 只有说明编号—职责时可写“图1”“视频1”；需要模型回指上传素材时必须使用 `@`，例如 `参考@视频1的运镜和动作`、`将@图片1中的人物对应@视频1中的红色模型`。
- 官方公式中的尖括号只是占位符，不能原样输出。

先确定这次 prompt 属于哪种意图：

| 意图 | prompt 的写法重点 |
| --- | --- |
| 文生视频 | 直接写主体、地点、事件、风格、镜头与声音，不引入不存在的参考素材 |
| 语义参考 | 先完成 `@素材 → 控制职责` 映射，再写新故事 |
| 首帧／首尾帧 | 把首尾画面作为严格的开始／结束锚点，正文只写两者之间如何自然变化 |
| 视频编辑 | 明确写 `编辑视频`，并用增加／加上、删除／去掉、修改／替换／改成说明对象、变化、时段和保留项 |
| 视频延长 | 写向前／向后延长、延续或续写，并先继承原视频的身份、运动方向、光线和声音，再写新变化 |
| 素材一键成片 | 写素材出现顺序、叙事顺序、需出现的文字／贴纸与转场，不把多份素材笼统称为“全部参考” |
| 无缝转场 | 写前段结束状态、后段起始状态、需要保持的主体／光线／声音以及过渡方法 |
| 组合能力 | 先选一个主任务，再逐项写素材职责与交接关系 |

## 2. 素材可用性

- 单次最多使用 30 张 4K 以内图片、10 个视频、10 个音频，合计不超过 50 个参考素材。
- 每段视频／音频及同类型素材总时长均不超过 30 秒；成片最长 30 秒。故事超出可读时长时，在叙事断点拆为多次 generation，而不是继续堆叠事件。
- 可以只用音频发起 generation。素材接近上限时，更严格地把每份素材限定为单一职责，避免主体、风格、动作或声音互相竞争。

## 3. 参考素材模式

语义参考只提取素材的指定层次，不要求逐帧复刻。每份素材选择一个主职责，并将未继承的层留给当前 prompt 重设。

| 模式 | 适用素材 | 需要写清的内容 |
| --- | --- | --- |
| 主体参考 | 人物、动物、道具、场景或虚拟角色的图片／视频／音频 | `@` 编号、主体名称、稳定外观或声音；动作、构图与情绪由正文决定 |
| 动作／运镜参考 | 视频、动作白模、预演视频 | 继承动作、运镜、光影中的哪些层；白模对象如何对应正式主体 |
| 场景参考 | 图片或视频 | 空间、时代、布景、环境关系和主光；是否同时继承镜头或氛围 |
| 风格参考 | 图片或视频 | 材质、色彩、光影、摄影或渲染气质；不让风格覆盖角色 ID 与故事 |
| 音频参考 | 音频、带音视频 | 音色、台词、旋律、节拍或环境氛围及其出现时段 |
| 多宫格故事板 | 一张多格分镜图 | 只作为大致剧情；正文仍按镜头补齐动作、运镜、空间和风格 |
| 多关键帧 | 多张独立图片 | 首句写“以图片 X 至图片 Y 的顺序作为关键帧”，再补齐中间运动和转场 |

- 多宫格的控制强度低于独立关键帧；必须逐画面对齐时选择关键帧。
- 白模只继承明确指定的动态信息。叠加角色图时写清正式角色与白模对象的对应关系，并让文字描述与白模时空内容一致。
- 参考视频已提供准确动作、运镜或节奏时，只写继承范围；补充它未提供的身份、场景、风格、声音和结尾。

## 4. 素材选择

- 主体音视频参考优先少量主体与短片段；主体过多或素材过长会降低稳定性。
- 实际单次上传不超过 9 张图，只放本次生成用到的素材。
- 同一主体在本次生成用到的多视角或表情用一张设定图上传，例如三视图；本次用不到的服装与状态不放进来。多个主体或物件并排在一张图里时，每个标上编号，正文写「@图片X 中的 N 号」指代。
- 故事板保持在 15 格以内，使用干净、简约的线稿，少放文字。素材越多越必须缩窄每份职责。

## 5. Prompt 的信息顺序

先写：

`主体 + 地点 + 事件 + 题材/风格 + 特殊运镜`

再按时间或镜头顺序写画面动作、摄影机、对白和音效，最后补充全片持续生效的镜头、环境、声音和情绪。

- 2.5 支持连续时间范围、时间点和相对时间。时间范围必须连续，例如 `0–3s、3–7s、7–15s`；每段只放能读清的事件，时间戳不用来控制频次。
- 直接写通用景别、机位、运镜和转场；小众术语补一个可见解释。转场写触发点、时间和方式。
- 动作优先是一条连续动作链，只把记忆点写到肢体细节；表情写成可观察的脸部、视线和姿态。
- 把对白、环境声、Foley、音乐与可见动作或时间段绑定。只对字幕和音频使用精确的负向控制，例如无 BGM 但保留环境声和动作音。

## 6. 输出前检查

- 任务意图明确，所有 `@类型序号` 能回指上传素材；素材职责不竞争。
- 图片、视频、音频的数量、时长和成片时长均符合第 2 节；超过限制时已按叙事断点拆段。
- 故事板与关键帧、语义参考与首尾帧、编辑与延长没有混淆为同一种控制强度。
- 时间范围连续，转场、动作、镜头、声音和文字均有明确时段或触发点。
- 不把本文件的 `@` 语法、时间戳能力或任务触发词迁移到其他模型。
