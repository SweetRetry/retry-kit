# 生成式设计套路候选

封杀清单那一轮的提问素材。按产品的界面类型挑出相关条目，每条作为一个问题提出并附推荐答案；用户确认的条目才写进 design.md 的 Do's and Don'ts，替代做法取自品牌与规范的访谈结果，本清单不预设风格。品牌明确选用的手法（如品牌渐变）不列为封杀项。

每条写进 design.md 时，用一句可观测描述命名，并给出该产品的正向替代。

## 通用

- **居中 Hero 加三张卡片**：首屏是居中大标题、空泛副标题和三张并列的图标卡片。业务内容被套进万能模板，首屏不呈现真实结论或工具。
- **卡片套卡片**：层层容器和描边代替分组，页面像一堆盒子。分组关系本可由留白、字阶和对齐表达。
- **装饰性质感**：渐变文字、模糊光斑、网格背景、毛玻璃和大面积投影，不承载状态、可供性或空间关系，只制造“精致感”。
- **徽章泛滥**：日期、作者、分类等普通元数据都套进 Pill 或 Badge，真正的状态提示因此失去辨识度。
- **装饰图标砖**：每个标题或段落前加图标，或给图标加浅色底块，不提高识别速度。
- **叙述创作过程**：页面上出现“本页采用了……布局”“接下来我们看……”之类的生成者口吻。

## 数据与报告类界面

仅在产品有这类界面时提问。

- **重复章节**：摘要、背景、建议、结论反复陈述同一主张。每个主张只应有一个出处。
- **表格被挤窄**：证据表格塞进窄栏，表头折行、数值挤压，旁边留白。
- **对齐冲突**：表头与单元格对齐方式不一致，数值列无法纵向扫读。
- **装饰图表**：图表不共享刻度或零基线，面积不对应真实数值。
- **情绪用色**：仅因数字“向好”就标绿，客观陈述变成自我推销。

文案中的夸张修辞与虚假精确属于文案范围，不在此提问。
