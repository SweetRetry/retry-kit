# 图标

图标替代或锚定文字，不做装饰。先定这个位置要不要图标，再定用图标库还是自绘。

## 1. 图标还是文字

判据：去掉图标后，用户是否找得更慢、认错对象或漏看状态。三者都不会时用纯文字。

图标只出现在：

- **纯图标按钮**（`size="icon*"`）：含义跨产品通用的动作（关闭、搜索、更多、复制、展开、拖拽），带 `aria-label` 与 Tooltip。要想一下才对得上的动作改用文字按钮。
- **扫视锚点**：导航、菜单、工具栏中需要扫视定位的同级条目，图标作文字前缀，同组全有或全无。
- **状态**：偏离常态、需要在扫视中被捕捉的状态（报错、警告、离线、同步中），图标与文字并用，不只靠颜色区分。
- **对象类型**：列表混排多种对象（文件格式、渠道、集成）时，图标区分类型。
- **业务空态**：主工作区空态的插图，按 §3 自绘。

其余位置用纯文字：

- 页面标题、CardTitle、DialogTitle、纯文字 Tab。
- 动词已说清含义的文字按钮（保存、取消、提交、确认）。
- 没有约定图形的抽象概念（权限策略、计费周期、审批规则）。要在多个候选里挑一个「大概像」的隐喻图标时，说明没有约定图形，用文字。

图标不重复相邻文字已说清的含义，不放进彩色圆形或方块底色。

## 2. 图标库

- 沿用项目已安装的图标库；未安装时用 `lucide-react`（shadcn 的 `components.json` 中 `iconLibrary` 的默认值）。lucide 缺少所需图形或需要多档字重时改用 Phosphor（`@phosphor-icons/react`）。一个项目只用一个图标库，品牌 Logo 除外。
- 全应用一种笔画：lucide 统一 `strokeWidth`，Phosphor 统一一档 `weight`；只有选中态可切到实心变体。
- 颜色继承 `currentColor`，随文字 Token 变化；状态图标用语义 Token（`text-destructive`）。
- 尺寸跟随相邻文字：`text-sm` 配 `size-4`，`text-xs` 配 `size-3.5`。组件库变体已统一 svg 尺寸时，调用点不再写尺寸。
- 旁边有文字的图标加 `aria-hidden`；纯图标按钮的可访问名称写在按钮上。

## 3. 自绘 SVG

库图标只能表达泛化类别（收件箱、文件、文件夹），含义却取决于业务对象的结构或状态时，自绘 SVG：

- **业务空态**：画出该对象在本产品里的空形态，如没有节点的流程画布、没有卡片的看板列、没有阶段的流水线，让用户认出「这里将出现什么」。放大的库图标与通用插画（空盒子、云朵、人物）做不到这一点，不用。
- **领域图标**：高频出现、作为扫视锚点、库里没有对应图形的领域对象，自绘一枚图标。

取形与画法：

- 从界面里该对象的真实构成取形（节点与连线、行与列、卡片轮廓），做简化，不找隐喻。验收：遮住相邻文字，熟悉产品的用户仍能说出它指哪个对象。
- 领域图标与图标库同网格：`viewBox="0 0 24 24"`，四周留 2 单位，描边宽与库一致，`stroke-linecap="round"`、`stroke-linejoin="round"`、`fill="none"`；与相邻库图标并排截图比对视重。
- 空态插图是单色线稿：`stroke="currentColor"` 配 `text-muted-foreground`，至多一个强调元素用 `text-primary`；路径加 `vector-effect="non-scaling-stroke"`，放大后笔画仍与图标库同宽；宽度 `w-24`–`w-40`，置于空态标题上方，每个空态一幅。不用渐变、阴影、纹理与多色填充。
- 写成项目内的组件（与其他图标同目录），插图加 `aria-hidden`，含义由相邻标题承担。
- 卡片、侧栏、弹窗内的子列表空态不加插图。
