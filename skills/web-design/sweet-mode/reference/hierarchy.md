# 信息层级与渐进式披露

先理清信息关系，再选组件承载。

## 1. Canvas 与 Chrome

压缩 Chrome，把视区留给 Canvas 与焦点。

- **Canvas**：用户此刻处理的工作对象及其留白，包括流程当前步骤、看板数据或工具里的作品。任务越需要专注，Chrome 越要让位。
- **Chrome**：导航、筛选、工具栏与上下文属性。只取完成任务所需的最小体量。
- **焦点**：推进任务的主操作或偏离常态的状态，连同隔离它的留白。单线流程只留一个推进主操作。主操作归属当前步骤尚未完成的目标动作。例如收集输入时在底栏提交键，交付结果供取用时在内容区取用键，而不是底栏关闭键。

按以下规则组织界面元素：

- **留白分组**：列表用留白、共享左对齐轴与 `space-y-*` 分组。Card 只用于语义、结构与操作同级的对象，绝不卡片套卡片。
- **真实承接**：每个元素必须对应真实需求、真实数据源或真实事件逻辑。不渲染假搜索框、装饰通知铃、空头像菜单、空链接、凑数统计卡，以及没有历史基线的涨跌百分比。列表预期不超过一屏（≤ 7 项）且无服务端过滤时，不放搜索框、筛选器与分页器。
- **信息增量**：每句文字、每个数字与每个标签都是一条陈述。用户从标题、字段名、可见项数量或控件本身已能得知的信息，直接删除。不影响当前判断或操作的信息（如其他角色的权限、系统内部归属），直接删除。有用但不满足 §2 判据的信息，延后披露。字号变小或颜色变浅不改变一条信息是否多余，多余的直接删除。
- **次要文字限额**：能用分组、顺序、控件或命名表达的信息，不写成说明文字。单个条目（列表行、卡片、表单字段、区块标题）至多保留一处次要文字。描述、副标题与眉题只写不写就会引发误操作的业务约束。Badge 只用于强状态或核心分类。
- **单字段单位置**：留下的字段各占一个独立结构位置，如分组、对齐列、行尾、图标或 Badge。不用 `·`、`•`、`|`、`/` 把多个字段拼成一行，也不在标题里拼接状态。
- **权重决定大小**：主导指标单独放大，次要指标紧凑排列。

## 2. 渐进式披露（Progressive Disclosure）

以当前场景的用户任务为单位。满足以下任一条件的信息直接呈现，其余延后披露：

1. **影响此刻决定**：缺少会导致判断错误或阻断流程，如代价、不可逆后果、禁用原因、报错，以及立即生效还是异步生效。原因未知时直接写明未知，不编造诊断。
2. **需要并排比较**。
3. **当前任务的高频主操作**。

用四个问题确定披露载体：

1. 保留当前上下文时，用就地展开或锚定浮层。需要脱离上下文并专注处理时，用模态弹窗或独立页。
2. 临时查看的内容，用易关闭的浮层。持续使用的内容，留在内容流（折叠区、分段切换、侧栏）。
3. 纯解释文本，用最轻的提示。包含输入或选择时，用可聚焦、可键盘操作的载体。
4. 互斥分支同一时间只显示一个。并列内容分组后折叠次要组。

常见映射如下：

- 保留上下文、临时且含交互：Popover / DropdownMenu。
- 保留上下文、持续或互斥：Tabs / ToggleGroup / Accordion。
- 脱离上下文且需专注：Dialog / Sheet。
- 需要深链或分享：独立路由。
- 无法推出时，沿用应用内同类场景的做法。同类内容全应用只用一种披露方式。

遵守以下披露边界：

- 只有一两个次要操作，或折叠后入口比原内容更难理解时，直接呈现。
- 表格行只留识别、判断所需的列与主操作。其余操作放进尾部溢出菜单，详情放进抽屉或详情页。
- 专业工具与设置的高频项一次点击可达，危险设置直接可见。
- 悬停只做增强。后果、禁用原因、报错与操作必须有不依赖悬停的可见入口，保证触屏与键盘可达。
- 披露入口使用带可访问名称的图标或带状态的标签，不依赖隐藏手势。
- 浮层不嵌套浮层。二级内容改为模态内分步或锚定浮层。
- 展开后的内容不得推翻用户基于收起态已做出的判断。

## 3. 功能编排

菜单、导航、工具栏与设置页用位置回答“这项操作作用于什么”。先定每项的作用对象与影响范围，再定分组与顺序：

- **位置即归属**：作用于同一对象的条目聚成一组，紧贴该对象。由一组内容派生的操作（新建、批量、查看全部）留在组内。只在归属改变处分组。
- **单一维度排序**：组间按离当前上下文由近到远排列，入口图标与文案承诺的用途排最前。组内按当前任务的使用频率排列。离开当前上下文或不可逆的操作排在所属组末尾，与同组条目隔开。
- **一对象一位置**：选择能同时承接对象状态（当前、选中）与管理操作的位置。列表行只能承接选择时，将该对象提出列表单独呈现并附带操作。
- **名称脱离位置仍成立**：同类操作作用于多个对象并存时，名称写出作用对象。只有一个对象时省略。
- **权重跟随可交互性**：分组标题、元数据等不可交互文字的视觉权重必须低于可交互条目。

## 4. 检验

用以下七项检查整页与截图：

- **缩略图**：把整页截图缩到约 400px 宽查看。首要焦点、分组与阅读路径依然清楚，没有等权区块互相抢眼。
- **Data-ink ratio**：逐项尝试移除卡片、边框、背景、图标、颜色与动效。移除后不损失信息或意符（signifier）的，不再恢复。
- **最小惊讶**：操作前只凭文案、图标与位置预测结果，再实际操作。结果必须与预测一致，不出现未声明的跳转、清空或提交。
- **一致**：同一对象全应用只用一个名称。同类操作、确认方式、反馈形态、空态与同级控件尺寸与项目既有界面一致。差异只用来表达语义差异，无语义的差异改回既有做法。
- **同级**：重复结构的对象保持语义、结构与操作一致。不等价对象用排序、分组、占比或密度区分。同级图表共享基准轴，面积与数值呈线性对应。
- **移植**：只替换文案后，版式若能直接套给无关业务，说明构图由模板主导。此时按真实内容重做。
- **窄屏**：375px 截图中通过重排保持层级与操作，关键内容完整，正文字号不缩小。
