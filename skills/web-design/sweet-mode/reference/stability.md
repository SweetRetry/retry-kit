# 尺寸稳定

状态变化不移动已有内容的位置。

## 1. 加载

- **首次加载**：结构固定的内容（卡片、表格、媒体）用 `aspect-*` 或 1:1 骨架屏占位；动态长流（文章、评论）只留 `min-h-[1lh]`，避免空数据时二次坍塌。
- **翻页、筛选、刷新**：旧数据保持渲染（`opacity-60`），加载反馈放在触发控件（按钮内 Spinner、Tab、边缘细进度条）。清空搜索或重置视图时直接清空。
- **控件**：按钮进入加载或禁用态时锁定宽高。

## 2. 卡片网格等高

同排卡片根节点 `h-full flex flex-col`；标题 `line-clamp-2` 或设最小高度，正文 `flex-1`，底部操作 `mt-auto`；媒体显式声明比例（`aspect-video w-full object-cover`）。

## 3. 空值与溢出

- 空列表渲染固定体量的空状态；缺失文本留 `min-h-[1lh]` 或 `"—"`。占位区分未加载、空、缺失与失败，不用默认值掩盖。
- 字段提示区预留 `min-h-5`，报错出现时不推挤提交按钮。
- 含动态文本的 Flex/Grid 子项加 `min-w-0`，长文本 `truncate` 或 `line-clamp-*`。

## 4. 退出过渡

退出过渡期间内容停在退出前的状态：触发退出的回调只负责退出，不改写即将消失的视图层级、选择、草稿、文案或计数；需要重置的状态在下次进入时重置。浮层关闭、toast 消失、折叠收起与列表项移除同理。
