# 布局与间距

用留白、共享对齐轴与表面差异表达分组。

## 间距

- 使用 8px 网格（`gap-2`、`gap-4`、`gap-6`、`gap-8`）。4px 只用于图标、角标等紧密关联元素。
- 按接近性原则（Law of Proximity）分组。组间距至少是组内间距的 2 倍。标题上方留白大于下方。标签先与输入框成组，再排表单项间距。
- 新布局从较宽档位起步，在完整页面中逐档收紧，直到分组清楚、阅读顺畅且主操作可达。高频工具与密集数据按任务密度取值。
- 兄弟间距由父容器 `gap-*` 或 `space-y-*` 控制，可复用组件根节点不写外部 margin。`margin` 只用于 `ml-auto` / `mt-auto` 推挤、负边距通栏与长文本排版流。

## 宽度

- 表单与阅读内容用 `w-full max-w-*`，按字段长度与阅读需要取档。成段阅读正文的行宽不超过约 65 个西文字符（`max-w-prose`）。
- 数据表格、编辑器与画布按比较或操作需要占用可用宽度。数据表格横向滚动或全宽显示，不为旁侧内容压缩列宽。
- 全宽导航不要求下方区块同宽，内容够用后保留侧边留白。
- 图像本身是内容时，可破出页边铺到视口边缘，不加圆角，不入卡片。文字仍对齐原栅格。

## 12 栏网格

页面画布与复杂看板用 `grid grid-cols-12`，不写绝对像素宽度。侧栏、工具面板等固定宽度结构面除外。等宽分栏只给同级对象，权重不同时用非对称分配：

| 形态 | 列分配 | 场景 |
| :--- | :--- | :--- |
| 主辅非对称 | `col-span-8` + `col-span-4` | 详情主体 + 侧栏 |
| 对称双栏 | `col-span-6` × 2 | 双栏表单、左右对比 |
| 三列等分 | `col-span-4` × 3 | 同级方案比较 |
| 四列等分 | `col-span-3` × 4 | 同级次要指标 |

跨多列的子项在移动端默认 `col-span-12`。

## 控件

- 控件高度由组件 `size` 变体管理。调用点不给 Button、Input、SelectTrigger 写 `h-*` 或 `py-*`。
- 同一行并排的输入框、只读值容器与操作按钮保持单行且同高，传入相同 `size`。带并排按钮的只读值优先用 `<Input readOnly>`。
- 输入框宽度跟随预期字符数。表单容器 `max-w-*` 内，验证码、端口、金额、天数等短字段收窄到 `w-24`–`w-48`，长文本字段占满整行。
- 选择控件跟随选项数量。2–4 个互斥短选项平铺为 RadioGroup 或 ToggleGroup。5–12 项用 Select。超过 12 项用 Combobox。

## 对齐

- 每个区块建立一条主轴。标题、正文、标签与控件的起始边落在同一条线上，不混用左对齐与居中。轴线按光学对齐取边。
- 偏离轴线必须承载层级或状态，如缩进、悬挂图标、居中的空态与主图。无语义的偏移视为缺陷。
- 条目元数据（日期、编号、作者）夹在标题上方会打断标题与正文的共同起始边。宽屏有侧边留白时，将元数据挂到轴线外侧并与标题首行对齐。窄屏时放回内容流。
- 图标与文字用 `inline-flex items-center gap-2`。大标题伴随辅助操作时用 `items-baseline`。
- 数值列对齐见 [typography.md](typography.md#数字字形)。

## 边界

- 分区优先靠留白与共享对齐轴，其次用微弱明度差，不用高对比度 1px 边框。
- 同色相邻元素必须留缝。填充色相同且有别于底色的相邻元素（并排按钮、卡片、标签、色块、选中行）零间距相接时，按统一连接性会被读成一个整体。留出 `gap-*` 即可打断连接，无需换色或加边框。只有刻意读成一件控件（ButtonGroup、分段控件）时才允许相接。
- 一处边界只用一种手段。相邻区域已靠明度差区分（`bg-sidebar` 与 `bg-background`、`bg-card` 与 `bg-background`）时，不再加分隔线或外框。Table、代码块等自带边界的组件直接放进布局流，不外套带内边距和边框的 Card。
- 成组列表可用 `divide-y divide-border/40`。菜单用组件库的 `*MenuSeparator` 分组。工具栏控件组之间用 `<Separator orientation="vertical" />`。其余分区用留白，不放横向 `<Separator />`。

## 光学对齐（Optical Alignment）

对齐文字字面与图形的视觉边缘和重心，而不是 DOM 边框盒。调整只在局部封装：

- 带内边距的 ghost 按钮与列表项 hover 底色，用 `-mx-*` 配 `px-*` 补偿，让文字落回主轴。
- 不对称图形（Play、Star）用 `translate-x-px` 微移 1–2px。图标加文字的按钮削减图标侧 1–2px 内边距。
- 引用块首行引号用 `hanging-punctuation: first` 或负缩进。
