# 图标

图标用来替代或锚定文字，不做装饰。先决定这个位置是否需要图标，再决定用图标库还是自绘。

## 1. 图标还是文字

用一条判据决策：去掉图标后，用户是否找得更慢、认错对象或漏看状态。三者都不会时，改用纯文字。

只在以下五类位置使用图标：

- **纯图标按钮**（`size="icon*"`）：含义跨产品通用的操作（关闭、搜索、更多、复制、展开、拖拽），必须配 `aria-label` 与 Tooltip。需要想一下才能对上的操作，改用文字按钮。
- **扫视锚点**：导航、菜单与工具栏中需要扫视定位的同级条目。图标作文字前缀，同组全有或全无。
- **偏离常态的状态**：页面级与区块级的报错、警告、离线或同步中状态。图标与文字并用，不只靠颜色区分。表格与列表行内状态按 `surface.md` §2 用圆点。
- **对象类型**：列表混排多种对象（文件格式、渠道、集成）时，用图标区分类型。
- **业务空态**：完整空态的插图（判据见 `resilience.md` §3，面板内同样适用），按 §3 自绘。

其余位置一律用纯文字：

- 页面标题、CardTitle、DialogTitle 与纯文字 Tab。
- 动词已说清含义的文字按钮（保存、取消、提交、确认）。
- 没有约定图形的抽象概念（权限策略、计费周期、审批规则）。当需要在多个候选里挑一个“大概像”的隐喻图标时，直接用文字。

图标不重复相邻文字已说清的含义，不放进彩色圆形或方块底色。

## 2. 图标库

- 沿用项目已安装的图标库。未安装时默认用 `lucide-react`（shadcn `components.json` 的默认值）。需要缺失图形或多档字重时，改用 Phosphor（`@phosphor-icons/react`）。一个项目只用一个图标库，品牌 Logo 除外。
- 全应用统一一种笔画：lucide 统一 `strokeWidth`，Phosphor 统一一档 `weight`。只有选中态可切换为实心变体。
- 图标颜色继承 `currentColor`，随文字 Token 变化。状态图标使用语义 Token（如 `text-destructive`）。
- 图标尺寸跟随相邻文字：`text-sm` 配 `size-4`，`text-xs` 配 `size-3.5`。组件库变体已统一 svg 尺寸时，调用点不重复写尺寸。
- 旁边有文字的图标加 `aria-hidden`。纯图标按钮的可访问名称写在按钮上。

## 3. 自绘 SVG

当库图标只能表达泛化类别（收件箱、文件、文件夹），而含义取决于本产品对象的结构或状态时，自绘 SVG：

- **业务空态**：画出该对象在本产品里的空形态（无节点的流程画布、无卡片的看板列、无阶段的流水线），让用户立刻认出这里将出现什么。不用放大的库图标或通用插画（空盒子、云朵、人物）。
- **领域图标**：高频出现、作为扫视锚点且库里没有对应图形的领域对象，自绘一枚图标。

按以下规范绘制：

- **取形**：从界面里该对象的真实结构简化取形（节点与连线、行与列、卡片轮廓），不找隐喻。遮住相邻文字后，熟悉产品的用户仍能说出它指哪个对象。
- **领域图标画法**：与图标库保持同一网格（`viewBox="0 0 24 24"`、四周留 2 单位、描边宽与库一致、`stroke-linecap="round"`、`stroke-linejoin="round"`、`fill="none"`）。写完后与相邻库图标并排截图比对视重。
- **空态插图画法**：单色线稿，用 `stroke="currentColor"` 配 `text-muted-foreground`，至多一个强调元素用 `text-primary`。路径加 `vector-effect="non-scaling-stroke"`，确保放大后笔画仍与图标库同宽。宽度在页面内取 `w-24`–`w-40`，在面板与侧栏内取 `w-16`–`w-24`，放在空态标题上方，每个空态一幅。不用渐变、阴影、纹理或多色填充。
- **封装**：写成项目内独立组件并与其他图标放在同目录。插图加 `aria-hidden`，含义由相邻标题承担。
