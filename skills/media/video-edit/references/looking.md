# 看片

你看的是抽帧，不是视频。这份讲在这个限制下怎么看准。

## 密度

| 要看什么 | 怎么出图 |
| --- | --- |
| 全部素材的内容、镜头、明显的崩坏 | `analyze` 生成的 1fps 触点图 |
| 挨着选段边缘、只粗看过的崩坏 | `edit.py inspect`，自动定区间，6fps |
| 选段的入出点、段内风险 | `edit.py sheet <clip> --start S --dur D --fps 4`，变形快的段用 6 |
| 镜头边界有没有漏帧 | `--fps 24`，边界前后各 0.3 秒 |
| 屏幕上的字、首尾帧 | `--at T` 单帧大图，或 `clips.json` 的 `first`、`last` |

图上没有时间戳。每次出图，命令都会打印网格和时间的对应关系，照着它换算。

## 机器给的是候选

- **镜头切点。** 会漏渐变、推拉、叠化、慢慢变亮变暗，以及同色背景下的换人。会误报闪白、光爆、快速运动模糊、屏幕内容整体切换。对着 1fps 图核对：漏了就在 `log.json` 里拆开镜头，误报就合并。某条素材漏得多，用 `edit.py analyze --clip <id> --threshold 0.12` 重算，没动过的日志骨架会跟着更新。
- **黑场和静帧。** 黑场多是生成素材里的「隔一下」。静帧不一定是问题，特写和定格表情可能是有意停顿。画面停住、声音也没变化，才是素材卡住。
- **台词。** 转写用 `ggml-large-v3` 加 VAD（init 时给 `--whisper-model` 和 `--vad-model`），kotoba-whisper 在自然口语评测上明显差，turbo 在一个评测集上出过整段重复，所以都不作默认。时间大致可信，字不可信，同一句常被转成不同的字。台词用来定哪里不能切，不当文案。要做字幕时人工核对。同一句重复出现好几遍，多半是无语音段的幻觉。

## 崩坏

AI 画面的崩坏集中在固定的地方。看到这些就放慢：

- 素材头尾的一两秒。
- 快速运动、旋转、广角和鱼眼的变形。
- 手、手指，以及手和物体接触的地方。
- 屏幕、纸面、招牌上的字。
- 换衣、洗澡、转身。
- 几个主体互相遮挡。

`kind` 的取值和定义见 `edit.py schema log`。

- **区间。** 从看得见问题的最早一帧写起，不从最明显的那一帧写起。1fps 上看到的，前后各放 0.5 秒，`seen` 写 1。精选时细看过再改准。
- **严重度。** 想的是观众会不会注意到。主体的脸、画面中心、持续好几帧的，是 major。边角的、一闪而过的、被运动模糊盖住的，可以是 minor。
- **不雅画面。** 换衣、洗澡类镜头一律 4fps 以上逐帧看，把整段暴露区间标成 `nudity`。

## 备选

同一拍点的几条备选，常见这些特征：首尾帧和关键帧构图相似，只有局部不同；台词或画面文字的语种不同；时长几乎一样。AI 分别生成的备选像素相似度很低，指纹比对分不出来，靠看图和台词判断。

## 顺序的证据

有剧本时以剧本为准，下面几条只用来把素材对到剧本的场次上。没有剧本时，按可靠程度从高到低：

1. 屏幕上的时间、日期、进度（钟表、手机、日历）。
2. 首尾帧衔接。上一条的尾帧和下一条的首帧在同一空间、接着同一个动作。
3. 台词里的问答和指代。
4. 道具和服装的状态变化，比如没穿好到穿好、完整到碎裂。
5. 类型惯例，比如起床在出门前、产品镜头在片尾。这一条是推断，写进 brief 时标「推断」。

## 空间

有两个以上主体，或者有方向运动的镜头，在镜头的 `side` 里记下主体在画面的左右和运动方向。越轴要靠相邻选段的 `side` 对比才能发现。
