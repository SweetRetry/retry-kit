# Video Prompt

每份 Prompt 对应目标入口的一次生成，可含长单镜或连续多镜。只引用已确定素材与媒介，不捏造输入。

## 1. 选择模型规则

从上下文确定模型；无法确定且会改变写法时询问。只读取目标模型 reference，其素材解释、顺序、格式和能力限制优先于通用写法：

- [Seedance 2.0](references/seedance-2.0-prompt.md)
- [Seedance 2.5](references/seedance-2.5-prompt.md)
- [MiniMax-H3](references/minimax-h3-prompt.md)

## 2. 明确素材职责

多素材时标注控制范围，仅在实际冲突处添加隔离说明：

| 素材 | 锁定内容 | 保持自由或由当前剧本决定 |
| --- | --- | --- |
| 角色 | 五官、体型、固定服饰 | 动作、表情、站位与位移 |
| 场景 | 空间结构、透视与主光 | 运镜带来的透视、天气微动；人物固有色与动作 |
| 风格 | 质感、色彩与画面媒介 | 人物或道具几何与动作路线 |
| 动作／运镜 | 指定动作路线、节奏或机位 | 主体身份、五官、发型与服饰 |
| 音频 | 指定音色、旋律、对白或底噪 | 画面既定节拍；按情绪调整音量 |

用可见特征建立拍摄基准：媒介、画幅、光线、色温和主体空间锚点。排除项仅保留用户要求或避免实际冲突所需内容，表达方式按模型 reference。

## 3. 写出时序与连续性

- 按顺序写起始状态、主动作演进、摄影机、环境反馈、声音与结束状态；只保留当前任务需要的项目。
- 接触与变形写清触发、施力方向／接触点、受力反馈和终态；情绪外化为表情、呼吸或抓握。对白与音效对齐动作时段。
- 新道具、地点或动作留足“看清 → 发生 → 反馈”的时间；时长不足先删次要动作。
- 同一机位与连续运动能交代清楚时保留长镜；视点、时空或焦点改变时明确切镜。
- 多镜承接人物、道具、空间与运动状态。连续动作尾帧保留惯性，不提前减速定格。
- 超出入口时长时，在动作暂停或场景切换处分段。每段重述交接所需的身份、持物、位置、方向、主光与声音基调。

## 4. 核验与交付

仅省略当前模型与参考模式能可靠承载的信息；是否逐镜补动作、运镜与空间按模型 reference。删去空泛修饰和无法拍到或录到的文学描述。

只输出可直接粘贴的 Prompt。冲突按用户最新要求及模型规则处理；仍需取舍时再询问。
