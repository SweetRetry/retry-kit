# Seedance 2.0 Prompt Reference

只在目标入口明确为 Seedance 2.0 时使用。素材解释、信息顺序、格式与能力限制以本文件为准；其余内容与连续性原则见 `video-prompt` 主文档。

官方依据：[提示词指南](https://docs.volcengine.com/docs/82379/2222480?lang=zh)、[输入任务教程](https://docs.volcengine.com/docs/82379/2291680?lang=zh)。

## 1. 素材引用语法

- `@` 是 prompt 中引用上传素材的 literal 前缀。按上传顺序写 `@图片1`、`@视频1`、`@音频1`；英文入口按当前 UI 实际解析的 token 写 `@image1`、`@video1`、`@audio1`。
- 官方教程中的 `<图片N>`、`<视频N>`、`<主体N>` 是公式占位符，不能原样输出。尖括号只在本模型的音效标记 `<>` 中有 literal 语义。
- 每次回指素材都保留 `@`、类型和序号。素材库 ID、素材内文字或素材数量不能取代这个绑定。

## 2. 素材可用性

- 单次可引用最多 9 张图片、3 个视频、3 个音频；图片、视频、音频可以组合，但不能只上传音频发起 generation。
- 单次成片为 4–15 秒；素材或故事超过这一范围时，先按叙事断点拆分，再为每段写自包含 prompt。
- 编写 prompt 前先删除不会承担身份、动作／镜头、场景／风格或声音职责的素材。超过上限、只含音频或职责冲突的素材组合不能直接交付。

## 3. 先写清任务意图

| 任务 | 写法 |
| --- | --- |
| 全模态参考 | `参考@图片1中的女孩，生成……`、`参考@视频1中的运镜，生成……`、`参考@音频1中的音色，生成……` |
| 编辑视频 | 直接写 `严格编辑@视频1，将……改为……`；不要写“参考@视频1”，未提及内容保持不变 |
| 延长视频 | 写 `向前延长@视频1` 或 `向后延长@视频1`，再交代续接的动作、空间、声音与结束状态 |

- 组合任务先写参考素材及其控制维度，再写编辑或延长目标，例如“参考@图片1中的角色外观，严格编辑@视频2，将……”。
- 编辑增加元素时写元素特征、出现时机和位置；修改写原特征与新特征；删除写删除目标及必须保留的内容。
- 延长多段素材时写出过渡画面与交接关系，例如“@视频1 后接……，再接@视频2”。

## 4. 全模态参考素材模式

| 模式 | 素材与写法 | 继承范围 |
| --- | --- | --- |
| 主体参考 | `参考@图片1中的女孩` | 身份、外观、服饰、道具或场景主体；当前动作、表情与构图由正文决定 |
| 动作／运镜参考 | `参考@视频1中的运镜、动作` | 动作路径、节奏、机位或摄影机路径；不要让它隐式覆盖角色身份和场景 |
| 场景／风格参考 | `参考@图片1中的场景与光影` | 空间、环境、光影、色彩、材质或影像气质；不自动继承其中人物与事件 |
| 音频参考 | `参考@音频1中的音色` | 音色、旋律、节拍、环境声或音效质感；正文仍需写声音的发生时段 |

- 多个模式可组合，但每份素材只承担明确职责。例如主体图控制身份、运镜视频控制运动、音频控制声音，然后再写新故事。
- 需要稳定主体时写“将@图片1中穿红裙、戴草帽的女人定义为张红”，后续始终使用同一标签。
- 参考视频已准确给出动作或镜头时，只说明继承范围；补充它未提供或当前任务主动改变的场景、风格、声音与结尾。

## 5. Prompt 的信息顺序

按官方公式组织：

`精准主体 + 动作细节 + 场景环境 + 光影色调 + 镜头运镜 + 视觉风格 + 画质 + 约束条件`

- 先锁定“谁做什么”，再写地点、光色、摄影机与风格，最后补充确有必要的画质与可验证约束。
- 复杂视频写 `镜头1`、`镜头2`、`镜头3`，按事件顺序排列。每镜依次写运镜／切换、动作与表情、空间变化、必要声音。2.0 不稳定支持精确秒级时间戳，用镜头序号而非硬时间段控制节奏。
- 动作写身体部位、幅度、速度、力度和前后承接；高爆发动作拆出起势、受力与结果。情绪外化为视线、呼吸、姿态、表情或说话方式。
- 使用标准景别、机位和运镜词。

## 6. 声音、台词与文字

| 内容 | 标记 | 写法 |
| --- | --- | --- |
| 音乐 | `()` | 写音乐质感、起止、音量与情绪关系 |
| 音效 | `<>` | 写声源、动作落点、空间感和强弱 |
| 台词 | `{}` | 保留原话，并写说话人、情绪与发生时机 |
| 字幕 | `【】` | 保留原文，并写出现时段、位置和可读性 |

- 非中文台词依次写语言、必要的地区变体或口音、表达方式、说话人和 `{台词原文}`。
- 画面文字写原文、颜色、风格、出现方式、时机和位置；优先常用字，避免生僻字与特殊符号。

## 7. 素材准备与检查

- 角色身份优先使用独立、清晰的人脸特写，再配合单独半身或全身图。人脸、姿态、服装、细节和背景混在一张图中，或人脸占比过小，容易造成 ID 漂移。
- 角色图负责身份，姿态与动作由正文或运镜视频负责。出现 ID 漂移时，减少竞争素材、换清晰脸部锚点、重写主体定义与职责。
- 检查素材数量、类型和时长符合本文件第 2 节；所有 `@类型序号` 可解析；主体、动作／运镜、场景／风格、音频都有明确来源；声音标记与内容类型匹配；不把本文件的语法迁移到其他模型。
