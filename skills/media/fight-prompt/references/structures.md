# 分粒度 Prompt 结构与运镜映射

不同生成任务的注意力预算不同：30 秒多镜长段需要严密的全局锁防漂移，2–5 秒单镜特写或挥斩若硬套全套全局锁反而会稀释画面质感。根据本次任务的生成粒度选用以下三种模式之一；输出时整段为纯文本，不带 Markdown 标题符号。

## 1. 模式选择

| 模式 | 适用场景 | 结构取舍 |
| --- | --- | --- |
| **模式 A：多镜导演长段** | 单次生成 10–30s、含 4–10 个镜头的完整交手段落 | 配齐「素材／主体绑定 + 段落头 + STYLE LOCK + VFX／打击字典 + 执行锁定 + DIRECTOR SHOTS（含 CAMERA 与 HANDOFF）+ 负面提示词 + 尾行」 |
| **模式 B：单镜精拍短片** | 单次生成 2–6s，只拍一个极致镜头（蓄力微距、全身发力挥斩、独立奇观终爆） | 只保留本镜出场素材、简化版 STYLE LOCK、本镜用到的 0–2 条视效锁与单条 SHOT；删去不触发的执行行与跨镜衔接行 |
| **模式 C：多段接力组接** | 战局超过模型单次时长上限，或高潮拆为多条专精镜头（微距＋出招＋关键帧终爆）剪辑成片 | 按静止蓄力点、合鞘点或关键帧切分；每段按自身粒度选模式 A 或 B，标注成片时间段与本段上传素材，续段显式继承前段战损与站位 |

## 3. 模式 B：单镜精拍短片（2–6s 极致单拍）

单镜生成时，删去 `SEGMENT` 流程链、跨镜衔接与未触发的执行行，按镜头任务选用以下三种精简重心：

### 变体 B1：蓄力／机关微距镜（如压镡吸风、扣扳机、瞳孔映敌）

不写 `VFX LOCK` 大字典与交手因果，聚焦微距光学、局部机械动作与环境微物牵引：

```text

STYLE LOCK
[媒介质感一句]。具名色：[本镜用到的 3–4 种颜色归属]。[核心介质]具备[微距可见特征]，禁止退化成[白雾／糊光]。场景锁定：[战场基调与主光一线]。

执行锁定
```

## 4. 模式 C：多段接力与分镜组接协议

当完整战斗需要拆成多条 prompt 时，按以下规则保证剪辑无缝咬合：

1. **选准切分点**：只在**蓄力顶点定姿**（如举刀指天白光炸开）、**收招死寂拍**（如合鞘瞬间）、**遮挡擦镜**（碎鳞、刀光、浓烟铺满前景的一瞬）或**微距切全景的尺度跳变点**拆分，不在半截挥刀中途硬断（除非刻意做动作匹配剪辑并锁死首尾帧）。
2. **动态筛选每段素材**：每条 prompt 顶行标明 `用在：[成片时间区间]` 与 `上传：[本段实际用到的素材名]`，不把本段不出场的资产塞进上传列表分散模型注意力。
3. **跨段守恒传递**：
   - 具名色分账表、双方核心不变量与永久地标方位在各段之间保持一致。
   - 续段（如 B 段）在 `环境` 行首句显式列出上一段留下的具体战损（如 `左肩缺三块甲、胸前缺两块甲、画左冰沟全程保留`），且 `SHOT 01` 开场画面直接带着这些痕迹起拍。

## 5. 运镜动力学映射表

拒绝无意义的镜头乱晃或机械套用焦段；根据当前拍点的**戏剧任务**选配焦段与机位：

| 当前拍点的戏剧任务 | 焦段与机位运动 | 构图与空间锚定要求 |
| --- | --- | --- |
| **起势蓄力、机关触发、眼神博弈** | `85–100mm 微距／特写`：贴刃口、刀镡、胸核、眼瞳缓推或沿器物横移 | 用刀面、冰面或瞳孔倒影带出对手或奇观；背景永久地标或天际主光虚化为光斑 |
| **看清全身发力链、格挡拆招与残心** | `35–50mm 中景稳机位或正侧平移`：机位稳住，不急推乱甩 | 完整框入从脚下地面到兵器末端的发力轨迹与衣发惯性，保留一侧地标 |
| **高速对冲、连闪换位、贴身缠斗** | `24–35mm 越肩、低位侧跟、横向急甩`：贴近运动轨迹同步加速跟拍，随换位反向甩镜 | 保持 180° 轴线同侧（越轴需连续环绕划过），借前景掠过的火花碎屑强化速度感 |
| **巨物苏醒压迫、重击落地的重量兑现** | `18–24mm 贴地仰拍`：随巨物起身上摇，顺巨爪／重锤落势急摇向下，接触瞬间径向重震 | 将前景碎石／冰簇与高耸出画的巨物叠压构图，保留背景月亮或高大断柱作尺度标尺 |
| **立体机动、穿烟突进、弹幕穿梭** | `14–18mm FPV／贴背跟拍`：贴角色后背冲出烟尘、擦肩扑向受击点，或高空俯冲切入近景 | 让碎甲、冰片或火星迎面擦过镜头边缘，目标始终处于冲刺准星方向 |
| **灾变大招展开、双波中点爆炸** | `12–16mm 无人机超广角`：随下劈俯冲后再被冲击波推着急速拉升后退 | 把渺小角色、庞大对手、铺天盖地的视效几何与永久地标同框收进画面，兑现天崩地裂尺度 |
| **战后余韵、胜负落定** | `50mm 平视慢移` 或 `100mm 特写缓推`：呼吸感慢速推进或绕到侧前方定格 | 落在一个安静微细节（雪落眉梢、刀尖垂地、余烬熄灭），画内保留全部累积战损 |
