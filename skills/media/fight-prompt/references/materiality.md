# 打击与视效实体化指南

视频模型会把抽象的动作与能量词汇（如“凌厉剑气”“强大魔法”“剧烈爆炸”“高速交手”）坍缩成廉价白雾、平面光圈、细光线、均匀火团或无重量擦碰。编写招式词条与重击描述时，先按本文件的四步法把效果还原为可拍摄的物质与光学结构。

## 1. 实体化推导四步法（通用任何题材与未知能力）

遇到任何战斗媒介（包括下表未列出的水墨、重力、声波、沙暴、血咒、丝线、纳米机械等），按以下四步构建描述：

1. **找物理载体**：拒绝“纯粹能量”或抽象形容词，指定可见物质或光学现象作为载体（如墨滴与飞白残迹、空气透镜折射与压碎的石块、绷紧反光的金属细丝、电弧与高压白汽）。
2. **锁几何与基数**：写死形状、厚度与具体数量。唯一核心、裂口、巨墙写死 `1 颗／1 道` 防止模型复制出多个；离散弹体、冰棱、斩痕、花瓣写清具体数目（如 `七根`、`三层`、`三十道`）防止稀释成乱飞粒子；尺寸用相对人体或画幅的比例锚定（如 `宽过半个画面`、`高过人物五倍`、`一指厚`）。
3. **拆内外复合层**：拒绝单层色块，拆为 `主色核心实体材质` + `内含纹理／流束／碎物` + `外缠伴生物（碎石、电弧、霜花、焦烟、浪沫）` + `前缘或接触点的极亮信号`。
4. **立反退化对举**：预判该效果最容易偷懒退化成的廉价视觉，在句尾写明 `不是[退化态]，而是[带厚度／折射／重量／碎片的实体态]`。

## 3. 蔓延与相变铁律

- **沿结构蔓延**：冻结、熔化、腐蚀、裂解或充能作用到躯体与环境时，必须写明**路径**（沿甲缝五路爬开、沿刀口裂纹冻结、从膝甲螺旋爬上胸口、沿斜切线错位滑开），严禁写“全身变红／变白／发光”。
- **异质相变**：两类介质接触时写出物理相变——冰火相撞炸出白汽与融水；高热刃入海蒸成细雾；气浪掠过水面压出凹槽；重击落石地先龟裂下陷再掀飞石块。
