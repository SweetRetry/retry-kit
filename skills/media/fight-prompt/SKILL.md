# Fight Prompt

视频模型生成战斗画面时有五种高频退化：双方无接触对空挥或木桩挨打、动作匀速发飘缺乏重量、特效坍缩成白雾或平面光、高速运动下敌我色彩与空间跳乱、短镜头硬套长模板导致失焦。本 skill 用**按粒度封装、力学耦合、视效实体化、节奏反差、全局守恒**五条原则锁死生成结果。

不同生成粒度（单镜精拍、多镜长段、多段组接）的输出结构与运镜映射见 [structures.md](references/structures.md)；物理搏击、冷热兵器与超凡能量的实体化拆解见 [materiality.md](references/materiality.md)。动笔前先读完两份参考。

## 1. 定生成粒度与素材职责

**原则：结构服务于单次生成的注意力预算；单条 prompt 只携带本镜实际出场并生效的资产与锁。**

先判断本次交付属于哪种粒度，按 [structures.md](references/structures.md) 选择对应封装结构：

- **单镜精拍（2–6s）**：聚焦单一戏剧动作（蓄力微距、单招挥斩与残心、独立命中终爆）。删去未触发的全局行与过场，把描述密度集中在当前镜头的微距物理、全身发力链或爆裂层次上。
- **多镜长段（10–30s）**：单次生成包含起承转合的完整交手段落。配齐风格色彩锁、招式或重击字典、执行与因果锁、逐镜时序与镜间 `HANDOFF`，防止中后段设定漂移与战损吞没。
- **多段组接成片（Assembly）**：战斗超出单次时长上限，或包含跨尺度特写（如微距压镡 → 稳机位挥斩 → 巨型刀痕终爆）时，在**姿态定格点（举刀蓄满、合鞘静止、单膝滑停）或强光遮挡处**拆成多条独立 prompt。每条只上传本段实际出场的素材；续段开场显式继承前段留下的战损、站位与光线。

明确每份输入素材的控制边界，防止互相污染：

- **身份素材或文生主体**（角色、对手、武器）：有参考图时用目标入口语法绑定，无参考图时直接内联进开篇主体句；各自锁死 3–6 项全段不变的可见几何特征（发式、疤痕、服饰或装甲结构、兵器部件、瞳色、胸口核心）。身份图里会在战斗中被毁、卸下或改形的部件（饰物、头盔、护甲、兵器），绑定时写明它只代表某个时间点之前的外观；之后该角色出场的每个时间片都正面写一次新状态（`[部位]空无一物／已断／已卸下`），它的碎片与残骸离开原位、不排成原形，否则模型会在下一个特写里按身份图把它画回来。
- **场景素材**：锁死 2–3 个永久地标及其画面方位，区分不可毁地标与可改写介质（地面、海面、云海、植被）。
- **质感或关键帧素材**：只借材质、形态或特定画面构图（如冰封质感图、劈天刀痕关键帧），显式写明人物或对手外观仍以对应身份素材为准。纯终爆命中镜可撤下出招角色，直接绑定关键帧素材与受击目标。
- **生成与剪辑分工**：单帧黑白冲击帧、硬切全屏频闪卡点、补帧与调色归后期剪辑，不写进生成指令；仅当剧情设计了 1–2s 的风格化变身过场时，才写明帧级媒介切换（如发光线稿、2D 平涂与厚涂笔刷）并锁死前后同位置同姿态落定。

## 2. 建攻防力学与动作锚点

**原则：交手是双方力学关系的实时耦合，拒绝单人套路拼接与无代价越级硬扛。**

先按双方的**体量比、兵刃射程与人数**确定攻防语法，再设计具体动作：

| 对抗类型 | 攻防力学语法 | 受击与环境反馈 |
| --- | --- | --- |
| **悬殊体量（以小搏大／巨物战）** | 小体型方禁用原地招架硬扛，防御词表限定为斜架卸力、贴地侧滑、借力蹬踏、绕背攀爬；被迫硬接必写泄力代价（双膝下沉龟裂、被推出十米犁沟）。巨物起手沉、落势快，靠体量横扫与压迫 | 巨物局部崩甲、碎鳞、断角、后仰踉跄或单膝跪地；落空攻击写明砸毁的柱段、礁石或地面深坑，兑现重量 |
| **同体量近身博弈（冷兵／拳脚）** | 重在距离切入（丈→尺→寸）、兵刃走势（粘、架、弹反、刮刃滑脱）与重心破坏（破防失衡、扣腕别肘、横扫跌扑）；每次交锋改变双方身位或攻守主导权 | 刃口火花、护具裂痕、衣袍撕裂、脚步滑行犁痕、震退撞碎掩体 |
| **远程与重火力交锋（法术／枪炮／机甲）** | 锁死发射源与后坐力 → 弹道或束流跨空间推进 → 拦截（立盾、斩开、掩体吃弹）或机动规避；两股持续力量对撞时写出推回位移与中点压缩咬死 | 护盾蛛网碎裂、反应装甲掀飞、过热白汽、焦黑弹孔群、后坐力踏陷地面 |
| **一打多群战（突围／冲杀）** | 主角沿明确动线切入，每拍只与前景最近 1–2 个目标发生实打实的物理接触，其余敌群承担围拢、受惊硬直或被余波扫飞，禁止多人同平面乱挥 | 前景受击者甲碎倒飞撞翻后排，阵型被犁出缺口 |

再写**动作因果链**，招式、升级与分镜都从这条链上取：

- 用一串 `X → 所以 Y` 写完整段交手。每一步的起因是上一步留下的东西：受力转成下一招的起势，被改写的环境成为下一步的条件（遮蔽、掩体、落脚点、障碍），一方的处境逼出另一方的新手段；角色设定里的特质在链上某一步成为破局的原因。双方每一步都在回应对方。
- 双方距离、关键物体的尺寸与数量在链里写定并逐步记账；每一步都能用这些数值走通（够得着、来得及、数得清）。

为关键动作建立清晰的**姿态锚点**与**触发映射**：

- **起势 → 爆发 → 残心**：开场、静拍与终局的招式钉死**起手定姿**（沉腰握刀、拇指压镡、双手举刀过顶、拉弓满弦）与**收势残心**（刀停身侧半秒、单膝插刀滑停、背身静立衣发顺刀势甩出），用两端静止姿态夹住中间的高速爆发。链中段的招式以上一步的反作用为起势，收势直接流进下一步。
- **身体动作唯一触发**：超凡招式或重火力在执行锁中建立 `身体动作 → 【招名】` 的触发表；没有身体发力起手或机关动作的能量不凭空出现。
- **形态切换防融化**：战斗中发生变身或装甲着装时，严禁写连续变形；锁死**同一位置、同一姿势**，通过能量光柱、发光线稿闪切或装甲部件逐块扣合完成切换。

## 3. 实体化打击与视效

**原则：把抽象的能量词与打击感拆解为定量几何、复合材质、结构蔓延与反退化对举。**

先确定本段战斗的**物理档位**，再按 [materiality.md](references/materiality.md) 编写视效或重击条目：

- **写实物理档（纯武侠、历史冷兵、拳脚搏击、现代战术）**：不添加超自然发光；用刃口冷光与交击火星、气浪压平草木或震散雨雾、衣料绷紧与撕裂、肌肉与甲片震颤、石板龟裂与泥水飞溅来外化力道。
- **超凡与科幻档（法术、剑气、机甲重武、异能）**：本段出现的每个核心视效或特殊重击建立独立【招名】词条（攻守双方均列），每条写齐四要素：
  1. **定量几何**：明确形状与形制，外形易混的物件（矛与剑、枪与炮）用部件级正面描述锁定（头部形状、杆或柄、护手有无、长度比例）、写死数量（唯一光核、裂口、巨浪写死 `1 颗／1 道` 防复制；离散连击、冰棱、花瓣写死 `七道／十二簇／三层` 防稀释）与相对人物或画面的尺寸。
  2. **内外复合层**：`[主色 + 核心实体材质]`，内含 `[内部纹理／流束／碎晶]`，缠绕 `[外层伴生物：碎石／电弧／霜花／焦烟／浪沫]`，`[前缘／尖端／命中处]` 爆 `[全场唯一信号色]`。
  3. **结构化蔓延**：效果作用到目标或环境时，沿物理结构推进（沿甲缝爬开、沿裂纹冻结成壳再崩落、切口先滑开再崩散、海面先压凹成漩涡坑再拔起成巨墙），拒绝全身均匀变色。
  4. **反退化对举**：条尾固定写 `不是[该效果的廉价退化态]，而是[带厚度／重量／折射／碎片的实体描述]`。
- **受击剥离物守恒**：按受击方材质锁死掉落物清单（碎甲、碎鳞、断角、碎岩、冰片、熔滴、电火花；无血化风格显式锁死无血液与断肢，写实血肉题材按需限定血雾或破布）。

## 4. 排节奏与升级曲线

**原则：靠速度反差、极静蓄势与分级爆发制造张力，避免同一烈度反复拉锯。**

- **命中帧同步**：命中帧上镜头（重震、急推或被冲击波推开）、速度（升格只放在出刃或接触瞬间，崩碎或滑脱时骤回全速）、光（超凡档接触点闪亮并照亮双方；写实档靠飞溅的汗水、水花、火星反光与灯具晃动）、声（重击或骤停）、环境（冲击环、碎石、气浪）与身体（震开、后滑、形变）在接触点同时突变。视效的落点就是接触点。
- **单向升级曲线**：多镜段落按每镜 `2–4s`（终爆可至 `5–6s`）排布，每拍兑现一次可见升级：**新机制首现、空间或尺度跃升、攻守易势或实质破防**，且这次升级由上一拍的结果逼出。拍名连起来即为动作链，烈度不回落。总时长由动作链长度与交手密度推出，在模型上限内按需取值。
- **变速与静拍控制**：
  - **交手密度**：交锋以连击串为单位，串内接触间隔 `0.3–0.6s`，写成 `每 0.4s 一击，连续 N 击` 并逐击列出动作；一个时间片可以装下一整串。慢只来自升格与静拍：全段升格不超过 3 处、每处不超过 `0.3s`，静拍只留给开场、终爆前与收势，其余时间全速。
  - **极动前极静**：终结技释放或大对撞爆发前，留出 `0.5–1.5s` 的静拍（四周死寂芒草垂落、两股力在正中咬住静止、镜面刀身最后一寸滑入鞘口）。
  - **局部静止防死帧**：需要定格刀痕、残影或冰封瞬间时，写成**核心刀痕／姿态静止 + 环境微物（雪片、浪沫、碎鳞、寒气、发梢）持续飘动或被牵引**，避免模型把整幅画面冻成死帧。
- **多级终爆与余韵收势**：
  - 高潮打击拆成 **2–3 级几何演化**（如“先下凹成漩涡坑吸住目标 → 反向膨胀立成巨墙 → 覆落吞没”，或“先旋转收紧向内一缩 → 再由内向外逐层绽开／炸裂”）。
  - 先定结尾类型。**悬停**：停在全段张力最高的接触或揭示上（两股力咬死、对手新形态首现、角色隐藏的能力或状态首次显露），让下一段有处可接；段落属于更长战斗时优先悬停。**收势**：胜负落定，给落败反应与余韵留足时长，最后 `1.5–2s` 落在一个安静的可见细节（缓步垂刀、闭目呼出白气、余焰渐暗）。两类结尾都把全段累积的战损与地标定格在画内。

## 5. 锁全局守恒、分镜运镜与交接

**原则：高速运动靠色彩分账、动态光源、永久地标与镜间动势交接维持时空连续。**

- **色彩分账与动态光影**：
  - **具名色互斥**：写成 `X 色管 Y`。对抗双方不共色；若单一角色跨阶段升级变色（如按招式阶段分用紫、淡青、深海蓝），各阶段主色明确切换且不侵入对手色域。非接触区各保本色，接触界面才产生全场唯一的**命中信号色**（通常为炽白）与相变物（白汽、折射、分色交界）。环境固有色独立具名，不在分账表内的颜色归入负面约束。
  - **能量即光源与反射叙事**：发光招式、熔核与爆心作为实时光源照亮面部、甲片与地面，或在大招出现时压暗天光；善用**反射面**（镜面刀身、竖瞳、冰瓣、水面）在特写中映出对手或巨型奇观；关键命中瞬间将双方轮廓压在爆点或背景亮源前形成清晰剪影。
- **空间双层制与因果门控**：
  - 方向与路径用画面坐标写：每个运动物写明朝向、起点与去向（`[物体][朝向]，从[画面方位]向[画面方位][运动方式]`）；要对撞的两股力放在同一条轴上。主角朝目标前进的方向全片只呈现为两种：侧面镜头里朝画面一侧（如画右），身后镜头里冲向纵深；交锋镜头只从这两类机位拍，环绕不越过对抗轴。
  - 锁死双方基本站位关系与 2–3 个永久地标；战损痕迹（裂坑、犁沟、焦痕、霜迹、缺甲）随镜头**单向累积、只增不减**。
  - 严格执行 `成形 → 逼近 → 接触 → 受力 → 破坏 → 留痕`，接触前对方不倒、地面不碎；跨拍联动写死**门控事件**（如 `霜环触到钩爪后魔兽才睁眼`、`刀镡咔地合上鞘口那一刻冰莲才绽放`）。
- **分镜时序与同拍双动**：
  - 镜内按 `0.5–2.0s` 切片推进。**同一时间片内攻守双方都有动作或受迫反馈**（即便被冻结或压制，也有红眼骤缩、熔核跳动、钩爪抽动），消灭背景木桩。攻击落在对手的附属物上（法器、坐骑、护盾、召唤物、手中兵器）时，持有者同拍先试图阻止（格挡、回拽、闪避），被击中时身体随之受力（偏头、后仰、踉跄）。
  - 招式首次出现写 `【招名】首现：` 并用一句复述主色、实体材质与信号色位置；后续镜头只写招名。每个人物、物体与招式全片只用一个名字，不换同义词。
- **运镜动力学与镜间 HANDOFF**：
  - 按当前拍点的戏剧任务选择焦段与运动（见 [structures.md](references/structures.md)）：微距特写收紧蓄力（地标或主光虚化为背景光斑），中景稳机位拍清全身发力与残心，越肩或侧跟拍高速换位，贴地仰拍或超广角拉升兑现巨物尺度并框入永久地标。
  - **旋向解耦**：画面同时存在旋转特效与环绕运镜时，分别写死俯视旋向（如风暴逆时针、镜头顺时针）并锁死人物朝向，防人物原地自转冒充镜头环绕。
  - **剪辑节奏**：镜头节奏与交手密度同步，交锋段约每 `0.8–1.5s` 切一个镜头，机位始终在运动，慢推慢摇只留给开场与收势。连贯靠动作匹配剪辑：切在动作中途（挥到一半、飞到一半、跃到空中），下一镜从同一动作的下一瞬接上，切换前后画左画右关系与运动方向不变。
  - **HANDOFF 与最后一帧**：多镜段落每镜结尾写明双方终态位置与姿态（站／跪／倒）、关键物体的存在与数量（消失的写 `不再存在`）、仍在运动的事物、累积战损与切镜引子（掠过前景的碎屑／刀光或下一拍起手）；末镜用「最后一帧」取代 `HANDOFF`，列全最终定姿、全部留存痕迹与原位地标。

## 6. 反推负面约束与交付核验

**原则：负面词是本段锁定的镜像防线，只拦截本段真实存在的退化风险。**

形制、存在状态与机位这类错误先在正文用正面描述修正（应有的部件、`[部位]空无一物`、机位所在一侧），负面词只作补充；只写 `禁止 X` 或 `不是 X` 会把 X 带进画面。

从前五步设定逐组反推负面提示词，组间用分号分隔：

1. **视效与色彩退化**：本段各招式的具体退化形态（白雾、平面光圈、细线、黑色贴片、均匀火球）；双方颜色互换、对手全身单色涂抹、分账表外的杂色光。
2. **力学与表演违例**：主角背对对手出手、原地站桩、对空乱挥、换手持兵或护甲换边、超出防御词表的动作（如小体型硬扛巨爪）；对手轻飘无重量、挨打无反应、换造型、只在背景游荡不交手；变身画成连续融化变形。
3. **因果与空间违例**：门控结果抢跑（未触先倒、未触先碎、合鞘前提前爆裂）、战损与碎甲复原、永久地标被毁。
4. **镜头与时间病态**：整段慢动作、整幅画面定格死帧、多镜段固定机位死拍、镜头无目的来回摇摆、人物原地转圈代替镜头环绕。

交付前逐项核验：

- **粒度与结构匹配**：单镜精拍已删去无关全局行；多镜长段锁与分镜齐全；跨段组接已对齐每段上传素材与继承战损。
- **实体与触发闭合**：超凡与重火力档每条【招名】具备定量几何、复合层与 `不是 X，而是 Y`，在分镜里首现一次并绑定触发动作；写实物理档无凭空光效，每次重击写明接触点、形变与物理剥离物。
- **时空与痕迹守恒**：各镜时长相加等于总时长；每条 `CAMERA` 包含框定意图并保留永久地标（或微距光斑）；每条 `HANDOFF` 与下一镜开头咬合；战损只增不减并在最后一帧列全。
- **因果、命中与读法**：每一步的起因都能在上一步找到，距离、尺寸与数量逐步走通；每个时间片双方都有动作或受力；全局锁里写 `全片` 的状态与时间线上的事件不冲突，会变化的状态写成带时间范围的 `0–Ns`；每个命中片具备命中帧同步；逐句确认方向、朝向、姿态与物体存在只有一种读法。
