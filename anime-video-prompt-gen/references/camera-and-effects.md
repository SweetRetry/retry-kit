## 镜头景别

| 景别 | 英文 Prompt | 适用场景 |
|------|------------|---------|
| 大远景 | extreme wide shot (EWS) | 世界观建立、环境交代、史诗感开场 |
| 远景 | wide shot (WS) | 场景全貌、人物与环境关系 |
| 全景 | full shot (FS) | 展示人物全身、动作场景 |
| 中景 | medium shot (MS) | 对话场景、日常互动 |
| 中近景 | medium close-up (MCU) | 情感表达、角色反应 |
| 近景 | close-up (CU) | 面部表情、情绪高潮 |
| 特写 | extreme close-up (ECU) | 眼神、关键道具、微表情 |
| 过肩镜头 | over-the-shoulder shot (OTS) | 对话、对峙、跟随视角 |
| 俯拍 | high-angle shot / bird's eye view | 渺小感、全局、战场俯瞰 |
| 仰拍 | low-angle shot / worm's eye view | 压迫感、权威、角色气场 |
| 荷兰角 | Dutch angle / tilted shot | 不安、紧张、心理扭曲 |

## 镜头运动

| 运动 | 英文 Prompt | 效果说明 |
|------|------------|---------|
| 推镜头 | push in / dolly in | 聚焦、紧张感递增 |
| 拉镜头 | pull out / dolly out | 揭示环境、释放压力 |
| 横摇 | pan left/right | 环境扫描、跟随运动 |
| 纵摇 | tilt up/down | 仰望展示、俯视全貌 |
| 跟拍 | tracking shot / following shot | 跟随角色移动、沉浸感 |
| 环绕 | orbit shot / 360° rotation | 角色展示、戏剧性增强 |
| 摇臂 | crane shot / jib shot | 从低到高的壮观展示 |
| 手持 | handheld / shaky camera | 紧迫感、真实感、追逐 |
| 稳定器滑移 | gimbal smooth glide | 流畅穿越、梦幻感 |
| 急速推进 | crash zoom / snap zoom | 震惊、发现、喜剧效果 |
| 无人机视角 | drone shot / aerial sweep | 宏大场景、追逐、航拍 |
| 慢动作 | slow motion / 120fps slow-mo | 关键动作、情感放大、战斗细节 |
| 延时 | time-lapse | 时间流逝、环境变化 |

## 转场方式

| 转场 | 英文 Prompt | 适用场景 |
|------|------------|---------|
| 硬切 | hard cut / straight cut | 快节奏、动作场景 |
| 淡入淡出 | fade in / fade out | 开场、结尾、时间跳跃 |
| 交叉溶解 | cross dissolve | 平滑过渡、回忆 |
| 擦除 | wipe transition | 场景切换、平行叙事 |
| 匹配剪辑 | match cut | 相似形状/动作连接两个场景 |
| 跳切 | jump cut | 时间压缩、不安感 |
| 闪白 | flash white / whip to white | 爆炸、觉醒、闪回起始 |
| 闪黑 | smash to black | 悬念、突然终止 |
| 物体遮挡 | object wipe / pass-behind | 自然过渡、物理遮挡 |
| 缩放穿越 | zoom through / seamless zoom | 微观到宏观、维度穿越 |

## 特效类型

| 特效 | 英文 Prompt | 用途 |
|------|------------|------|
| 粒子效果 | particle effects (sparks/embers/dust) | 战斗火花、灵气粒子、灰尘 |
| 能量光环 | energy aura / power glow | 觉醒、蓄力、力量展示 |
| 元素特效 | elemental effects (fire/water/ice/lightning) | 法术、招式、自然力 |
| 速度线 | speed lines / motion blur streaks | 快速移动、战斗冲击 |
| 冲击波 | shockwave / impact ring | 爆炸、撞击、力量释放 |
| 魔法阵 | magic circle / runic formation | 咒术、召唤、结界 |
| 残影 | afterimage / motion ghost | 高速移动、分身 |
| 碎裂 | shatter effect / breaking apart | 破坏、突破、崩塌 |
| 发光文字 | glowing text / floating characters | 咒语、系统提示、预言 |
| 时间停滞 | time freeze / frozen moment | 关键瞬间、审视全局 |

## 音乐节奏提示

在 prompt 中可附加的节奏/情绪标记，帮助 AI 理解动态节奏：

| 节奏 | 英文描述 | 场景 |
|------|---------|------|
| 史诗管弦 | epic orchestral, dramatic crescendo | 战斗高潮、觉醒、飞升 |
| 古风悠扬 | traditional Chinese instrumental, guzheng/erhu melody | 古风日常、回忆、山水 |
| 电子节拍 | electronic beat, synth-driven rhythm | 都市战斗、追逐、科幻 |
| 钢琴抒情 | soft piano, emotional melody | 告白、离别、心理独白 |
| 紧张弦乐 | tense strings, suspenseful score | 悬疑、追踪、倒计时 |
| 寂静无声 | silence / ambient noise only | 震撼前的静默、孤独 |
| 渐强爆发 | build-up to drop, rising intensity | 蓄力到爆发的过渡 |
