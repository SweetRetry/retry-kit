# Seedance 2.0 生视频 Prompt

## 交付合同

一份 prompt 对应一次 **4–15 秒 generation**。一次 generation 可以是一个连续镜头，也可以是在这段时长内完成的多镜序列；需要多次 generation 时，分别交付自包含 prompt，并在相邻 prompt 中重复必要的承接状态。

本 skill 只使用当前任务附带或明确允许读取的意图、文字、图片、视频、音频与命名资产。输入可以是一个明确想法，也可以已经包含生成段、镜头与时间码。

本 skill 的前提是视频媒介已经由用户或当前任务确定。需要先根据网站产品属性、页面职责和运行约束决定
是否使用 background video 时，不采用本合同。

输入合法时，最终回复只包含可直接粘贴的多行自然语言 prompt。生成时长、画幅、上传文件等由入口字段承载；prompt 与这些字段一致，正文只写会改变画面或声音的内容。输入存在无法执行的时长、时间码或素材职责冲突时，先返回具体冲突与需要修正的信息。

## 执行步骤

### 1. 定界每次 generation

先确定用户要交付的一次或多次 generation，以及每次要表达的内容。

- 已给出生成段或本地时间码时，把该划分视为权威输入：每段从 `0s` 开始，时间码连续、首尾相接，末点等于该次 generation 的时长。
- 只给出一个镜头意图或短视频想法时，按叙事必要性自行确定一次 generation 的边界。
- 内容超过 15 秒且没有现成划分时，在叙事断点拆为多次 generation；每段保留可独立理解的起点、变化和结束状态。

完成标准：已列清所有 generation；每次时长均为 4–15 秒；已有划分和时间码被原样对齐。任一条件不成立时，已指出准确冲突并停在本步。

### 2. 提取生成约束

从当前上下文提取会直接改变生成结果的约束：主体身份、造型、场景、道具、影像气质、构图、动作、运镜、节奏与声音。上下文带有稳定、可解析的 `@资产名` 时原样引用，并写清它控制什么；没有命名素材时，直接用文字描述同一组生成约束，后续步骤保持不变。

只保留决定生成成败的最小约束集。每份命名素材写清素材类型、控制职责、必须保留的锚点、允许变化与作用范围。

按素材内容分配默认职责：

- 角色图控制身份、脸部、发型、体型、服装与持物；姿势、表情、背景、光线和构图随当前镜头变化。
- 场景图控制空间结构、时代、关键布景与主光方向；主体和镜头动作随当前设定变化。
- 风格图控制材质、色彩、光影与摄影或渲染气质；具体内容和布局随当前设定变化。
- 分镜图控制当前镜头的景别、构图、运镜与画面文字；正式身份、场景和影像气质保持优先。
- 动作视频控制动作路径、身体节奏、接触关系与速度；运镜视频控制摄影机路径、机位、节奏与焦点变化。使用特定片段时标明时间段。
- 音频控制明确指定的音色、对白、旋律、节拍、环境声或 Foley；关键声音绑定到可见动作点。

每个控制维度指定一个主来源。多个输入共同控制同一维度时，写明优先级或各自作用的镜头；冲突依次服从用户对当前成片的明确要求、主体与关键物体身份、当前动作和空间逻辑、场景与道具结构、影像气质与氛围。

用户给出导演、艺术家或作品的风格参考时，先把参考转译为当前视频的五类具体决定：光影与反差、色彩与明暗、镜头行为、构图与空间、时间与运动节奏。只保留该参考确实改变的维度，服从用户指定的参考强度，并按稳定设定或时段变化分别写入既有字段；不得只追加名字或抽象风格句，也不得因风格参考自行复刻某个现成片段的主体、调度或镜头序列。

完成标准：每项约束都能在当前上下文定位并直接改变生成结果；每个控制维度只有一个主来源，冲突已有明确优先级；风格参考已转译为当前视频的可观察决定；所有 `@资产名` 都真实可解析。

### 3. 分配理解预算与镜头形态

先列出观众必须理解的叙事节拍，再分配镜头和时间。每个新规则、目标、地点、道具功能或胜负条件都要获得“建立 → 可见验证 → 结果停留”的可读时间；剪辑和转场不占用这段理解时间。短段优先围绕一个核心机制或一条因果链，结尾承担一个主要 payoff。时间不足时，删除或合并次要概念，为必要节拍保留可读时长。

以剪辑点定义镜头。相邻节拍能在同一机位、空间和连续运动中清楚完成时使用单镜；机位、时空、视点或主要观看任务发生明确切换时使用多镜，并写明硬切或转场。时长约束作用于整次 generation，不按固定秒数机械切镜。

完成镜头判断后，把整次 generation 按少量关键变化点拆成首尾相接的 timeline beat。timeline beat 是最终 prompt 的基本时间单位；镜头只作为 beat 的关系属性：首段写“连续镜头起始”或“新镜头起始”，延续时写“承接同一镜头”，发生剪辑时写“硬切至新镜头”或具体转场。不要再为一个或多个 beat 添加 Shot 外层容器。

镜头时长服从叙事节拍。内容极短时，用可读的起势、反应或收尾停留补足 4 秒；多镜时各镜头时间首尾相接，总和等于本次 generation 时长。只在必须对齐现成素材、音乐节拍或精确动作点时使用小数秒。多次 generation 连续交付时，后一段开场继承前一段的结束状态、速度、屏幕方向、光线与声音。

完成标准：每个必要节拍都有可读时间；每个剪辑点都有叙事或节奏作用；时间码从 `0s` 连续到 generation 末点，总时长为 4–15 秒。

### 4. 写成可生成的状态变化

每个镜头只承载一个主要观看任务，以及一个主动作或一条连续因果动作链。按时间顺序完整写完一个 timeline beat，再进入下一个 beat；不要在摄影机、主体、环境等字段中分别维护跨越多个 beat 的平行时间轴。每个 beat 使用速度、方向、幅度、构图、数量和状态等可观察属性，写清：

1. 主体从什么可见状态开始，如何行动、反应并到达什么结束状态。
2. 摄影机从什么与目标影像语法一致的机位开始，沿什么空间路径、以什么速度移动，结束时形成什么景别或构图。
3. 光影、色彩和环境状态如何随主体、摄影机、情绪或风格机制变化，并强化动作、空间或氛围。
4. 当前入口支持原生声音时，对白、环境声、Foley 与音乐如何在动作点出现、增强或停止。

使用肯定、可观察的目标状态描述模型应当生成、保持或改变什么。例如写“全程缓慢稳定推镜，主体保持在画面中央”，而不是只列出需要避免的失败现象。

让动作遵守目标世界的因果与运动规则。普通身体运动写清位移、转身、接触和持物变化；超现实、图形化、抽象或风格化运动写清触发条件、变化过程与结束状态。静止镜头也要明确稳定项，只保留服务于当前风格和观看任务的必要微动。

为当前视频选择一套空间与视点规则：空间如何连续，镜头如何移动，遮挡、反射、穿越或形变在什么条件下发生。每次状态变化沿用这套规则；规则本身改变时，写清触发条件、可见过程和新的稳定状态。

为当前视频选择一套光色与细节规则。光影可以响应空间、动作、情绪、声音或其他风格机制；亮度、色偏、阴影和高光发生变化时，写清触发条件与可见结果。焦点、清晰度和信息可读性始终服从当前时段的主要观看任务，次要区域按所选风格的方式退后。

需要原生声音时，分别安排对白、环境声、动作音效与音乐，把关键声音绑定到动作点，例如接触时出现 Foley、对白结束后音乐再抬升。上下文附带声音素材时，只复用明确指定的音色、旋律、节拍或声音质感。

让细节密度服从生成成败。锁定素材职责、主体身份、一个主动作、起止状态、摄影机路径、关键空间关系、光色、运动规则和连续性锚点；选择性加入一个环境响应、一项焦点变化或少量声音事件。需求开放时，为非关键微动作和背景填充保留发挥空间；需求明确时，完整保留动作阶段、节奏、机位与素材职责。

每个镜头设置一个情绪任务，通过表演节奏、动作力度、镜头响应、光色变化或声音反差完成。复杂动作只要仍属于一条因果链，就按可见阶段推进；出现多个主要观看任务时，在机位、时空、视点或节奏的自然断点划镜。

完成标准：每个镜头都有“起始状态 → 动作与反应 → 结束状态”；每个 timeline beat 已完整交代该时段的主体、摄影机、环境和必要声音；空间、光色和运动变化遵守当前视频选定的规则，规则切换已有可见触发与结果；观看重点随时段清楚变化；情绪任务能被直接看见或听见；每项保留细节都影响生成结果。

### 5. 通过双重质量门槛

**状态交接。** 按时间码逐段追踪左右手、持物、姿态、位置、受力、服装、关键道具、HUD 或计数与空间关系。前一个 timeline beat 的结束状态直接成为后一个 beat 的起始状态；释放、交接、放下、保持和数值更新都有可见过程。同一只手只承担一个可执行动作，道具的出现、移动与消失都有画面内原因。击杀、消失、破坏、变形或状态切换写清最终可见状态、残留物与后续可恢复性，过程特效之后继续交代结果。难以用一句可见动作解释的交接，以简化动作链解决。

**电影表现力。** 状态交接只作为内部门槛。修正冲突后，prompt 只保留决定生成成败的连续性锚点，把主要篇幅留给情绪变化、表演节奏、观看重心、接触反馈、镜头张力与视听反差。动作发生后保留可读反应；情绪通过表情、姿态、动作力度、镜头、光色或声音完成，而不是只写抽象情绪词。使用风格参考或器材术语时，暂时移除名称复核；剩余决定仍须形成清楚的观看方法、运动节奏和光色逻辑。

完成标准：每个时间边界的状态都能逐项对账；每个镜头仍有清楚的情绪变化和观看重心；连续性说明没有压过最终画面表现。

### 6. 渲染最终 prompt

输出结构是稳定合同。上下文带有命名素材时先输出“参考素材 / References”组，否则省略；随后输出一个“全局设定 / Global Setup”组，再按时间顺序直接排列 timeline beat，不输出 Shot 外层标题。中文与英文使用下列 canonical 标题和 label；其他语言按相同语义直接翻译并在整份 prompt 中保持唯一译法，不自由改写同义标题。

参考素材组使用 `## 参考素材` / `## References`，每项素材单独一行，固定写成 `@资产名：素材类型；控制职责；必须保留的锚点；允许变化；作用范围。` 的目标语言版本。

全局组使用 `## 全局设定` / `## Global Setup`，并按以下顺序输出：

1. `视频意图：` / `Video Intent:`：整段的起止变化和最终记忆点。
2. `主体与造型：` / `Subject and Appearance:`：身份、数量、关系、稳定外观、服装、配饰和持物。
3. `场景：` / `Setting:`：地点、时间、天气和稳定空间关系。
4. `影像风格与调色：` / `Visual Style and Grading:`：互补风格、镜头感、景深、成像或渲染质感、主色、冷暖、饱和度和反差。
5. `运动基调：` / `Motion Baseline:`：动作与运镜贯穿整段的速度、幅度、连续性和运动规则。
6. `连续性锚点：` / `Continuity Anchors:`：跨时段必须稳定的身份、道具、空间、光色和屏幕方向。
7. `声音设计：` / `Sound Design:`：需要原生声音时的对白、环境声、Foley、音乐和混音关系；不需要声音控制时省略。

每个 timeline beat 使用二级 Markdown 标题，固定写成“时间范围｜与前一时段的镜头关系｜景别”的目标语言版本，例如 `## 0–3s｜连续镜头起始｜低机位近景` 或 `## 0–3s | Continuous Shot Begins | Low Close-up`。正文按以下顺序输出：

1. `摄影机：` / `Camera:`：机位起点、路径、速度、承接状态和结束画面。
2. `构图与光线：` / `Composition and Lighting:`：主体位置、空间层级、注意力路径和光线变化。
3. `主体动作：` / `Subject Action:`：起始状态、主动作、可见反应和结束状态。
4. `环境运动：` / `Environment Motion:`：只强化主动作、空间或氛围的环境变化。
5. `动作强度：` / `Action Intensity:`：静止、微动、中动或剧烈及其连续性。
6. `焦点：` / `Focus:`：只有对焦保持、rack focus 或景深变化承担叙事作用时出现。
7. `声音：` / `Sound:`：只有声音需要与本时段动作精确同步时出现。
8. `锚点变化：` / `Anchor Change:`：只有本时段合法改变全局锚点时出现。
9. `转场：` / `Transition:`：只有本时段结尾确实发生剪辑或片尾处理时出现。

全局信息只写一次；全局组保持六个必填字段和一个可选声音字段。每个时段的摄影机、构图与光线、主体动作、环境运动和动作强度始终出现，其余字段按明确适用条件省略；不得用一个字段替代另一个字段，也不得新增同义 label。用户用排除项表达边界时，优先把它转换成语义等价、可见或可听的正向状态，例如精确数量、唯一观看主体、整洁背景、单一连续镜头或实际存在的声音层。转换后必须逐项保留原约束；无法用正向状态等价表达的 hard exclusion，在最相关字段保留一句最小、明确的排除约束。不主动扩写 negative prompt、排除清单或补充控制段。

渲染前先确定目标语言：优先服从当前会话或系统明确给出的输出语言约定；该约定未指定具体语言或要求随用户时，服从用户明确指定的语言，否则沿用用户当前语言。标题、label、镜头关系、景别、动作强度、转场和字段值全部使用目标语言；资产引用、时间码、专有名词及必须保持原样的 model / camera / sound 术语除外。使用该语言惯用的大小写、标点和排版，但不改变上述结构、字段顺序与适用条件。

一个时段内只写该时段发生或保持的可见、可听状态；关键维度没有变化时，用目标语言自然表达延续。所有时间码连续、首尾相接并覆盖整次 generation。相邻时段没有剪辑点时，用目标语言明确表达同一镜头延续；只有出现剪辑点、时空或视点切换时才声明新的镜头关系，不把连续动作阶段误写成切镜。末段结束在明确画面。

严格区分职责：素材组只写素材与控制维度的映射；视频意图只写整段时间变化与记忆点；主体、造型和场景只写稳定内容；运动基调只写贯穿整段的运动规律；时段标题只声明时间范围、镜头关系与景别；时段正文只写该时段发生或保持的状态。使用高信息密度的完整短句，一行承担一种职责。

默认让全局组保持与约二百五十至五百个中文字符相当的信息密度，每个时段保持与约一百二十至二百五十个中文字符相当的信息密度；其他语言按自然表达所需长度调整，不机械套用中文字数。目标工具存在 prompt 限制时，依次压缩风格修饰、次要环境运动和非身份类素材说明，完整保留动作时序、素材职责、连续性与情绪任务。

完成标准：每份 prompt 都自包含、可直接粘贴；timeline beat 的时间码连续且末点匹配 generation 时长；每个 beat 已完整写完再进入下一时段；镜头延续与剪辑关系明确；所有 `@资产名` 可解析；标题、label、字段顺序与适用条件符合稳定合同；hard exclusion 没有在正向改写中丢失；所有结构文字已通过目标语言的单语校对；最终回复没有 prompt 之外的说明。
