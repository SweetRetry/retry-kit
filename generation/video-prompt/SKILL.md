# Video Prompt

## 交付合同 (Delivery Contract)

- **单次 Generation 定界**：一份 Prompt 对应目标入口的一次 **generation**（可为连续单镜头或多镜序列）；需多次 generation 时分别交付自包含 Prompt，并在相邻段重复必要承接状态。
- **素材与媒介约束**：只使用任务附带或明确允许读取的意图、文字、图片、视频、音频与命名素材；视频媒介必须已由用户或当前任务确定。
- **模型 Reference 优先**：先确认目标模型与版本，再读取对应 reference。专属 token、任务模式、时间标记与排版以 reference 为准。

| 目标模型 | Reference 规范文档 |
| :--- | :--- |
| **Seedance 2.0** | [Seedance 2.0](references/seedance-2.0-prompt.md) |
| **Seedance 2.5** | [Seedance 2.5](references/seedance-2.5-prompt.md) |
| **MiniMax-H3** | [MiniMax H3](references/minimax-h3-prompt.md) |

输入可执行时，最终回复**只输出可直接粘贴的 Prompt**；存在冲突时仅返回具体冲突项与需补充信息。

## 1. 定界 Generation (Boundary & Chunking)

1. **核心要素**：明确单次 generation 的起点状态、主动作演进与结束稳定态。
2. **时间线切分**：保留用户的叙事划分；超出单次模型可读时长时，在**因果转折或场景断点**处拆分，确保每段自洽并为下一段留下可继承状态。
3. **跨段承接锚点**：相邻 generation 交接时，必须在开头重复**主体身份、持物、空间坐标、运动速度/方向、屏幕朝向、光线与声音基调**。

---

## 2. 映射命名素材职责 (Asset Role Mapping)

按 reference 的 token 引用每份命名素材，严格锁定控制职责与作用范围：

| 素材类型 | 核心控制职责 | 允许的变化范围 |
| :--- | :--- | :--- |
| **角色素材** | 锁定角色身份、五官特征、体型与稳定服饰外观。 | 允许姿态变化、微表情、局部视线与动态位移。 |
| **场景素材** | 锁定空间结构、透视关系、地理特征与主光源方向。 | 允许随摄影机移动产生的视差与天气微动。 |
| **风格素材** | 锁定渲染材质、色彩基调、颗粒度与胶片/影像气质。 | 转译为当前镜头的具体光影反差与质感。 |
| **动作/运镜参考** | 仅继承指定的动作路径、运动节奏或摄影机轨迹。 | 允许主体与背景内容完全不同。 |
| **音频素材** | 继承指定的音色、旋律、BGM 节拍、对白或环境底噪质感。 | 允许根据画面情绪起伏调节响度。 |

> [!NOTE]
> **冲突仲裁优先级**：成片明确要求 ➔ 主体/关键道具身份 ➔ 当前动作与空间物理逻辑 ➔ 场景 ➔ 风格。每个控制维度指定唯一主来源。

---

## 3. 确立全局稳定设定 (Global Invariants)

在描述具体时间节拍前，先声明全片贯穿、无需重复计算的稳定语义：
- **核心意图与情绪基调**；
- **主体身份与不可漂移的特征/外观**；
- **场景空间几何与主光环境**；
- **统一的运动速度与声音连续性锚点**。

> 后续时间线中**只写发生变化的内容**；仅在叙事断点或新镜头开头重申必要锚点。

---

## 4. 镜头语法与叙事节拍 (Camera Grammar & Pacing)

1. **可读时间窗口**：每个新目标、规则、地点或道具功能，必须留足 **`建立 ➔ 可见验证 ➔ 结果停留`** 的观看时间；时间不足时果断删除次要概念。
2. **单镜 vs 切镜裁决**：
   - **单镜头**：相邻节拍能在同一机位、空间与连续运动中闭环时，优先保持单镜运镜；
   - **切镜/转场**：机位、时空、视点或观看焦点发生明确跃迁时才切镜。
3. **因果连续性**：多镜头交接时，**前一段的结束状态即为后一段的起始状态**；动作、持物、受力、位移与声音变化必须具备物理因果。

---

## 5. 写成六维物理可观测状态变化 (Observable State Vectors)

按发生顺序逐一描述物理现实中**摄影机能拍到、麦克风能听到**的变化：

1. **主体动作 (Subject Dynamics)**：从何种状态开始，以何种速度、幅度做何种位移/转身/接触/持物，动作导致了什么稳定结果；情绪一律外化为姿态、微表情与呼吸节奏。
2. **摄影机运动 (Camera Trajectory)**：机位高度、拍摄角度、运镜轨迹（Push/Pull/Pan/Tilt/Truck/Pedestal/Roll/Orbit）及景深焦点变化。
3. **空间与环境响应 (Environment Response)**：光影、天气、粒子、背景元素如何响应主体动作与情绪变化。
4. **声音与台词标记 (Audio & Voice Tokens)**：对白、环境声、Foley 拟音、音乐何时出现、渐强或静音，严格绑定时间段。
5. **前后状态承接 (State Continuity)**：上一状态如何自然延续，转场具备何种过渡逻辑。
6. **肯定式描述 (Positive Framing)**：使用明确可见的目标状态；无法转为正向的排除项仅在最相关处做最小限制。

---

## 6. 输出渲染与压缩检查 (Rendering & Quality Gates)

1. **模板与排版**：按 target reference 的素材 token、任务触发词、时间写法输出；无特定模板时按 **`素材映射 ➔ 全局设定 ➔ 顺序状态变化`** 输出多行结构。
2. **压缩与瘦身原则**：
   - 先删除无效形容词、重复风格词与次要环境噪音；
   - 坚决保留：**素材映射 Token、主体身份锚点、关键动作位移、摄影机轨迹向量、时序承接状态**。
3. **最终核验**：确保 Prompt 中**不含任何无法转化为画面/声音物理特征的废话**。
