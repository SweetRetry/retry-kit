# Video Prompt

## 交付原则：只给可直接粘贴的 Prompt

- **一次只生成一段 (Single Generation)**：一份 Prompt 对应目标入口的一次生成（可以是一个长单镜，也可以是多镜连续段落）；超出时长时分段交付，两段之间必须重复交接状态。
- **只用确定的素材**：严格按照给定的素材和指定的媒介生成，绝不凭空捏造未授权的素材。
- **看菜下饭（Reference 优先）**：从需求与上下文确定目标模型，无法确定且会改变写法时再询问。素材解释、信息顺序、格式及能力限制服从目标模型 reference；主文档提供其余内容与连续性原则：

| 目标模型 | Reference 规范文档 |
| :--- | :--- |
| **Seedance 2.0** | [Seedance 2.0](references/seedance-2.0-prompt.md) |
| **Seedance 2.5** | [Seedance 2.5](references/seedance-2.5-prompt.md) |
| **MiniMax-H3** | [MiniMax H3](references/minimax-h3-prompt.md) |

输入明确时，**最终回复只输出可直接粘贴的 Prompt**；冲突先按用户最新要求和目标模型 reference 处理，仅在仍需用户取舍时询问。

---

## 1. 单次生成定界：一次只生成一段

1. **核心要素**：交代清楚这一段从什么状态开始、主动作怎么演进、结束时的构图与运动状态；连续动作不要求停住。
2. **在有因果转折处切断**：叙事超出单次生成时长时，选在**动作暂停或场景切换**的地方切断，保证每一段自洽，并给下一段留好接棒状态。
3. **两段交接把话说全**：前一段结束、后一段开始时，必须在开头重申**人物是谁、手里拿着什么、人在哪、朝哪边走、主光和声音基调**；如果下一镜是连续动作接力，前镜尾帧必须**保留向前冲的运动惯性动势**，千万别让模型提前刹车定格。

---

## 2. 参考素材分工：说清管什么，更要说清不管什么

引用素材时，不仅要让模型知道该学什么，还要给模型划清边界，**严防多图参考互相争权、串色跑偏**：

| 素材类型 | 核心管什么 (职责) | 允许变什么 (自由度) | 严禁管什么 (排他防污染防线) |
| :--- | :--- | :--- | :--- |
| **角色素材** | 锁定五官、长相、体型与固定服饰。 | 允许做新动作、变表情、转头与位移。 | 严禁覆盖剧本指定的当前动作与站位。 |
| **场景素材** | 锁定空间结构、透视关系与主光方向。 | 允许摄影机移动带来的透视与天气微动。 | 严禁污染人物自己的肤色、衣服颜色与动作。 |
| **风格素材** | 锁定质感、色彩基调与胶片/画面气质。 | 转译为当前镜头的具体明暗与表面质感。 | 严禁改变人物或道具的几何结构与动作路线。 |
| **动作/运镜参考** | 只学指定的动作路线、节奏或摄影机走位。 | 允许主体和背景跟参考完全不同。 | 严禁改变角色的长相五官、发型与衣服。 |
| **音频素材** | 继承指定的音色、旋律、对白节奏或底噪。 | 允许随画面情绪微调音量大小。 | 严禁强行打乱画面既定的动作节拍点。 |

> [!NOTE]
> 多图参考时，主动在 Prompt 里加一句隔离声明（例如：“动作参考图仅供姿势与运镜参考，禁止参考其五官与服饰”），彻底解决模型多图打架的问题。

---

## 3. 拍摄制度与风格锁 (STYLE LOCK)：先立规矩，不准跑偏

确定贯穿片段的拍摄制度与环境基准；在 Prompt 中的出现顺序按目标模型 reference：
- **风格锁 (Style Lock)**：把抽象感觉换成可见的物理特征（是 35mm 实拍还是手机手持跟拍？画幅比例多大？有没有空气丁达尔尘雾？色温冷暖？是胶片噪点还是数码感？）；
- **必要排除项**：只表达用户要求或避免实际冲突所需的排除项；位置及表达方式按目标模型 reference，不强制添加固定负向清单；
- **主体与空间锚点**：人物固定外貌、场景大空间与主光源方向。

---

## 4. 镜头节奏：给模型留足反应时间

1. **留够看清的时间**：镜头里出现新道具、新地点或新动作时，必须留足 **`看清 ➔ 发生 ➔ 停留反馈`** 的时间；时长不够就果断删掉次要花哨动作。
2. **一镜到底还是切镜**：
   - 能在同一个机位和连续运动中交代清楚的，优先**一个长镜头推到底**；
   - 视点、时空或关注焦点彻底变了，再**明确切镜**。
3. **因果连续**：多镜头组接时，**前一镜停在哪，后一镜就从哪接**；谁打谁、谁受力、谁倒下，物理动作必须严丝合缝。

---

## 5. 按时间写清 6 件事（必须看得见、听得到）

按发生顺序逐一描述摄影机和麦克风能记录到的物理变化：

1. **主体动作（写出受力因果）**：别写“激烈搏斗、震撼碰撞”这种空词。写出**施力方向/接触点 ➔ 受力物怎么变形 ➔ 人体重心怎么后倾 ➔ 脚在地上滑出什么擦痕**；机械变形写清**触发 ➔ 脱扣 ➔ 齿轮咬合翻折 ➔ 卡死就位**。情绪全外化为微表情、抓握细节与呼吸节奏。
2. **摄影机运动**：机位高低、角度、运镜轨迹（推/拉/摇/移/俯冲/环绕）与焦点虚实。
3. **环境与物理反馈**：光线、天气、扬尘、碎石如何响应人的动作。
4. **声音与拟音**：声音是空间和重量的探测器：用碰撞声交代物体有多重，用环境回响交代空间有多大，局部动作与声音（抛掷-蓄能-翻折-锁死）一一咬合；对白和音效严格对齐时间段。
5. **前后状态承接**：前一状态怎么顺畅过渡过来，结尾的构图与运动状态如何交接。
6. **多说正面话**：清楚描述模型应当拍出什么画面，别写一长串复杂的反向绕弯话。

---

## 6. 挤干水分与最终检查

1. **模板与排版**：严格按照目标模型的 reference 格式（Token、时间轴标记）输出。
2. **挤干水分原则**：
   - **信息分流**：仅省略当前模型与参考模式能够可靠承载的信息；故事板是否需要逐镜补齐动作、运镜与空间，按目标模型 reference 判断；
   - 坚决删去“电影感、绝美、史诗级”等空洞修饰词；
   - 保留当前任务必要的素材映射、身份锚点、动作过程、机位与时序；没有参考素材或相关动作时不凑齐这些项目。
3. **最终核验**：确认整段 Prompt 里**没有哪怕一句话是摄影机拍不到、麦克风录不到的文学废话**。
