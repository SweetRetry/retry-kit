# Video Prompt

## 交付合同

一份 prompt 对应目标入口的一次 **generation**。一次 generation 可是连续镜头或多镜序列；需多次 generation 时分别交付自包含 prompt，并在相邻段重复必要承接状态。只使用任务附带或明确允许读取的意图、文字、图片、视频、音频与命名素材；视频媒介必须已由用户或当前任务确定。先确认目标模型与版本，再读取对应 reference。

reference 决定模型专属的素材 token、可用性、任务模式、时间写法、声音/文字标记与排版；与主文档冲突时 reference 优先。输入可执行时最终回复只含可直接粘贴的 prompt；存在冲突时只返回具体冲突与需补充的信息。

## 1. 定界 generation

确定每次 generation 的起点、主要变化、结束状态。用户给出生成段/时间线时保留其叙事划分，时间编码采用目标 reference 支持的方式。内容超过单次可读时长时在因果或场景断点拆分，每段独立理解并为下一段留下可继承结束状态。相邻 generation 承接时重复身份、持物、位置、速度、屏幕方向、光线、声音等必要锚点。

## 2. 映射素材职责

用"主体 + 动作或事件"确定内容基础，只保留会直接改变成片的场景、道具、风格、构图、运镜、节奏、声音约束，按 reference 的 token 引用每份命名素材并写清控制职责、必须保留锚点、允许变化、作用范围。角色素材控身份与稳定外观；场景控空间结构与主光；风格控材质、色彩、影像气质。动作/运镜视频只继承指定动作路径/节奏/摄影机行为；音频只继承指定音色/旋律/节拍/对白/环境质感。多张素材定义同一对象时写清各自视角与同一身份；对象数量由故事决定。每个控制维度指定一个主来源；冲突时优先用户对成片明确要求、主体与关键物体身份、当前动作与空间逻辑，再是场景、风格。风格参考转译为当前视频的光影、色彩、构图、镜头行为、运动节奏。

## 3. 确定全局稳定设定

在叙事节拍前确定只需写一次的稳定语义：整体意图与情绪、主体身份与不能漂移的外观或关系、场景空间与主光、统一视觉语言，以及贯穿全片的运动、声音、连续性锚点。后续只写发生的变化；只在叙事断点或新 generation 开头重申影响理解或稳定性的锚点。全局设定与时间内变化可按参考写法合并呈现，但不混淆职责。

## 4. 组织叙事与镜头

先列观众必须理解的节拍，再决定单镜或多镜。每个新目标、规则、地点、道具功能都要有"建立 → 可见验证 → 结果停留"的可读时间；时间不足时删除或合并次要概念。相邻节拍能在同一机位、空间与连续运动中完成时用单镜；机位、时空、视点或观看任务明确切换时才切镜或转场。按目标模型允许的时间/镜头组织方式顺序写少量关键变化，每段只承担一个主要观看任务与一条连续因果动作链。多镜或多段交接时前一段结束状态即后一段起始；动作、持物、位置、受力、道具、空间、声音变化都要有可见原因。

## 5. 写成可观察的状态变化

按发生顺序描述主体、摄影机、空间、光色、声音与前后承接。语义覆盖项（判断用）：主体从何状态开始、如何行动/反应到何状态；摄影机从何处观察、如何移动、成何构图；环境/光色/焦点如何响应动作、空间或情绪；对白/环境声/Foley/音乐何时出现、增强或停止；上一状态如何自然延续或合理解释转场。动作写位移、转身、接触、持物、速度、幅度、结果；情绪外化为表情、姿态、节奏、镜头或声音；静止画面明确稳定项与必要微动。用肯定、可见或可听的目标状态；无法转成正向状态的 hard exclusion 保留在最相关句。需求开放时为次要微动与背景填充保留空间；需求明确时完整保留动作阶段、节奏、机位与素材职责。细节只在它改变身份、连续性、主动作、关键空间关系、镜头、光色或声音时保留。

## 6. 渲染与检查

按 target reference 的素材 token、任务触发词、声音/文字标记、时间写法、自然语言模板输出；没有模板时按"素材映射 → 全局稳定设定 → 顺序状态变化"写简洁多行 prompt。排版只服务目标模型的可读性。检查素材可用且职责清楚、稳定设定与状态变化无混写、故事顺序与参考范围一致、关键状态能交接、镜头切换有叙事理由、声音文字绑定对应时段或动作。最终 prompt 只含会改变生成结果的内容。压缩时先删修饰语、重复风格描述、次要环境细节，保留素材职责、主体身份、稳定锚点、主要状态变化、镜头关系、连续性。
