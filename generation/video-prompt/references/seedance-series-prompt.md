# Seedance Series Prompt Reference

只在当前任务明确使用 Seedance 系列模型或入口时读取并应用本文件。核心的视频内容、timeline、连续性与输出结构仍服从 `video-prompt`；本文件只补充 Seedance 系列的 prompt 语法和入口边界。

## 入口边界

- 先确认当前任务使用的 Seedance 版本，不静默选择默认版本：

| 版本 | 单次 generation 时长 |
| --- | --- |
| Seedance 2 | `4–15s` |
| Seedance 2.5 | `4–30s` |

- 已给出的生成段或本地时间码必须落在对应版本范围内；内容超过单次上限时，按叙事断点拆成多次 generation。
- 只写“Seedance”而未明确版本，且版本差异会改变时长或可用能力时，先返回具体冲突与需要确认的版本，不自行按任一版本执行。
- 服从当前任务或入口提供的画幅、上传素材与其他参数，不把这些参数重复写进 prompt。
- 提示词正文只写会改变画面或声音的内容；入口参数与正文保持一致。
- 自然语言可以直接描述声音与文字。需要进一步区分内容类型时，再使用下列标记。

## 声音与文字标记

| 内容类型 | 标记 | 写法 |
| --- | --- | --- |
| 音乐 | `()` | 在圆括号内描述背景音乐 |
| 音效 | `<>` | 在尖括号内描述动作音效或环境音效 |
| 台词 | `{}` | 在花括号内保留角色说出的台词原文 |
| 字幕 | `【】` | 在方头括号内保留画面字幕原文 |

符号只区分内容类型，不替代自然语言中的时序、动作同步、音量变化、开始、停止和混音关系。严格区分台词、字幕与其他屏幕文字，必须准确出现的内容保持原文。

台词使用非中文时，按以下顺序声明：

`语言 → 必要的地区变体或口音 → 表达方式 → 说话人 → {台词原文}`

## 渲染检查

- generation 时长落在所选版本的范围内，时间码从 `0s` 连续到末点。
- 音乐、音效、台词和字幕使用与内容类型匹配的成对标记。
- 关键声音仍绑定到可见动作点或明确时间点。
- 字幕出现的时段同时写清位置和可读状态。
- 不把本文件的标记语法用于非 Seedance 入口。
