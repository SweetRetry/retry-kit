# Image Prompt

将意图转为单张画面可见的状态与关系，保留会改变生成结果的信息。

## 画面决策

按需选择，不凑齐全部维度：

- **主体与瞬间**：识别特征、穿戴、道具、动作阶段、表情与视线；多人时明确前后与遮挡。
- **构图与视角**：景别、机位、透视、主体位置、留白与焦点。
- **光线与色彩**：主光方向、软硬、阴影、冷暖及主体与背景的区分。
- **媒介与材质**：照片、绘画或渲染的具体特征，以及当前景别能看到的表面质感。
- **环境痕迹**：把情绪与氛围转为可见细节。

艺术家或电影风格转译为光影、色调与构图；删除没有可见落点的赞美词与分辨率口号。

## 参考与密度

- 资产设定图锁定识别与复用所需的不变量：五官、发型、衣服层级、材质与固有色。
- 有草图或分镜时，省略参考已明确且能可靠承载的构图与动作，仅补缺失的光影、质感与反差。
- 删除不改变结果的描述；次要背景保持最小假设。
- 正向描述应当看到什么；排除项交给目标入口支持的负向提示方式。

需求明确时直接写。只有抽象情绪且方向会明显改变画面时，先确认最重要的 1–2 个维度，其余作最小合理假设。

交付只含可直接粘贴的自然语言 Prompt，使用用户指定或目标模型适用的语言，不套方括号或表格。
