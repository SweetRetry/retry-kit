# Image Prompt

## 核心任务

把当前任务提供的想法、文字与参考素材分析为一组会实际改变生成结果的视觉决定，再组织成可直接交给 image generation model 的 prompt。先确定画面要表达什么以及任务重心，再按需处理主体与状态、场景与空间、构图与视角、风格、光色、材质、媒介和情绪。只锁定决定当前画面成败的内容，并按固定分组与 label 输出。

本 skill 独立运行，只使用当前任务提供、附带或明确允许读取的上下文。至少需要核心主体或视觉主题；缺失信息不会改变任务重心时作出最小假设，可能改变主体、关键关系、构图或视觉表现方向时向用户确认。完成标准：prompt 明确要生成什么、观众先看到什么、画面元素如何关联，以及哪些视觉表现让结果统一；所有决定互不冲突且没有无作用的约束。

## 无视觉上下文时先收敛方向

先判断当前输入是否已经提供足以决定画面的视觉上下文。存在参考图、明确媒介、成熟视觉规范，或主体、构图、光色与风格方向已基本成立时，直接编写 prompt，不重复询问。

只有题材、情绪或零散形容词，且不同视觉解释会明显改变最终画面时，先进入引导。按影响放大率检查尚未确定的决定：媒介与渲染、线条／边缘／体积、色彩与明度、光影、材质与细节。一个答案会同时改变多个维度或导向明显不同的成像结果时，优先询问。

每轮只提出 2–3 个最高影响问题，并保持以下结构：

```text
【已确认】
<后续保持的内容与视觉决定>

【当前视觉假设】
<一句话概括最有依据的视觉主轴>

【本轮待决】
1. <会实质改变结果的问题>
   推荐：<首选及其对画面的影响>
   备选：<2–3 个视觉结果真正不同的方向及各自代价>
```

推荐和备选必须来自当前任务的真实分叉，不按固定问卷遍历；能够从输入或素材判断的事实直接读取。收到回答后只重开受影响的视觉轴：相容决定继续保留，替换决定同步更新其连带关系，冲突决定先解决再继续。

用户明确要求直接出稿，或所有高影响决定已经清楚且相容时，采用当前证据最支持的方向并进入完整 prompt。只剩低影响细节时作最小假设，不继续询问。引导阶段只帮助收敛当前图片的视觉方向；最终交付合同始终是本 skill 末尾定义的完整 image prompt，不另行交付独立 Style Spec。

完成标准：高影响视觉决定已经清楚且相容；每项留白都不会改变任务重心或风格身份。

## 使用肯定指令

主 prompt 描述模型应当生成、保持或突出什么。用数量、位置、比例、密度、状态、色彩、材质和留白等可观察属性收窄生成空间。例如，用"画面唯一人物是一名剑士，独占中央轮廓"确定人物数量，用"背景开阔、道具稀疏、主体周围保留大面积留白"确定画面密度，用"人物双手自然垂放、五指清晰完整"表达手部要求。

主 prompt 承载期望出现的视觉内容与关系。参考边界使用正向归属描述，例如"人物身份沿用 @图片1，姿态、光线和构图按照当前画面设定生成"。安全与合规红线继续遵守系统规则，由系统层处理。

## 控制细节密度与模型自由度

逐项使用省略测试：删去这项信息后，模型是否仍能稳定生成用户真正关心的结果？不能则锁定，能则留给模型。

默认采用中等细节密度：锁定决定画面成败的视觉选择，把装饰空间留给生图模型。优先描述核心服饰、关键道具、主要空间层次和承担叙事作用的环境效果。

按以下优先级分配信息：

1. 必须锁定：核心主体、必要数量与关系、关键状态或动作、场景类型、主构图、主光色、风格方向和核心情绪。
2. 选择性锁定：一个次要动作或关系、二至四个环境线索、一至三个与当前景别相符的材质细节。
3. 留给模型：次要人物造型、非关键道具、背景填充、表面装饰、云层形状、普通植被和纯装饰性粒子。

用户需求开放时，优先提供清楚方向和适度留白，为模型保留合理想象空间。用户需求明确时，把用户明确给出的细节视为约束；只压缩互相冲突、超出所选景别可见范围或削弱主焦点的内容。用户明确要求高细节、设定还原、商业交付或像素级控制时，可以提高细节密度，并保持每条信息职责唯一。

每张图只设一个主焦点和一个记忆点。用户明确要求多个并行动作时按其要求组织；其他情况最多保留一个次要动作。人物数量影响结果时使用确切数字。广角远景描述轮廓、尺度与空间层次；特写画面优先呈现局部表情、材质与细节。

## 组织 Prompt 内容

### 视觉核心与记忆点

先用一句话明确画面的视觉核心：主体与什么环境、关系、尺度、动作、形式或反差共同构成这张图独有的观看理由。围绕一个主视觉焦点建立画面，并选择一个有意义的记忆点，例如异常尺度、独特轮廓、人物关系、空间矛盾、材料反差或光线事件。让记忆点直接服务主题。

### 主体与状态

说清画面中最重要的人、物或环境是什么。描述数量、身份、年龄感、外形、服装、道具等影响识别的特征，再说明静态画面中能够看见的姿态、动作阶段、表情、视线和状态。多人或多物体同时出现时，为每个对象明确位置、距离、互动关系和主次层级。需要叙事性时，让姿态、动作阶段、物件状态或环境痕迹本身承担"具体时刻"——主体想做什么、刚发生过什么、下一秒会发生什么，全部转化为静态画面中可见的证据。

### 场景与空间

说明地点、时代或时间、天气和环境状态，并明确前景、中景、背景中的关键元素。只加入能够强化主体、主题、情绪或空间可信度的细节，让环境通过遮挡、尺度、光线、路径或状态与主体发生关系。为当前画面选择一套空间表达规则，使层级、尺度、投影、遮挡或形变共同服务于目标内容和风格。

### 构图、视角与注意力路径

选择一个主导构图，明确景别、机位高度、拍摄角度、透视、主体位置、留白和景深。规划观众第一眼看到什么，随后发现什么，最后停留在哪里。用尺度、位置、明暗、色彩、视线、引导线和景深建立主次分明的视觉层级。视点、投影、遮挡、反射与透视边界遵守所选空间规则；使用变形、多视点或不可能透视时，让变化方式前后一致并服务于观看重点。

### 艺术风格

定义整体艺术流派、题材风格、绘制技法和文化语境。可以叠加少量互补方向，但每个方向必须贡献不同维度。默认保留一至三个风格项；一个主风格已经完整时就以它统领画面。使用具有可执行视觉特征的风格词，并让各项彼此兼容。

用户给出导演、艺术家或作品参考时，先把参考转译为当前画面的具体选择：光影与反差、色彩与明暗、镜头或视角、构图与空间。只保留该参考确实改变的维度，服从用户指定的参考强度，并把决定分别写入对应字段；不得只追加名字或抽象风格句，也不得因风格参考自行复刻某个现成画面的主体、调度或构图。

### 光线与色彩

描述主色、辅助色、饱和度、冷暖倾向、明暗关系、光线方向、光线软硬和整体调色。多个描述可以叠加，但要形成统一的视觉逻辑，例如低饱和暖棕主调、阴影偏青、黄昏侧逆光和电影级调色。默认保留二至四项，并让每项分别承担色彩、明暗、主体分离或调色职责。必要时说明主体与背景如何通过色彩或明度分离。光影可以服从场景条件、发光对象、情绪变化、所选媒介或其他成像机制；只需写清它如何影响主体、空间和观看重点，不预设单一照明方式。

### 质感与材质

描述重要主体的材料表现和画面微观质感，例如皮肤纹理、粗糙纸张、金属高光、玻璃折射或胶片颗粒。默认保留一至三个当前景别确实能够看见、并影响主体识别、风格或观看感受的材质特征。清晰度、纹理和表面可读性服从注意力层级与所选风格的细节规则，只让承担观看任务的区域获得充分信息。

### 媒介模拟

选择一种主要的成像或渲染媒介，例如中画幅胶片、35mm 摄影、3D 渲染或手绘水彩，用它统一最终成像逻辑。镜头、胶片、渲染器或绘画材料确实改变结果时写入，并保持一个统一的主媒介。媒介和器材术语只能强化已经成立的主体、空间、机位与光线；临时删去这些术语后，画面仍应具有清楚的视觉核心和统一的成像逻辑。

### 情绪与氛围

确定希望观众产生的核心情绪，以及这种情绪指向主体、关系、环境还是纯粹的感官体验。把抽象情绪转化为人物姿态与距离、空间尺度与留白、光色与天气、材质和构图节奏。画面可以专注纯粹氛围；具体视觉机制应当独立传达目标感受。

## 编写顺序

1. 确定视觉核心、主焦点和记忆点，只保留能够强化它们的创意。
2. 描述主体状态、场景空间、构图视角和注意力路径，使“画什么”明确唯一。
3. 统一艺术风格、光色、材质、媒介和情绪机制，解决互相冲突的要求。
4. 检查景别与细节、机位与可见范围、人物数量与动作复杂度、艺术风格与媒介是否兼容。
5. 回查空间、视点、遮挡、反射、光影与材质是否共同服务于所选内容、风格和观看重点，没有互相冲突的表达规则。
6. 使用导演、艺术家或作品的风格参考时，暂时移除参考名称；若剩余决定没有形成可辨认的光影、色彩、视角或空间差异，继续把参考转译为当前画面的可观察选择。
7. 检查所有要求能否从单张静态图片中观察到，并保留高信息密度、职责唯一的词语。

发生冲突时，依次保留用户明确要求、主焦点与记忆点、当前景别可见的信息、支撑情绪的风格细节。主体识别、构图可读性和核心时刻始终优先于次要装饰。

## 输出方式

最终回复只包含一份多行自然语言主 prompt。使用分组标题建立一级层级，使用 label 建立二级层级；分组之间空一行，每个 label 单独一行，并使用高信息密度的完整短句或短语。画幅、尺寸和参考文件上传由目标入口的对应字段承载，正文只描述画面本身。

输出结构是稳定合同。无论目标语言是什么，始终使用两个二级 Markdown 标题，并按下列顺序逐行输出字段；不得改名、重排、合并或新增字段。中文与英文使用表中的 canonical label，其他语言按相同语义直接翻译并在整份 prompt 中保持唯一译法，不自由改写同义标题。

| 语义职责 | 中文 canonical label | English canonical label |
| --- | --- | --- |
| 第一组标题 | `## 画面核心` | `## Visual Core` |
| 主视觉事件、第一观看点和最终记忆点 | `视觉意图：` | `Visual Intent:` |
| 可见主体、状态、关系、地点、空间层次与关键细节 | `主体与场景：` | `Subject and Setting:` |
| 画框、景别、机位、透视、景深和注意力路径 | `构图与视角：` | `Composition and Viewpoint:` |
| 第二组标题 | `## 视觉表现` | `## Visual Treatment` |
| 艺术流派、题材风格、技法或文化语境 | `艺术风格：` | `Art Style:` |
| 主辅色、冷暖、明暗、光源方向与调色关系 | `光线与色彩：` | `Lighting and Color:` |
| 当前景别可见的关键材质与微观质感 | `质感与材质：` | `Texture and Materials:` |
| 确实改变成像逻辑的摄影、绘画或渲染媒介 | `媒介表现：` | `Medium:` |
| 核心情绪及其具体视觉机制 | `情绪氛围：` | `Mood and Atmosphere:` |

两个组标题与除“媒介表现 / Medium”之外的字段始终出现；媒介没有实质改变成像逻辑时省略该字段。严格区分字段职责，同一信息只在最合适的字段出现一次。标题、label、字段值和必要说明全部使用目标语言；资产引用、专有名词及必须保持原样的 model / camera / rendering 术语除外。

先确定目标语言：优先服从当前会话或系统明确给出的输出语言约定；该约定未指定具体语言或要求随用户时，服从用户明确指定的语言，否则沿用用户当前语言。使用该语言惯用的大小写、标点和排版，但不改变上表规定的结构与字段职责。

交付前逐句检查主 prompt，只保留模型应当生成、保持或突出的内容。用户用“没有人物”“不要文字”等缺席或排除表达约束画面时，优先把它改写成语义等价、可观察的正向构图、数量或表面状态，例如“研究站是画面中唯一主体，所有面板保持空白且无标记”。改写后必须逐项保留原约束；无法用正向状态等价表达的 hard exclusion，在最相关字段保留一句最小、明确的排除约束。不主动扩写 negative prompt、排除清单或“补充限制”一类模板外分组。

批量生成多张图片时，每张图片使用一个完整、自包含的 prompt，并重复必要锚点。

开放需求下，prompt 使用与约四百至七百个中文字符相当的信息量；其他语言按语义密度调整，不机械套用中文字数。包含分组标题、label 和标点，去除换行与空行后的完整 prompt 硬性控制在 1000 个字符以内；用户明确要求的细节优先占用预算。如果全部明确要求需要更多空间才能准确表达，先请用户决定优先级。重要视觉信息保持具体，每个 label 保持一行。

用户明确要求或目标工作流需要其他语言时，再提供对应版本。用户要求“只给最终 prompt”时，仍输出这一份分层自然语言。最终检查结构完整、字段顺序稳定、语言单一、排版符合目标语言习惯，且没有同义 label 漂移或模板外分组。
