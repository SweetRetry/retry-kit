# Image Prompt

## 核心任务

把任务提供的想法、文字、参考素材分析为一组会实际改变生成结果的视觉决定，再组织成可直接交给生图模型的 prompt。先确定画面要表达什么与任务重心，再按需处理主体与状态、场景与空间、构图与视角、风格、光色、材质、媒介、情绪，按固定分组与 label 输出。至少需要核心主体或视觉主题；缺失不改变重心时作最小假设，可能改变主体/关键关系/构图/视觉方向时向用户确认。

## 无视觉上下文时先收敛方向

已有参考图、明确媒介、成熟视觉规范，或主体/构图/光色/风格基本成立时，直接编写 prompt。只有题材、情绪或零散形容词且不同视觉解释明显改变画面时进入引导：按影响放大率检查媒介与渲染、线条/边缘/体积、色彩与明度、光影、材质与细节；一个答案同时改变多维度或导向明显不同结果时优先询问。每轮提出 2–3 个最高影响问题，同时列出已确认决定、当前视觉主轴、推荐方向与真正不同的备选。

推荐与备选来自当前任务真实分叉；能判断的事实直接读取。收到回答只重开受影响的视觉轴，相容决定继续保留。用户要求直接出稿或高影响决定清楚相容时采用最支持方向进入完整 prompt；只剩低影响细节时作最小假设。最终交付合同始终是本 skill 末尾定义的完整 image prompt。

## 使用肯定指令

主 prompt 描述模型应当生成、保持或突出的内容，用数量、位置、比例、密度、状态、色彩、材质、留白等可观察属性收窄生成空间。参考边界用正向归属说明各素材控制什么、哪些维度按当前画面生成。安全合规红线由系统层处理。

## 控制细节密度与模型自由度

逐项用省略测试：删去后模型是否仍能稳定生成用户真正关心的结果，不能则锁定。默认中等密度：锁定决定成败的视觉选择，把装饰留给生图模型。优先级：必须锁定（核心主体、数量/关系、关键状态动作、场景类型、主构图、主光色、风格方向、核心情绪）→ 选择性锁定（一个次要动作、2–4 环境线索、1–3 材质细节）→ 留给模型（次要造型、非关键道具、背景、装饰、云、植被、粒子）。需求开放给清楚方向与适度留白；需求明确把用户细节视为约束，只压缩冲突、超景别可见范围或削弱主焦点的内容。每张图一个主焦点一个记忆点；用户要求多动作时按其要求，否则最多一个次要动作；人物数量影响结果时用确切数字。

## 组织 Prompt 内容

**视觉核心与记忆点**：一句话明确画面视觉核心（主体与什么环境/关系/尺度/动作/形式/反差构成观看理由），绕主焦点建立，选一个有意义记忆点并服务主题。

**主体与状态**：说清最重要的人/物/环境：数量、身份、年龄感、外形、服装、道具等识别特征，及静态可见的姿态、动作阶段、表情、视线、状态。多对象明确位置、距离、互动、主次。叙事性由姿态、动作阶段、物件状态或环境痕迹承担"具体时刻"。

**场景与空间**：说明地点、时代/时间、天气、环境状态，明确前/中/背景关键元素，只加入强化主体、主题、情绪或空间可信度的细节，让环境通过遮挡、尺度、光线、路径、状态与主体发生关系。

**构图、视角与注意力路径**：选主导构图，明确景别、机位高度、拍摄角度、透视、主体位置、留白、景深，规划观众第一眼/随后/最后的观看路径，用尺度、位置、明暗、色彩、视线、引导线、景深建立主次。视点、投影、遮挡、反射、透视遵守所选空间规则。

**艺术风格**：定义艺术流派、题材风格、技法、文化语境，可叠加少量互补方向且各贡献不同维度，默认 1–3 风格项，用可执行视觉特征的风格词。用户给导演/艺术家/作品参考时转译为光影反差、色彩明暗、镜头视角、构图空间的当前选择，只保留该参考实际改变的维度，服从参考强度并分别写入对应字段。

**光线与色彩**：描述主辅色、饱和度、冷暖、明暗、光向、光线软硬、调色，形成统一视觉逻辑，默认 2–4 项并各自承担色彩/明暗/分离/调色职责，必要时说明主体与背景如何分离。

**质感与材质**：描述重要主体的材料与微观质感，默认 1–3 个当前景别可见、影响识别、风格或感受的特征。

**媒介模拟**：选一种主要成像或渲染媒介统一最终成像逻辑；器材术语只能强化已成立的主体、空间、机位或光线，删去术语后画面仍应有清楚视觉核心。

**情绪与氛围**：确定观众核心情绪及其指向（主体/关系/环境/感官），转化为姿态与距离、尺度与留白、光色天气、材质、构图节奏，具体视觉机制独立传达目标感受。

## 编写顺序

1. 定视觉核心、主焦点、记忆点，只保留强化项。
2. 描述主体状态、场景空间、构图视角、注意力路径，使"画什么"唯一。
3. 统一风格、光色、材质、媒介、情绪，解决互斥要求。
4. 检查景别细节、机位可见范围、人物数量动作复杂度、风格媒介兼容。
5. 回查空间、视点、遮挡、反射、光影、材质共同服务内容、风格、观看重点。
6. 风格参考暂时移除名称后若剩余决定没有形成可辨认差异则继续转译。
7. 检查所有要求能从单张静态图观察到，保留高信息密度、职责唯一的词。

冲突时依次保留用户明确要求、主焦点与记忆点、当前景别可见信息、支撑情绪的风格细节；主体识别、构图可读性、核心时刻优先。

## 输出方式

最终回复只含一份多行自然语言主 prompt。用分组标题建一级层级、label 建二级层级；分组间空行，每个 label 一行，用高信息密度完整短句。画幅、尺寸、参考上传由目标入口对应字段承载，正文只写画面本身。输出结构是稳定合同：始终用两个二级 Markdown 标题并按序输出字段，中文与英文用 canonical label，其他语言按语义翻译并在整份中保持唯一译法。

| 语义职责 | 中文 label | English label |
| --- | --- | --- |
| 第一组标题 | `## 画面核心` | `## Visual Core` |
| 主视觉事件、第一观看点、最终记忆点 | `视觉意图：` | `Visual Intent:` |
| 可见主体、状态、关系、地点、空间层次、关键细节 | `主体与场景：` | `Subject and Setting:` |
| 画框、景别、机位、透视、景深、注意力路径 | `构图与视角：` | `Composition and Viewpoint:` |
| 第二组标题 | `## 视觉表现` | `## Visual Treatment` |
| 艺术流派、题材风格、技法、文化语境 | `艺术风格：` | `Art Style:` |
| 主辅色、冷暖、明暗、光源方向、调色关系 | `光线与色彩：` | `Lighting and Color:` |
| 当前景别可见的关键材质与微观质感 | `质感与材质：` | `Texture and Materials:` |
| 确实改变成像逻辑的摄影/绘画/渲染媒介 | `媒介表现：` | `Medium:` |
| 核心情绪及其具体视觉机制 | `情绪氛围：` | `Mood and Atmosphere:` |

两个组标题与除"媒介表现/Medium"之外字段始终出现；媒介无实质改变时省略该字段。严格区分字段职责，同一信息只出现一次。标题、label、字段值、说明用目标语言；资产引用、专有名词、必须保持原样的术语除外。目标语言：优先会话或系统明确约定，否则用户指定语言，否则用户当前语言。

交付前逐句检查只保留模型应当生成、保持或突出的内容；排除表达优先改写成语义等价、可观察的正向构图、数量或表面状态，无法正向等价的 hard exclusion 在最相关字段保留一句最小明确排除。批量多图每张用完整自包含 prompt 并重复必要锚点。开放需求按约 400–700 中文字符语义密度，其他语言按语义密度调整；含标题、label、标点且去除换行空行的完整 prompt 硬性控制在 1000 字符内，用户明确细节优先占用预算，空间不足请用户决定优先级。最终检查结构完整、字段顺序稳定、语言单一、排版合目标语言习惯、无同义 label 漂移。
