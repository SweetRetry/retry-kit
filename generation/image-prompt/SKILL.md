# Image Prompt

## 1. 核心心智模型 (Mental Model)

生图 Prompt 的本质不是文学散文或填表清单，而是**向生成模型传递高确定性、物理可观测的视觉属性**。
提示词应描述单张静态画面中肉眼可见的状态与物理关系，而非主观感受、情绪评价或故事情节。

## 2. 视觉思考维度 (Thinking Axes)

解构需求时，按以下维度进行视觉决策（无固定线性顺序，按需聚焦）：

- **主体与状态 (Subject & Moment)**
  - 静态特征：数量、身份、形体、服装、道具及识别性外貌。
  - 凝固瞬间：具体的动作阶段、姿态、微表情、视线方向；多主体时明确物理间距、遮挡与主次层级。
- **构图与视角 (Composition & Viewpoint)**
  - 镜头规划：景别（特写/中景/全景）、机位高度与拍摄角度（俯/仰/平/倾斜）、透视关系与焦段感。
  - 动线与画框：主体在画面的几何落点、留白比例、前景引导线与景深虚实（焦平面）。
- **光线与色彩 (Lighting & Color)**
  - 光照逻辑：主辅光源方向、光质（柔光/硬光/边缘光/体积光）、明暗反差比与投影形态。
  - 色彩体系：主辅色调、冷暖倾向、色彩饱和度与明暗分离度，确保主体从背景中清晰分离。
- **质感与媒介 (Texture & Medium)**
  - 成像媒介：具体媒介特征（如 35mm 胶片颗粒、厚涂油画笔触、黏土定格、3D 渲染光追等），而非空泛的画质词。
  - 微观材质：当前景别下肉眼可辨的表面物理质感（如粗糙麻织、湿润反光、风化锈蚀、皮肤细纹）。
- **氛围落地 (Atmosphere Grounding)**
  - 感受转译：将抽象情绪转化为具体环境的物理痕迹或光影节奏（如雨夜地面反光、弥漫的尘埃丁达尔光、过曝的霓虹光晕）。

## 3. 核心决策原则 (Decision Heuristics)

### 可观测性原则 (Groundability)
- **剔除无效修饰**：禁止使用“超级细节”、“杰作”、“美丽的”、“史诗级”等无物理落脚点的空洞形容词。
- **转译抽象参考**：用户提供导演、艺术家、流派或作品参考时，转译为其标志性的光影反差、色调配比、构图和镜头语言，只保留实际改变画面的视觉维度。

### 约束与自由度平衡 (Constraint vs. Freedom)
- **锁定成败关键**：精确锁定决定成败的视觉骨架（核心主体、关键动作、主构图、主光色与核心风格）。
- **省略测试（奥卡姆剃刀）**：删去某个词后，若模型仍能稳定生成预期画面，则不写该词；将次要背景、装饰元素留给模型发挥，避免因过度约束（Over-prompting）导致模型崩溃或画面僵硬。

### 正向肯定描述 (Positive Framing)
- 描述模型**应当生成、保持或突出**的具体属性（位置、材质、状态、光影）。
- 排除表达优先改写为正向构图或表面状态约束；否定逻辑与安全红线交由系统层/Negative prompt 处理。

### 模糊输入收敛策略 (Disambiguation)
- **已有明确视觉信息**：直接编写，不做多余假设。
- **仅有情绪/题材且存在严重分歧**：先用 1–2 个最高影响的维度（如媒介类型、写实度、光影基调）收敛方向；次要细节作最小合理假设。

## 4. 输出交付准则 (Delivery)

- **内容纯粹**：交付内容聚焦于画面本身的视觉呈现。
- **自适应组织**：输出高信息密度、语义连贯的自然语言 Prompt（英文或目标语言）。根据下游模型与任务特性自然分段，不强制套用固定模板标签或表格。
