# Image Prompt

## 1. 核心思路：只写镜头看得见的东西，别聊文学感受

生图提示词不是抒情散文，也不是堆砌标签的清单。你是在指挥一台只能看懂物理画面的照相机。
只写单张静态画面里**肉眼看得见的状态、光线、材质和物理关系**，别写“心情悲伤、气氛史诗、绝世美人”这种让模型瞎猜的废话。

---

## 2. 画面拆解五要素 (按需聚焦，不必生搬硬套)

拆解需求时，从以下五个维度组织画面：

- **谁在画面里、在干什么 (主体与瞬间)**：
  - 外貌长相：长相、年龄、体型、穿戴与识别性道具；
  - 凝固瞬间：停在哪个具体动作阶段、微表情、视线看哪；多个人物时写清谁在前谁在后、谁遮挡谁。
- **相机摆在哪、怎么看 (构图与视角)**：
  - 景别与机位：特写/中景/全景，俯拍/仰拍/平视/斜倾，透视长焦还是广角感；
  - 画框与留白：主体落在画面什么位置（三分线/正中），前景引导线与背景虚化程度。
- **光打在哪、什么色调 (光线与色彩)**：
  - 光从哪来：主光从哪个方向照过来，是柔光还是刺眼强光，阴影落在哪里；
  - 颜色倾向：画面整体偏暖还是偏冷，主体颜色怎么跟背景区分开。
- **摸上去是什么质感 (质感与媒介)**：
  - 媒介类型：是 35mm 胶片颗粒、油画笔触、还是 3D 渲染，别用“8K 超清”这种废话；
  - 表面微观材质：当前景别下肉眼看得见的粗糙麻布、湿润反光、皮肤纹理或金属锈迹。
- **环境里的真实痕迹 (氛围落地)**：
  - 情绪变物理痕迹：把抽象氛围换成真实的细节（比如雨夜地面积水倒影、空气里的丁达尔光束、霓虹过曝的光晕）。

---

## 3. 避免翻车的决策原则

### 看得见才算数（拒绝空洞词）
- 坚决不用“杰作、史诗感、超级细节、绝美”等没有任何物理落脚点的词。
- 提到艺术家或某部电影风格时，转译为其标志性的光影对比、色调配比和构图习惯，只留真能改变画面的词。

### 立标准 vs 依赖图纸（信息分流）
- **资产立项（角色/道具设定图）**：承担全片“立标准”职责，穷尽锁定五官特征、发型、衣服层级、反光材质与固定色值。
- **有草图/分镜参考时**：文字主动极简，绝不重复图纸上已经画明白的构图和动作，只补图纸看不到的光影、质感与反差。

### 奥卡姆剃刀（能省则省）
- 删去一个词后，如果模型依然能生成想要的效果，那就坚决不写。次要背景留给模型发挥，写得太满反而导致画面僵死或特征冲突。

### 多说正面的大白话
- 直接描述画面里**应当看到什么**（材质、位置、光线）。否定排除项交由系统负向提示词 (Negative Prompt) 处理。

### 遇到模糊需求时的收敛策略
- 需求明确：直接写，不多加脑补；
- 只有抽象情绪、方向存疑：先拿最影响成败的 1–2 个维度（写实度、媒介类型、光影大基调）收敛方向，其余次要细节做最小合理假设。

---

## 4. 交付准则

- **纯粹交付**：只给画面本身的视觉 Prompt，不夹带解释废话。
- **自然连贯**：输出信息密度高、语义通顺的自然语言 Prompt（英文或目标模型推荐语言），不生硬套用方括号或表格模板。
