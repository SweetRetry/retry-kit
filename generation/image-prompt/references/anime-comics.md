# 动漫与漫画

先确定是在生成动画风插画、角色设定，还是漫画页面。动漫题材、角色比例、线条和上色方法是独立选择，不能用“anime”一词包办。

## 1. 区分交付物

- **Anime-style illustration（动画风插画）**：单张构图，角色设计与背景表现可以不同；没有漫画需求就不自动加入分格、气泡和速度线。
- **Model sheet / turnaround（设定图／转面图）**：统一角色比例、发型体积、服饰构造和配色。多视图是同一角色，正侧背面服从同一设计。
- **Expression sheet（表情设定）**：指定需要的表情变化，保留身份与头部比例；不是一张多角色群像。
- **Manga page / comic panel（漫画页面／单格）**：页面需分格、阅读顺序和文字；单格只处理当前动作与表达。
- **Webtoon（条漫）**：竖向阅读、段间留白与节奏适合滚动；单张页面仍需明确各格内容，不能只写 vertical。

请求单格时不扩成故事规划；请求多格页面时说明单张图内的格序，不写视频时序。

## 2. 术语与视觉机制

| 术语 | 作用 | 使用条件 |
| --- | --- | --- |
| clean line art（清稿线条） | 明确轮廓与结构，便于上色 | 指定线宽变化、边缘和描边色；不等同于所有区域粗黑线 |
| cel shading（赛璐璐式上色） | 以简单、分层的色块表达阴影 | 明确阴影级数和边界；连续渐变或柔光可用于指定区域 |
| sakuga（高质量作画语境） | 常指动画中的突出作画表现 | 单张图应落实为动作张力、造型或线条，不把它当固定材质 |
| chibi / super-deformed（Q版／夸张变形比例） | 改变头身比、四肢和五官概括 | 同时写识别点与实际比例，不能只说“可爱” |
| screentone（网点） | 用图案密度表达明暗、材质或效果 | 区分点密度与网点频率，说明作用区域 |
| spot blacks（实黑块） | 大面积黑色建立焦点与节奏 | 与白区、网点和线条配合；不是全图压暗 |
| speed lines / impact lines（速度线／冲击线） | 表达方向、速度或集中冲击 | 指向具体动作与焦点；不自动布满背景 |
| speech balloon / gutter（对白气泡／格间空隙） | 组织文字与阅读路径 | 请求漫画页时明确文字、位置、尾巴指向和格间关系 |
| foreshortening（透视缩短） | 近远肢体的尺寸变化表现动作 | 保持可读的肢体关系，避免用“动态”替代姿态 |

## 3. 人物、背景与页面

角色的头身比、面部编码、发束和服饰形状先统一。背景可以细密绘制，也可以图形化或留白；说明与角色共用哪些调色或明暗规则。

黑白漫画由线、实黑、网点和留白组织层次。彩色漫画仍需明确线条与色块，不默认套写实肤质。漫画文字逐字保留，文字方向和阅读顺序服从用户的语言与版式。

需要戏剧光线时，可与硬边阴影共存；要求柔和厚涂上色时，则不要同时把全图限定为纯平涂。风格混合明确到区域或层级。

## 4. 写法对照

- **动画风角色图**：`clean tapered line art, flat base colors with two distinct shadow levels, consistent stylized facial proportions`；补姿态和背景关系，不附带漫画网点。
- **黑白漫画单格**：`bold spot blacks, sparse screentone shadows, directional speed lines behind the moving arm, an open area for the specified speech balloon`；效果线服务动作，气泡服务文字。
- **转面设定**：`front, profile and back views of the same character, aligned head height, consistent hair volume and costume seams`；细节服从设计一致性。
