# 2D 插画

先选形状和画法，再组织色彩、边缘与细节。本 reference 处理通用插画语言；具体绘画材料读 [painting-printmaking.md](painting-printmaking.md)，动漫和漫画读 [anime-comics.md](anime-comics.md)。

## 1. 选择插画语言

| 方向 | 关键表现 | Prompt 需明确 |
| --- | --- | --- |
| flat / vector illustration（平面／矢量观感） | 概括形体、清晰色块与轮廓 | 几何或有机形状、边缘、调色、描边；渐变按设计决定 |
| editorial illustration（编辑插画） | 用图像表达主题、观点或隐喻 | 核心视觉关系和阅读重点，不必等同某种固定画法 |
| children's book illustration（绘本插画） | 角色、动作和环境服务叙事 | 目标读者、造型比例、细节层级和材料观感；不自动等于圆脸加粉彩 |
| line art（线描） | 线条承担结构、体积或纹理 | 线宽、节奏、疏密、封闭轮廓与留白 |
| digital painterly（数字绘画观感） | 色块与笔触塑造形体 | 边缘控制、明度分组、笔触尺度与焦点细化 |
| technical / botanical illustration（技术／植物插图） | 清楚表达结构或识别特征 | 正确部件关系、观察方向、标注和比例；非真实结构不能靠细节词掩盖 |

“矢量观感”指视觉特征，不能承诺输出可编辑 SVG。制作真正矢量文件属于文件交付和验证。

## 2. 专业词与表现决策

| 术语 | 改变什么 | 用法 |
| --- | --- | --- |
| shape language（形状语言） | 轮廓、形体家族和比例关系 | 写哪些形状占主导、如何服务角色或主题 |
| line weight（线宽） | 轮廓强调、层次与节奏 | 均匀、粗细变化或按遮挡加重，选择一种明确机制 |
| contour / gesture drawing（轮廓／动态线） | 外形结构或动作张力 | 前者强调边界，后者强调姿态；不能互相替代 |
| hatching / cross-hatching（排线／交叉排线） | 以线的方向与密度建立明暗 | 适合钢笔、铅笔或刻画式语言，不自动加入平涂风格 |
| flat colors / color blocking（平涂／色块组织） | 用清楚的色域建立形体和重点 | 说明明度与面积关系，比只写“鲜艳”更可控 |
| value grouping（明度分组） | 大明暗块的层级 | 主体、背景与焦点先分组，再分配局部细节 |
| hard / soft / lost edges（硬／软／消失边缘） | 形体的清晰程度和视线流动 | 重点可清晰，非重点可融合；不能全图同样锐利 |
| negative space（负空间） | 轮廓之间或周围空隙的形状 | 明确留白位置和作用，不仅写“简洁” |
| limited palette（有限调色板） | 颜色关系与统一程度 | 指定主色、辅色和重点色；色数仅在需要时固定 |

## 3. 组织空间与材质

空间可以由透视、遮挡、比例、层叠、边缘或色彩建立。平面插画可以弱化透视；写实插画也可以采用复杂空间。以目标画法决定，不把二维统一理解为无体积。

表面信息服从画法：平涂的金属可能只需高光色块，线描的织物可能只需排线。布纹、颗粒或纸面要指向具体区域与尺度，避免全局叠一层噪点。

## 4. 写法对照

- **平面编辑插画**：`bold geometric shapes, flat overlapping color planes, restrained palette, deliberate negative space`；补主题隐喻和阅读路径。
- **线描插画**：`variable-weight ink contours, sparse cross-hatching on shadow planes, open white space around the focal object`；让线条承担结构，未要求时不补镜头散景。
- **数字绘画**：`large grouped values, selective hard edges at the focal point, visible broad brushwork in secondary areas`；重点细化与次级简化分开。
