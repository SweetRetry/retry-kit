# 材料、工艺与拼贴

先确定是真实制作物的拍摄观感，还是模拟工艺的插画／CG。材料构造决定边缘、接触、厚度和纹理，不应只在普通插画上覆盖一层材质噪点。

## 1. 材料与工艺语言

| 术语 | 制作逻辑与可见特征 | 需要明确 |
| --- | --- | --- |
| cut-paper collage（剪纸拼贴） | 裁切纸片在平面中组合 | 切边、撕边、纸色、叠放和是否有厚度 |
| layered paper cut / paper relief（层叠纸雕／纸浮雕） | 多层纸形成空间与投影 | 层数关系、切口、间距、光线方向与真实厚度 |
| origami（折纸） | 折叠建立平面、折线和体积 | 折面结构、纸材与对象轮廓；不把层叠剪纸称为折纸 |
| quilling（纸衍） | 纸条卷曲形成线性体积 | 纸条宽度、卷曲方向、疏密与投影 |
| photomontage（照片蒙太奇） | 来自不同照片的元素拼合 | 裁切或融合边界、尺度关系、色调匹配或有意错置 |
| assemblage（组合艺术） | 实体物件在三维中组合 | 物件类别、固定与接触关系、真实表面 |
| appliqué（贴布） | 布片叠贴在底布上 | 布边、针脚、缝线、图案层级 |
| embroidery（刺绣） | 针脚形成线条与色面 | 针脚方向、密度、线材、底布；与印在布上的图案区分 |
| needle felt（针毡） | 羊毛纤维构成形体 | 纤维尺度、柔软轮廓与体积；不画成规则编织针脚 |
| knitting / crochet（针织／钩织） | 纱线形成不同结构的线圈 | 选择可见线圈与织物密度，保留具体工艺身份 |
| clay / plasticine（黏土／橡皮泥） | 塑形产生圆润体积、压痕和接缝 | 是否保留指痕、表面光泽和支撑结构；不统一成光滑塑料 |
| ceramic / glazed ceramic（陶器／釉面陶器） | 胎体与釉面共同建立表面 | 区分哑光胎、光亮釉、厚度和高光 |

材料名称保留，但必须确定构造关系。像绒毛、针脚和纸纹这类微细节服从观看尺度。

## 2. 拼贴的组合决策

1. 确定各元素的来源与作用：照片、文字、纸片、绘画或实物。
2. 选择统一尺度与透视，或明确有意造成的尺度错置。
3. 决定边界是硬裁切、撕边、柔性融合还是遮挡。
4. 用留白、层叠和色彩建立阅读路径。

拼贴不是随机元素堆积。异质材料可以统一调色，也可以保留差异；超现实组合需要明确不合常规的视觉关系，不能靠一个 surreal 标签包办。

## 3. 真实工艺与模拟效果

- 拍摄实物时，光线要揭示层厚、针脚或塑形痕迹，读 [photography.md](photography.md)。纸浮雕尤其需要接触阴影和层间投影。
- 用 CG 模拟时，几何和材质实现上述构造，读 [render-3d.md](render-3d.md)。黏土动画观感在单张图中通过姿态、压痕与制作痕迹表达，不加入动作时序。
- 平面化工艺插画可以只保留材料语言，不必变成桌上摆件的实拍；明确目标是平面画面还是实体展示。
- Mixed media（混合媒介）需要说明哪部分用什么媒介，以及通过裁切、层叠、绘画覆盖或共用调色连接。

## 4. 写法对照

- **纸雕场景**：`layered cut-paper relief, distinct overlapping paper planes, visible cut edges, directional light casting shallow shadows between layers`；厚度与层叠共同建立空间。
- **刺绣插画**：`stitched thread shapes on a woven ground, directional embroidery stitches following the forms, restrained raised thread relief`；纹理来自针脚，不是贴一张织物纹理。
- **照片拼贴海报**：`hard-cut photographic fragments at deliberately contrasting scales, torn-paper accents, a unified limited palette, a clear title area`；文字与版式再读 [graphic-design.md](graphic-design.md)。
