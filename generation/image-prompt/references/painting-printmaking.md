# 绘画与版画

先选材料和技法，再选形体、明度、边缘与笔触。画材不是一层可统一叠加的纹理；它会改变色彩覆盖、边缘与细节方式。

## 1. 绘画材料与技法

| 材料／术语 | 可见作用 | 选择条件与边界 |
| --- | --- | --- |
| watercolor wash（水彩铺色） | 透明色层、纸白透出与水分形成的边缘 | 区分铺色区域与留白，不统一把颜色刷成不透明厚块 |
| wet-on-wet（湿画法） | 湿底上颜色扩散、交融、柔边 | 适合气氛和大色域；清晰局部可以湿底干后另画 |
| dry brush（干笔） | 笔触断裂、纸或底材纹理穿出 | 需要干涩表面与擦笔痕迹时；不代表全图低饱和 |
| granulation（水彩颗粒沉积） | 颜料颗粒在纸面产生不均匀色域 | 只在需要这类材料痕迹时添加，与数字噪点区分 |
| gouache（水粉） | 覆盖性较强、哑光色块与平面组织 | 可有稀释透明区域；不是 watercolor 的同义词 |
| oil glazing（油画罩染） | 透明薄层叠加形成色彩深度 | 需要通透层次时；与厚涂可在不同区域共存 |
| impasto（厚涂） | 堆起的颜料与可见笔触、刀痕 | 说明厚涂区域和笔触尺度；不要同时把全表面限定为无痕平滑 |
| scumbling（薄擦／擦绘） | 不完全覆盖底层的碎色与干擦效果 | 需要破碎边缘、空气感或表面层次时 |
| alla prima（直接画法） | 直接组织色块与笔触的绘画观感 | 强调有把握的笔触和色块关系；不是精确的视觉结果保证 |
| charcoal / graphite（炭笔／石墨） | 颗粒、排线、擦抹与纸白建立明暗 | 明确线描还是大面积擦抹，不默认给石墨添加油画厚度 |
| ink wash（水墨晕染） | 墨色浓淡、渗化、干湿与留白 | 先判断书写性线条或墨块组织；不能只加泛称东方题材 |

## 2. 绘画组织语言

- **Chiaroscuro（明暗对照）**以光暗塑造体积和戏剧层级；**tenebrism（暗色背景中的强亮区）**更强调深暗与局部光，不与任何“暗画面”混称。
- **Sfumato（烟雾式柔化）**强调细腻、模糊边界的色调过渡；**hard edge（硬边）**强调清晰边界。按焦点或画法分区，而非全图两者同时最大化。
- **Broken color（分置色）**用相邻独立色触建立观感；**optical mixing（视觉混色）**由观看时的综合色感成立，和湿颜料混合不同。
- **Underpainting（底层绘画）**只有透出或影响画面时才需要在 Prompt 中说明；生产步骤不必全转为画面标签。
- 笔触的方向、大小与密度应服从形体、画幅和观看尺度。主体细化、背景概括可以有不同边缘处理。

“印象派”“表现主义”“超现实主义”等名称可以保留，但需确定实际采用的是色触、形体变形还是意象关系。题材、时代、流派和材料不能互相替代。

## 3. 版画与印刷语言

| 术语 | 画面机制 | 使用条件 |
| --- | --- | --- |
| woodcut / linocut（木刻／油毡刻） | 凸版切割产生的线、块面与留白 | 选择粗细刀痕与实黑组织；木纹仅在目标需要时显露 |
| etching / engraving（蚀刻／雕刻凹版） | 细线、排线和线密度形成明暗 | 适合精细线性结构；不要默认套粗块状木刻线条 |
| lithography（石版画） | 可呈现绘画式线条、蜡笔颗粒或色面 | 根据目标作品说明颗粒与色层，不能仅凭名称固定黑白 |
| screenprint（丝网印刷） | 分色油墨、平面覆盖与叠印关系 | 指定色版、叠色与边缘；套色偏移仅在需要时加入 |
| halftone（半色调网点） | 点的大小或分布模拟连续色调 | 确定网点尺度和区域，不等同于绘画笔触 |

有文字或版式目的时，补读 [graphic-design.md](graphic-design.md)。普通绘画不因“复古”自动添加纸张破损、褪色或脏边。

## 4. 写法对照

- **水彩**：`transparent washes, wet-on-wet diffusion in the distant foliage, preserved paper white, crisp dry-brush accents on the focal figure`；干湿机制分区。
- **厚涂油画**：`broad opaque color masses, directional impasto on the lit planes, restrained soft edges in the shadows`；厚度和软边承担不同作用。
- **木刻观感**：`bold relief-print shapes, carved white marks within black masses, a limited ink palette`；刻线与实黑建立结构，不用胶片颗粒代替。
