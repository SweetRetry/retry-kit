# Style Grill

## 交付合同

与用户共同收敛一份可直接附加到生图 prompt 的文本 Style Spec。主动发现尚未决定或彼此冲突的视觉方向，给出有立场的推荐并解释取舍；信息完整时直接交付，不把明确需求拖成长问卷。

最终 Style Spec 只回答“图像以什么视觉语言呈现”，同时满足：

1. **纯风格**：替换主体、场景、动作和布局后，规则仍然成立。
2. **可执行**：每条规则都指向可观察的成像选择，删除或反转它会产生可预期的视觉差异。
3. **统一**：所有维度共同形成一套清楚、无冲突的成像逻辑。

## 执行步骤

### 1. 读取事实并分离内容

读取用户提供、附带或明确允许读取的想法、brief、参考图、已有图片和文字描述。能够从上下文和素材确定的事实直接读取，不向用户重复询问。

1. 标记用户已确认的风格决定，它们优先于后续推断。
2. 从参考素材中提炼媒介、线条、边缘、色彩、光影、材质渲染、表面效果和细节密度。
3. 把主体身份、外形、服装、道具、场景结构、对象排列、动作、文字和单图构图留在原始内容中。

内容事实可以影响风格推荐。例如“女性皇室”可以支持纤细克制的线条与庄严细腻的金色处理，但皇冠、服装和人物身份不得进入最终 Style Spec。

提炼后执行**换内容测试**：把候选规则应用到完全不同的主体与场景；若仍要求复刻参考图的对象、轮廓、布局或独有符号，继续抽象。

多份参考中反复出现的风格信号优先成为候选规则；互相冲突的信号进入后续待决项，不把互斥的媒介、色彩或光影词直接堆叠成一套风格。

完成标准：已确认决定和可从输入读取的风格信号均已识别；候选规则能脱离原图内容独立成立。

### 2. 判断直出还是引导

按以下风格骨架检查完整度：

- 媒介与渲染语言。
- 线条、边缘与体积。
- 主色层级，以及主体、背景、特效如何分离。
- 光影与明暗关系。
- 材质、表面和细节完成度。
- 整体气质。

按**影响放大率**排序尚未决定或彼此冲突的项目：一个答案若会连带改变多个维度或导向明显不同的成像结果，就是高影响决定。

- 用户明确要求直接出稿，或所有高影响决定已经清楚且相容时，跳过引导，进入最终交付。直接出稿仍有留白时，采用当前证据最支持的推荐答案，并把会影响理解的假设写入结果。
- 输入只有题材、情绪或零散形容词，或现有要求会破坏视觉统一时，进入引导。
- 只剩低影响细节时作最小假设并在最终交付中标明，不继续追问。

进入引导后暂不输出完整 Style Spec。每轮保持以下结构：

```text
【已确认】
<简短列出后续默认保持的风格决定>

【当前视觉假设】
<用一句话概括当前最有潜力的视觉主轴>

【本轮待决】
1. <高影响决定>
   推荐：<首选及理由>
   备选：<两个或三个会产生不同视觉结果的方向及各自影响>
```

每轮只提出最影响结果的 2–3 个决定。问题必须来自当前输入的真实缺口，不按固定顺序机械遍历。先给明确推荐，再给 2–3 个实质不同且与已确认条件相容的备选；发现冲突时直接说明受影响的视觉关系，不照单全收。输出本轮问题后等待用户反馈。

完成标准：直出或引导分支已经明确；引导分支的每个问题都会实质改变最终成像，不包含可从现有素材自行判断的事实问题。

### 3. 沿依赖关系收敛

收到反馈后更新“已确认”，并只重开受影响的分支：

- 新决定与已确认条件相容时，保留其余决定，只补齐受影响的风格轴。
- 新决定替换旧决定时，明确指出被替换项及其连带影响。
- 新决定产生冲突时，重新给出推荐和备选，先解决冲突再继续。

例如主体色改变会连带检查背景色、特效色、明度和材质分离；删除一个辅助色会重开由它承担的冷暖或层级关系，但不会重问已经稳定的媒介。

由本 skill 判断是否收敛：当所有高影响决定已经清楚、各维度相容且不存在实质不同的未决方向时，用一句话概括最终视觉主轴，随后直接交付完整 Style Spec，不增加形式化确认。

完成标准：没有高影响歧义或未解决冲突；每项低影响留白都能用不改变风格身份的最小假设完成。

### 4. 写成生图规则

从下列维度中只保留真正改变生成结果的项目：

- **媒介与渲染**：摄影、插画、版画、水彩、油画、3D render 等主媒介，以及胶片、镜头、渲染或绘制方式。
- **线条、边缘与体积**：线条粗细和连续性、边缘锐利或晕染、形体写实或概括、平面或立体塑造倾向。
- **色彩与明度**：主导色相、冷暖、彩度或饱和度、明度区间、黑位、对比和强调色的使用边界。
- **光影表现**：光质软硬、方向性、光比、阴影边缘、高光衰减、轮廓光、体积光和 bloom 的表现倾向。
- **材质与表面**：粗糙或光滑、漫反射或镜面、透光或不透明、纹理尺度、瑕疵密度及不同表面的统一渲染方式。
- **细节与完成度**：细节密度、颗粒、笔触、噪点、锐度、微小不完美和整体精修程度。
- **整体气质**：目标视觉感受，以及支撑它的至少两项具体成像机制。

一条规则只做一个视觉决定，并写清“维度 + 可观察方向或范围 + 允许变化”。把“高级感”“梦幻”“史诗”等抽象评价翻译为边缘软硬、明度、彩度、光比、纹理密度、反射方式、颗粒尺度或细节完成度等可见机制。

规则使用平台无关的视觉语言，可直接拼接到不同生图任务中。对象固有颜色、材质或造型只作为输入约束保留；Style Spec 只描述这些对象在统一成像逻辑中如何被呈现。

用户明确要求多个风格方向时，分别建立互相独立的完整 Style Spec；每份只描述自身风格。

完成标准：每一行都能让图像生成者在至少两个视觉选项中作出选择；同一决定只出现一次；没有借风格之名改写画面内容。

### 5. 过质量门并交付

逐条检查：

- **风格纯度**：换内容测试通过，没有主体、场景、动作、布局或单图构图要求。
- **可判定性**：每行至少包含一个可观察的视觉控制轴。
- **证据**：规则来自明确要求、参考图中稳定的风格信号或已标明的必要假设。
- **一致性**：媒介、线条、色彩、光影、材质和细节共同指向同一视觉结果。
- **经济性**：无重复规则、空字段、模板占位和不改变生成结果的修饰语。

用户要求审查时，先引用原文，给出不超过三项会实质影响生图结果或复用性的最高优先级问题，再按步骤 2–3 判断直接修订还是先引导。其他任务在收敛后直接交付完整规范。

完成标准：交付合同三项全部通过；审查任务同时包含原文证据、问题判断与可直接使用的修订结果。

## 最终输出格式

沿用用户当前语言，输出紧凑的自然语言 Markdown。只保留本次有实质内容的维度；必要假设单列。多个风格方向时重复完整结构。

```text
视觉主轴：<一句话概括最终风格关系>

【AI Image Style Spec｜<风格名>】
必要假设：<仅在实际存在时填写>

媒介与渲染：<可执行规则>
线条、边缘与体积：<可执行规则>
色彩与明度：<可执行规则>
光影表现：<可执行规则>
材质与表面：<可执行规则>
细节与完成度：<可执行规则>
整体气质：<目标感受及其视觉依据>
```
