# World Director — 示例输出

本文是一份 `world-director` 的**工作示例**：在同一个示例任务上展示 skill 如何把「题材 + 核心角色 + 故事种子」发展成一套自洽、服务于故事的世界观。示例世界为虚构的"潮生群岛"，用于演示 `SKILL.md` 中的判断原则——因果推导链、冲突功能化、深度校准与 `待定` 留白——而非规定任何题材方向。

> 假设输入：低魔奇幻 + 文明叙事；核心角色：一名反抗开采的岸民少女；故事种子：潮汐巨树在枯死、垄断魔力的贵族在暗中搜刮下层。

```text
【范围】
输入与版本:低魔奇幻题材;角色为岸民少女"洱音";故事种子为"潮汐巨树枯死、贵族垄断魔力来源"。
承担故事功能:一套主要支撑"资源/权力压迫—基层反抗—文明存续危机"的世界观;魔力系统的代价与稀缺资源直接产生持续施压与叙事约束。
关键假设:世界基调取"温和悲悯的生态奇幻"而非暗黑史诗;科技停留在前工业水准(仅靠魔法辅助的农业与航海)。

【一、基础定位】
- 世界全名:潮生群岛(别称"风潮诸陆"、简称"潮陆")
- 世界类型:低魔奇幻 / 生态文明叙事
- 时代感对照:类比中世纪庄园制 + 早期远海航商的质感,无工业
- 一句话概念:一片由"潮汐巨树"的树根托举上万年的浮陆群岛;魔力来自树液"潮髓",被根系贵族垄断,而树正在枯死。
- 核心关键词:潮髓垄断 · 浮岛漂移 · 树即神明 · 存续危机
- 主要舞台:浮陆群岛的悬岸聚落、季风贸易航路、深渊暗根带
- 世界基调:悲悯、潮湿、缓慢压迫中隐含觉醒
- 主要居民:人类为主的"岸民",与陆地共生的"根系贵族",以及被边缘化的水栖"盐裔"
- 角色切入口:一名在潮落时偷偷掘取浅层潮髓维持家计的岸民少女(洱音)
- 故事类型:生态危机下的底层反抗与身份觉醒
- 世界边界/规模:数十座会缓慢漂移的浮岛组成的群岛,海域之外是"无光深渊",边界未知且危险
- 标志性画面:潮水退去时裸露出盘错的巨树根茎,琥珀色的髓光在新月之夜亮起
- 常见印象词:青绿水雾、树根之城、潮汐灯、下沉的贵族
- 创作重点:力量(潮髓)如何通过垄断变成压迫,以及树死即城亡的存续压力
- 备注:基调与创作重点一致——没有把压迫写成孤立事件,而是接进文明存续的大背景。

【二、地理环境】
- 主要气候:湿热,常年海雾与季风雨,高地凉爽
- 季节变化:"大潮"与"小潮"主导 Cycle,而非春秋;大潮季风暴频仍
- 主要地貌:树根网上的浮岛台地、潮间带、悬壁聚落、海下深渊
- 代表地区:主岛"母树悬城"、盐裔聚居的"礁链湾"、贸易枢纽"潮港"
- 自然奇观:新月夜的"髓潮"(浅层潮髓上浮发光的海面潮汐)
- 常见灾害:潮汐风暴、浮岛漂移撞向邻近孤岛、枯根塌陷
- 丰富资源:鱼获、海盐、潮麻(织物)、树皮建材
- 稀缺资源:潮髓(魔力之源)、旱季净水(浮岛蓄水有限)——两者都直接指向冲突
- 水源/粮食:靠聚落蓄水池与潮间田;旱季短缺,水成为下层血汗的一项
- 生态特征:浮岛生态自足;巨树根系深扎深渊,是群岛稳定的唯一依托
- 交通难点:浮岛漂移使固定航线需按季修订,深渊带不可通航
- 贸易条件:季风航路联系各岛,潮髓是唯一硬通货,流通被贵族卡死
- 未探索区域:无光深渊与暗根带,官方讳莫如深
- 人工改造痕迹:贵族在树根内凿出的"髓室"矿道,以及堤坝式防洪墙
- 环境如何影响生活:潮涨农耕渔猎、潮落掘髓;净水与潮髓的双重稀缺塑造了阶级差序
- 备注:稀缺资源(潮髓、净水)都追得到社会影响与冲突,交通难点与后面维度的"贸易常被贵族把持"一致。

【三、种族生态】
- 主要智慧种族:岸民(人类)、根系贵族(与树根共生的长寿变种)
- 次要种族:盐裔(水栖,能短暂离水,被边缘化)
- 标志性生物:潮汐巨树(兽性与植物性兼具的共生母体)、深渊暗根
- 常见动物:逐潮鱼、在根上筑巢的藤鸟
- 家养动物:藤鸟(传讯)、潮羊(肉与毛纤维)
- 宠物/坐骑:少数贵族驯养巨鳐于浅海行驶
- 最早文明种族:根系贵族——潮汐巨树文明的后裔,掌握潮髓知识的源流
- 最年轻种族:岸民——靠早期开垦浮岛兴起的农渔业人群
- 种族关系:贵族以"守树者"自居垄断潮髓;岸民承担掘髓与供血役;盐裔世代受排挤(利益+历史双重根源)
- 是否有共同祖源:传说共源于潮汐巨树,但缺乏实证,贵族刻意淡化
- 特有生理特征:贵族皮肤木质化、寿命数百年、不惧潮水;盐裔鳃裂与鳞甲;岸民无特殊生理
- 常见外观差异:贵族呈青褐树纹肌理与琥珀瞳,盐裔偏蓝灰鳞,岸民偏浅麦色
- 与环境的关系:贵族依赖树根内部生态存活,离开浮岛会逐渐失能→与"世界规则"闭合
- 优势行业/职能:贵族=祭司/开采/驭潮;岸民=农耕渔获/航运/掘髓苦役;盐裔=浅海捕捞与珍珠采捞
- 生物禁忌:私自培育树苗、以刑器具采挖"母根"皆为大忌
- 备注:种族关系建立在利益与历史之上,正因为树在枯死,贵族才更急切向岸民与盐裔搜刮潮髓——关系有当下张力。

【四、世界规则】
- 魔法是否存在:存在,但为"潮髓"所限的低魔体系
- 获取方式:饮入潮髓碎屑、或经由"髓链"植入体表;贵族通过髓室大规模提取
- 使用代价:每次施术损耗寿命与记忆(失忆片断),重度成瘾后沦为"髓役"
- 限制/禁忌:离开浮岛潮髓环境即逐渐失能;深层"母根"髓不可触碰(会反噬使用者)
- 谁能使用:理论上人人可作短期施术,实则潮髓被贵族垄断,平民仅靠潮落浅层残屑
- 学习方式:贵族祭司在"髓堂"口传身授,民间禁习深层术式
- 科技水平:前工业——魔法辅助的航船、汲水、防波,无火器与机械
- 通讯手段:藤鸟传讯、潮音号角、季风信标接续
- 能源来源:潮髓为主,辅以风帆、潮汐机
- 医疗方式:祭司 "髓愈" 治疗高昂,下层靠草药与经验
- 教育/研究机构:髓堂(贵族垄断知识与河源)、商会学徒制
- 关键发明:髓灯、髓链植入术、逐潮罗盘
- 常见工具:掘髓铲、髓灯、藤鸟笼、潮麻帆
- 超自然现象:新月髓潮、枯根低啸、深渊暗根反噬之夜
- 魔法与科技关系:互补但被权力截断——理论可让全体受益的技术被垄断成特权
- 备注:每个力量都有代价与边界,魔力垄断正好制造 "能用却用不起" 的张力,符合低魔定位。

【五、社会信仰】
- 政体/统治形式:贵族邦联 + 各岛"长老会",实权在垄断髓室的诸位元老
- 重要城市/据点:母树悬城(政教中心)、潮港(贸易)、礁链湾(盐裔聚集)
- 权力来源:对潮髓的持有与"守树者"的合理叙事
- 主要宗教:泛灵树神崇拜——潮汐即祈祷,树即世界之骨
- 法律执行者:贵族执法队("髓卫")与长老会判例
- 神明是否真实:不直接显形;树确实具备兽性意志,但"神"的社会叙事由贵族操纵(可留作转折)
- 社会阶级:根系贵族 > 自由岸民 > 债役民 > 盐裔
- 节日/仪式:潮落采髓节、新月髓潮祭、植根礼(新生婴孩以树皮礼束腕)
- 常见职业:掘髓役、渔农、航商、祭司、髓愈师、藤鸟信使、珍珠采捞
- 社会禁忌:触碰母根、私自育苗、在髓堂外谈论"神是否垂死"
- 货币形式:潮髓碎屑为硬通货,并存贝币与盐券作小额
- 价值观:以"守树、守序、守根"为纲,下层则以"活过这场潮"为日常伦理
- 主要产业:潮髓开采、渔盐、潮麻纺织、环岛航运
- 秘密组织/地下势力:走私潮髓的"潮农会"、盐裔的"暗潮盟"、以及一批暗中护树的失势祭司
- 贸易路线:主环岛季风航路为贵族税卡;礁链湾附近存在走私水道
- 备注:社会阶级从潮髓稀缺与种族关系推导;每条禁忌都追得到信仰(树神)与权力利益(保护垄断),非孤立设定。

【六、历史与冲突】
- 起源/创世传说:潮汐巨树是"世界的骨",浮陆由树根托举而生
- 重大历史事件:三百年前"大潮震"浮岛大重组,近百座孤岛沉入深渊
- 古代文明:潮汐巨树文明(根系贵族的直接先民)留下的髓室与刻纹
- 重要历史人物:古树王"剖根者"(传说中首开髓室者);百年前主张共髓的祭司"明桡"(被处决)
- 学界争议:树是否只有一棵"母种";渊底的暗根是否吞过大潮震的海陆
- 当前世界局势:树渐枯,潮髓逐年减产,贵族加速向债役民与盐裔搜刮维持挥霍
- 主要战争:百年前"共髓战争"(明桡之乱),现多为压缩为税卡与缉私摩擦
- 外部威胁:无光深渊的"暗根"势力时有侵蚀边缘浮岛
- 内部矛盾:贵族垄断 vs 岸民承受挖掘/供血役;盐裔的长期被边缘化;失势祭司的护树主张
- 失落之物/遗迹:母种所在、古髓室的完整刻纹、"共髓时代"的髓铣工艺
- 传说/预言:"树倒之日,海吞万岛"——被当作恐吓下层守序的谶语,也暗示真实危机
- 冲突受益者:垄断商团与部分元老(搜刮潮髓的既得利益)
- 冲突受害者:债役民、盐裔、以及因树死而最先失去庇护的底层聚落(均由第三节/第五节推出,非临时添加)
- 当前危机:潮髓减产引发链式坍缩——供水、航运、治安全面承压
- 剧情钩子:洱音在枯根深处发现一株仍活着的母种幼苗,成为"神是否垂死"与贵族垄断合法性的爆点
- 备注:当前局势由资源(潮髓枯竭)与垄断(贵族)推出;剧情节子直接落到具体、可取的冲突点。

【七、生活与视觉】
- 普通人的一天:潮落掘髓或潮涨农渔;用髓灯下井,傍晚以藤鸟传讯、赶在风暴前回港
- 衣食住行:潮麻与树皮布;住依根而建的悬屋;出行靠舢板与藤桥
- 家庭结构:多代同住,掘髓与渔获分工明确
- 教育方式:平民学徒制+口头潮历;贵族族学在髓堂
- 婚丧习俗:以树皮礼束腕结亲;死者骨殖沉入潮间带"归于树根"
- 娱乐/艺术:髓光雕刻、潮汐歌谣、季节竞技(潮中竞舟)
- 语言/文字:通用"潮语"、盐裔的哨语、贵族刻纹文
- 礼仪/社交:见面行"按根礼";对贵族须垂目示敬
- 健康/卫生观:重湿气养生,潮疫被视为潮髓失衡之罚
- 审美偏好:偏嗜青绿潮色与琥珀髓光,器物重圆润木感
- 主色调:青绿(潮)为主,琥珀(髓)点缀,深青(深渊)衬托
- 建筑语言:依树根盘错的悬屋、悬桥、髓室巢窟,垂直依附而非平面铺城
- 服装轮廓:下层短褐潮麻束腿,贵族长袍镶木质鎏纹与琥珀扣
- 道具系统:掘髓铲、髓灯、藤鸟笼、逐潮罗盘、髓链(贵族/髓役)
- 图案/符号:潮汐纹、树轮年徽、树的血管状刻纹
- 光影/氛围:潮水中透下的青绿光斑、髓灯的琥珀光、深渊方向永不透光的沉黑
- 备注:主色调/建筑/服装/符号均由地理(水与树根)与资源(潮髓)与信仰(树神)推导,是生态奇幻统一质感而非拼贴名词。

【无法自决的矛盾】
无——示例设定内未出现两条创作事实的真正冲突;若有,此处列矛盾来源与受影响维度并交用户裁决。
```

> 教学说明：
> - 「地理」的稀缺资源箭头指向「社会」的垄断与「历史」的危机,「种族」的贵族失能设定回扣「规则」的环境依赖——展示因果推导链。
> - 「历史」的受益者/受害者由已有维度推出而非临时添加;「社会」的禁忌均有信仰/权力来源。
> - 未承担故事功能的细节(如个别地名、动物名)保留在最简程度而未堆砌;低相关条目按深度校准处理。
