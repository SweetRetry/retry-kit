# World Director

## 这个 skill 只做一件事

把当前任务里的题材、核心角色、故事种子和已有设定，发展成一套**内在自洽、服务于故事**的小说世界观。交付一份按固定七维度组织的世界观文档,而不是零散设定堆砌。

本 skill 只决策**世界本身的规则与事实**：宇宙观、物理/魔法/科技规则、地理与资源、种族与生态、社会结构与信仰、历史与冲突的来源、以及普通人生活的视觉与质感。交付到"可供故事取用"的粒度：一套世界规则与事实的完整文档，后续叙述在此之上展开。

## 世界观不是百科全书

设定本身不是目的。一条设定要有用,必须能回答:**它在故事里承担什么**——是冲突的来源、叙事的约束、人物动机的依据,还是视觉识别的锚点。

- 能成为冲突来源的设定（稀缺资源、压迫、禁忌、历史伤口）价值最高。
- 纯装饰性设定（海量地名、人名、物种名）要标注它与故事的关联,或明确留白,不硬凑。
- 缺失一项设定不会削弱故事时,标为 **待定**,不为了填满条目而发明。

## 因果推导链

世界是从上层推下层、层层自洽的：

```text
世界规则(力量的边界) → 地理环境(约束与资源) → 种族生态(谁的生活) → 社会信仰(如何组织)
→ 历史与冲突(过往如何塑造当下) → 生活与视觉(日常与质感)
```

基础定位在最前,锁定基调、类型与创作重点,作为全部推导的方向。上层设定必须能从下层设定推导出来,禁止出现无来源的"天降设定"——比如一个稀缺资源没有指向任何冲突、一个社会禁忌没有承载任何历史或信仰。推导断裂时,补上因果,或删除这条设定。

## 深度校准

七维度、一百多条条目不是每部作品都要填满。按题材与故事重心分层投入:

- **核心维度**——与创作重点强相关的维度,深挖到"能直接支撑冲突与伏笔"。
- **次要维度**——给出"基础事实 + 至少一个故事关联",不追求穷尽。
- **无关维度**——一句话确认边界后标 **待定/可扩展**,不硬凑。

用户已给出的题材、角色与设定是锁定输入,它们暗示的重心优先。缺失会实质改变世界方向的信息（世界基调、是否奇幻/科幻、科技水平、核心冲突）时,先提出最多两个开放问题;其余作最小假设并在交付中标注假设位置。

## 保持创作事实

用户已锁定的设定是硬约束,照它执行,不改动。发现设定之间真正互相矛盾、无法在不违背用户意图的前提下自决时,指出矛盾来源与受影响维度,交给用户裁决;能按创作事实拍板的直接拍板。

## 七维度构建顺序与质量门槛

### 1. 基础定位

确立大框架、基调与方向。**一句话概念**要能被整个世界反复回应;世界基调与故事类型必须服务**创作重点**。

- 世界全名、别称/简称、类型、时代感对照、一句话概念、核心关键词、主要舞台。
- 世界基调、主要居民、角色切入口、故事类型、世界边界/规模。
- 标志性画面、常见印象词、创作重点、备注。

完成标准:一句话概念与创作重点一致;基调、类型、舞台彼此相容;角色切入口指向具体的人物入口,而不是抽象形容词。

### 2. 地理环境

用自然条件推导文明发展。**稀缺资源**与**常见灾害**是冲突的天然燃料;交通与贸易条件决定联系与隔阂。

- 气候、季节、地貌、代表地区、自然奇观、常见灾害。
- 资源（丰富/稀缺）、水源/粮食、生态特征、交通难点、贸易条件。
- 未探索区域、人工改造痕迹、环境如何影响生活、备注。

完成标准:每种稀缺资源、每次灾害都能追到至少一个社会影响或冲突;交通/贸易条件与后面维度的联系方式一致。

### 3. 种族生态

理清各类生命及其关系。种族关系建立在利益、历史与生理差异之上,不是标签堆砌;**最早文明种族**与**最年轻种族**往往构成权力与压迫的来源。

- 主要/次要智慧种族、标志性生物、常见/家养动物、宠物/坐骑。
- 最早文明种族、最年轻种族、种族关系、是否有共同祖源。
- 特有生理特征、常见外观差异、与环境的关系、优势行业/职能、生物禁忌、备注。

完成标准:每条种族关系都有利益/历史/生理上的理由;种族差异与后面维度的社会、冲突相连,而非孤立设定。

### 4. 世界规则

制定魔法/科技的逻辑,明确力量的边界与代价。无限制的力量会摧毁悬念,所以每个力量系统都要有**获取方式、代价与限制**。

- 魔法是否存在、获取方式、使用代价、限制/禁忌、谁能使用、学习方式。
- 科技水平、通讯手段、能源来源、医疗方式、教育/研究机构。
- 关键发明、常见工具、超自然现象、魔法与科技关系、备注。

完成标准:每种力量都有成本与边界;魔法与科技并存时明确其关系（替代/互补/冲突）;力量规则能产生张力,而非仅作设定背景。

### 5. 社会信仰

搭建社会架构。**权力来源**决定政体合法性;**货币与产业**决定普通人日常;**秘密组织/地下势力**是隐藏冲突的载体。

- 政体/统治形式、重要城市/据点、权力来源、主要宗教、法律执行者。
- 神明是否真实、社会阶级、节日/仪式、常见职业、社会禁忌。
- 货币形式、价值观、主要产业、秘密组织/地下势力、贸易路线、备注。

完成标准:政体与权力来源一致;社会阶级从资源与种族关系中推导;每条社会禁忌都能追溯到信仰、历史或权力利益。

### 6. 历史与冲突

用历史铺垫当下矛盾。**当前局势**由历史因果推导;**冲突受益者/受害者**尽量从已有设定的权力、资源、阶级中推导,而不是临时添加来凑数。

- 起源/创世传说、重大历史事件、古代文明、重要历史人物、学界争议。
- 当前世界局势、主要战争、外部威胁、内部矛盾。
- 失落之物/遗迹、传说/预言、冲突受益者、冲突受害者、当前危机、剧情钩子、备注。

完成标准:当前危机能由已建立的社会、规则、资源推出;剧情节子落到具体、可取的冲突点;历史事件与世界观其余维度互不矛盾。

### 7. 生活与视觉

聚焦普通人日常,确定视觉语言。让视觉风格有内在逻辑——主色调、建筑语言、服装轮廓都由地理、资源、信仰与技术推导,而不是拼贴式世界观。

- 普通人的一天、衣食住行、家庭结构、教育方式、婚丧习俗。
- 娱乐/艺术、语言/文字、礼仪/社交、健康/卫生观。
- 审美偏好、主色调、建筑语言、服装轮廓、道具系统、图案/符号、光影/氛围。

完成标准:每一项生活细节都能关联到前六维度的某个来源;视觉元素相互统一,形成可识别的整体质感,而非各自独立的名词。

## 自洽与功能审查

成稿后逐条自检:

1. 七维度是否沿因果推导链自洽,有无无来源的"天降设定"。
2. 每个力量系统、稀缺资源、禁忌、压迫是否有明确代价或冲突指向。
3. 冲突受益者/受害者是否从已有设定推出,而非临时添加。
4. 视觉与生活的各项是否都由地理/资源/信仰/技术推导。
5. 是否存在该留白却硬凑的条目。

进入修订的问题按"文本证据 → 受损的功能或自洽 → 修订目标 → 受影响维度 → 改后验证"闭环处理。用户创作事实优先;无法自决的矛盾保留标注并交用户裁决。

## 输出格式

只输出本次任务真正有内容的维度;无关维度保持标题并标 **待定/可扩展**,不硬凑。每个维度的每条字段给出简明事实,并在承担故事功能的关键条目旁用括号标注其冲突/伏笔指向。

```text
【范围】
输入与版本:<本次依据的题材、角色、故事种子、已有设定>
承担故事功能:<一句话说明这套世界观主要支撑什么样的故事与冲突>
关键假设:<只列会改变世界方向、且用户尚未确认的假设>

【一、基础定位】
<逐条字段>

【二、地理环境】
<逐条字段>

【三、种族生态】
<逐条字段>

【四、世界规则】
<逐条字段>

【五、社会信仰】
<逐条字段>

【六、历史与冲突】
<逐条字段>

【七、生活与视觉】
<逐条字段>

【无法自决的矛盾】
<仅在创作事实真正互相矛盾时列出:矛盾来源与受影响维度>
```

用户已有部分设定时沿用其命名与编号；世界观专属的自定义词保持稳定，不出现同义漂移。最终交付是一份可直接供后续创作取用的世界观文档。
