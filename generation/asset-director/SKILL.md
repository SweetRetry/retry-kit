# AIGC Asset Director

## 这个 skill 只做一件事

对故事里出现的每个角色、场景、元素,只问一个问题:

> 是否有一张**参考图**能提供文字达不到的跨画面锁定信息（对象身份、空间几何）？

回答"是"的,决定是**复用**已有的、还是**新建**一张,并说清它长什么样、锁哪些属性、在什么状态下用。回答"否"的,把它交给最终 prompt 用文字承载。

本 skill 只决策**对象级控制**:角色或道具的身份、固有配色与材质、独有纹样,以及场景的结构、尺度、关键位置与固定布景。跨画面通用的媒介、笔触、全局色彩体系、材质渲染方式、光影逻辑与情绪基调属于**成像风格**,作为文本规范读取,不构成新增图片资产的理由。上下文附带文本风格规范或风格参考时,把它们当作创作事实读取,让素材计划与其对齐。

## 资产 = 可复用、可 lock 的图

AIGC 工作流里,"资产"约定俗成指可复用、可 lock 的图片参考——角色身份图、场景 plate、道具身份图。一张身份图能同时锁形制、比例、对象固有材质与配色及几何,信息密度远高于同等成本的其它介质,也是生成模型最稳的对象级控制入口。跨画面通用的成像风格由文本规范承载。

本 skill 的产出就是这份**图片参考素材库**。范围到"哪些对象需要图、每张图锁什么、什么状态下用"为止。

**这些内容作为下游生产环节的执行需求处理,不进本文档:**

- **过程性动作、接触关系、运镜、节奏、构图**：镜头级控制,在描述具体 shot 的画面变化时说清。
- **声音（对白、声线、环境声、音效）**：交给最终 prompt 或后期。
- **可文字化的动作细节、状态属性变化、次要装饰**：写进最终生图/生视频 prompt。

## 入库判断

**按"跨画面复用"和"文字够不够"两条判断,不按"剧本里有没有"判断。**

一个角色反复出现要长成同一个人、一个场景反复出现要是同一个地方——这类"跨画面锁同一个对象身份或空间几何"的需求,只有图能稳。这是入库的核心理由。

一个只出现一次、文字就能稳定画出来的杯子,用文字承载即可。一个没名字、却要跨多个画面保持同样形状和损伤的杯子,才需要参考图。

只服务单个画面的构图、动作、接触、运镜是镜头层的执行需求,在描述该 shot 时说清即可。

## 三个决策

对每个角色/场景/元素:

- **文字** —— 模型能稳定生成,对象身份或空间几何没有额外控制需求。写进 prompt 即可。
- **复用** —— 已经有一张合适的图（用户提供的、或已成功生成后回流的）,直接拿来用。
- **新建** —— 缺一张能提供不可替代锁定信息的权威图,需要先做出来。

关键事实互相矛盾、无法判断该锁哪个状态时,标 **冲突**,交给用户裁决。

## 每张参考图要说清三件事

**只正向描述素材本身。** 每张图只说清"它长什么样、锁什么、匹配哪个状态":画面里画了什么、留白与背景是什么、锁哪些属性。要限定范围,就用一个明确的、可描绘的正向场景（纯色底、空景 plate、留白构图）把范围直接画出来。人物走位、屏幕方向、剪辑点等由镜头层处理——一张空间图锁的是"这个地方长什么样",走位由分镜决定。

1. **是什么** —— 一张具体、能定位的图（角色身份图、场景 plate、道具身份图……）,用具体形态描述,不用"史诗感""悲伤氛围"这种词冒充素材。
2. **画面长什么样 + 锁哪些属性** —— 用自然语言正向说清整张图里画了什么（主体形态、姿态、比例、背景与留白）以及需要锁定的对象级属性（形制、固有配色、固有材质、独有纹样、结构与位置关系等）。比如"横版三视图身份图,一名同款剑士呈正面 / 3-4 侧 / 侧身跑动三态,身后是纯浅灰底,锁脸型、发色、巨剑形制与铠甲固有配色";再如"9:16 竖版空景 plate,画面里是空赛道、空看台与固定灯架,锁赛道宽度、弯道曲率、看台层级和灯架位置"。
3. **什么状态下用** —— 图要匹配当前叙事时点的状态,把角色某一阶段的形态明确绑定到对应画面。

## 先建连续性清单,再检查单次控制需求

拆之前,按叙事顺序列出所有需要跨画面保持一致的东西,以及它们会怎么变化:

- 谁/什么（角色、物件、地点、反复出现的视觉母题）
- 它必须保持不变的特征是什么
- 它在哪个叙事时点发生状态改变、之后如何延续

状态变化怎么处理,取决于新状态的差异靠什么才能稳住:

- **差异靠文字能稳定复现的,共用主体图,状态差异写进 prompt。** 一致性锚点（哪只手、哪把剑、哪枚徽记的形制）由主体图锁着,可描述的属性变化（血由鲜红变干涸、衣服由干净变脏、灯由亮变灭）交给文字。
- **差异是模型编不稳、又要跨画面反复出现的独有形态时,新建该状态的图。** 比如一处独一无二的破损变形、一块特定的断口——文字说不清"它长什么样",且后续多个画面要保持同一个样子。
- **一个对象要为多个状态做图时,优先用一张横版多状态图承载。** 把同一对象的几个形态（如完整 / 受损）并排放进一张图（类似角色三视图）,模型能直接看到"这是同一个东西、只是换了形态",一致性最稳。当某个状态复杂到并排放不下、或必须单独喂参考时,才拆成独立的图。
- **状态变化是过程的（逐齿碎裂、断裂坠落、贴地擦过）,交给镜头层描述。** 图锁不住过程,这类内容属于镜头层的画面变化。

这张清单是 asset 的全部工作范围——决定哪些角色、场景、元素因**跨画面对象身份或空间几何一致性**需要图片参考。

## 独立职责

这个 skill 单独运行。输入可以是模糊想法、完整剧本、分场、shot list、图、素材目录,或它们的任意组合。

保持输入里的创作事实。发现冲突时,指出冲突来源和受影响的素材,交给用户裁决,保持剧情不变。

**能按创作事实拍板的,直接拍板。** 输入（剧本、附录、导演意图）已经锁死答案的,照它执行,直接决定并写进计划。这类判断在本 skill 职责内:一份素材做成一张还是几张、某个状态并入还是单出。只有两条创作事实**真正互相矛盾、无法在不改剧情的前提下自决**时,才把这一处指出来交给用户。

素材变化后,输出影响范围:哪些参考**新增 / 变了 / 作废 / 不受影响**。

## 输出格式

只输出本次任务真正有内容的部分。

```text
【范围】
读了什么:剧本 / storyboard / 已有素材的版本。本文档只收跨画面复用的图片参考;过程性动作、镜头级构图/运镜、声音在连续性清单里点明去向后,交给下游环节。

【连续性清单】
| 名称 | 类型 | 必须保持一致的特征 | 状态怎么变（在哪个叙事时点、变成什么） | 是否入素材库 |
入库理由：跨画面复用 + 文字锁不住。不入库的条目一句话说明去向（镜头层描述 / prompt / 后期）。

【参考素材库】
两级组织：先按大类分节（角色 / 场景 / 元素）,大类内按对象成块。同一对象的不同状态是它名下的多行;某个对象只有一个状态就只有一行。

大类归属:
- **角色**:有身份的人、有身份的载具（车、机甲、飞船等承担叙事身份的载具）与它们的贴身附属物。角色的身份图、状态图、贴身道具（方向盘上的贴标、随身武器、专属头盔）都挂在这个角色名下。
- **场景**:空间基准——描述"这个地方长什么样"（关键位置、结构、尺度、固定布景与对象固有属性）。跨画面通用的色彩、光影与材质渲染方式沿用文本风格规范。
- **元素**:不属于任一角色的独立道具,或贯穿全片、需要跨画面保持一致的可复用视觉图形母题。

| 对象 | 图（状态） | 画面长什么样 + 锁哪些属性 | 用在什么状态/哪些画面 | 来源（已有/待做/生成回流） | 文字 / 复用 / 新建 |

【制作顺序】
先做被最多画面复用的身份图、空间图;再做由它们派生的、必须新建的状态图;能靠成功生成结果回流的放最后。

【无法自决的矛盾】
仅在两条创作事实真正互相矛盾、无法在不改剧情的前提下拍板时出现,列出矛盾来源和受影响的素材。能自己按创作事实决定的直接写进上面的计划。
```

只有剧本、没有已成型的素材编号时,素材库自建稳定的临时名称。输入已有素材编号和文件名时沿用。
