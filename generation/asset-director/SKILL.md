# AIGC Asset Director

## 核心问题

对每个角色、场景、元素只问一件事：

> 是否有一张**参考图**能提供文字达不到的跨画面锁定信息（对象身份、空间几何）？

是 → 决定**复用**已有、还是**新建**一张，并说清它长什么样、锁哪些属性、什么状态下用。否 → 标 **文字** 承载。

本 skill 只管**对象级控制**：角色/道具的身份、固有配色与材质、独有纹样，场景的结构、尺度、关键位置与固定布景。跨画面通用的媒介、笔触、色彩体系、光影、情绪基调属于**成像风格**，由文本规范承载，不构成新增图片资产的理由。

## 复用判断

**按"跨画面复用 + 文字够不够"判断，不按"剧本里有没有"判断。**

- **文字** —— 模型能稳定生成，无额外锁定需求。写进 prompt。
- **复用** —— 已有合适参考图（用户提供 / 成功生成后回流），直接拿来用。
- **新建** —— 缺一张不可替代锁定的权威图，需先做出来。

反复出现要长成同一个人的角色、要是同一个地方的场景，只有图能锁稳，这是入库核心理由。只出现一次、文字就能画出的杯子走文字；没名字却要跨多画面保持同样形状与损伤的杯子才需要图。

关键事实互相矛盾、无法定锁哪个状态时标 **冲突**，交用户裁决。

## 连续性

拆之前，按叙事顺序列出所有需跨画面保持一致的对象，及其变化：

- 谁/什么（角色、物件、地点、反复出现的视觉母题）
- 必须保持不变的特征
- 在哪个叙事时点改变、之后如何延续

状态变化按"新状态差异靠什么稳住"处理：

- **文字能稳复现的** → 共用主体图，差异写进 prompt（血变干涸、衣变脏、灯熄灭）。一致性锚点（哪只手、哪把剑、哪枚徽记）由主体图锁着。
- **模型编不稳、又要跨画面重复出现的独有形态** → 新建该状态图（一块特定断口、一处独一无二的破损）。
- **一个对象多状态** → 优先一张横版多状态图（并排放完整/受损，模型能看出"是同一个"）；放不下或必须单独喂参考才拆独立图。
- **过程性变化**（逐齿碎裂、断裂坠落）→ 这类过程由镜头层描述。

## 角色 / 道具 / 资产

素材库两级组织：先按大类分节，大类内按对象成块。同一对象的不同状态是它名下的多行；单状态就一行。

- **角色**：有身份的人、承担叙事身份的载具（车、机甲、飞船）与贴身附属物。身份图、状态图、贴身道具（随身武器、专属头盔）都挂在该角色名下。
- **场景**：空间基准，描述"这个地方长什么样"（关键位置、结构、尺度、固定布景）。色彩、光影、材质渲染沿用文本风格规范。
- **道具 / 元素**：不属于任一角色的独立道具，或贯穿全片、需跨画面保持一致的可复用视觉图形母题。

每张参考图只正向说清三件事：**是什么**（角色身份图 / 场景 plate / 道具图，用具体形态，不用"史诗感"冒充素材）、**画面长什么样 + 锁哪些属性**（主体形态、姿态、比例、背景留白 + 形制、固有配色、固有材质、独有纹样）、**什么状态下用**（匹配当前叙事时点）。要限定范围就用可描绘的正向场景（纯色底、空景、留白构图）把范围画出来；人物走位、屏幕方向、剪辑点由镜头层处理。

## 独立职责

单独运行，输入可为模糊想法、剧本、分场、shot list、图、素材目录或其组合。保持输入里的创作事实；能按创作事实拍板的直接拍板（一份素材做一张还是几张、某状态并入还是单出）。只有两条创作事实真正互相矛盾、无法在不改剧情的前提下自决时，才指出矛盾来源与受影响素材交用户裁决。素材变化后输出影响范围：哪些参考**新增 / 变了 / 作废 / 不受影响**。

## 输出格式

只输出本次任务有内容的部分。

```text
【范围】
读了什么：<剧本 / storyboard / 已有素材版本>。只收跨画面复用的图片参考；过程性动作、镜头级构图/运镜和声音仅记录为非资产约束。

【连续性清单】
| 名称 | 类型 | 必须保持一致的特征 | 状态怎么变（叙事时点、变成什么） | 是否入素材库 |
入库理由：跨画面复用 + 需跨画面保持同一身份或空间几何。不入库条目一句话说明控制方式（镜头/文本/声音约束）。

【参考素材库】
大类：角色 / 场景 / 道具·元素
| 对象 | 图（状态） | 画面长什么样 + 锁哪些属性 | 用在什么状态/哪些画面 | 来源（已有/待做/生成回流） | 文字 / 复用 / 新建 |

【制作顺序】
先做被最多画面复用的身份图、空间图；再做派生的、必须新建的状态图；靠生成回流放最后。

【无法自决的矛盾】
仅在两条创作事实真正互相矛盾、无法不改剧情自决时出现，列矛盾来源与受影响素材。
```

只有剧本、没有成型素材编号时自建稳定临时名称；输入已有编号时沿用。
