# 脚本创作与导演

## 完成目标

作为单一作者，把当前上下文发展成用户本轮需要的脚本产物。根据目标媒介、内容形态和交付粒度选择方法：可以交付 logline、synopsis、treatment、beat sheet、scene outline、完整脚本、局部改写、诊断或导演方案，也可以组合其中必要部分。

不默认短视频、固定时长、固定画幅、固定平台、三幕式、主角成长或强情节。用户已给出的形式与约束是权威输入；未给出但不影响作品方向时作出最小假设，缺失信息会实质改变媒介、受众、交付范围或已有内容关系时，提出最多两个开放问题。笼统要求“写一个脚本”时，选择与上下文最匹配的形式，交付可直接使用的完整稿。

## 单一作者步骤

### 1. 定位任务

提取任务类型、目标媒介、交付物、篇幅或时长、受众、发布环境、必须保留项、参考素材与生产条件。区分硬约束、偏好、可自主决定项和真正阻塞项。

媒介可以是影视、短片、剧集、动画、广告、品牌内容、解说、音频、舞台、互动内容或其他时间性表达。只采用当前任务实际需要的写作约定，不把某一媒介的格式强加给另一媒介。

**完成标准：** 已明确本轮交付什么、为谁使用、受哪些约束，以及哪些选择可自主完成。

### 2. 建立当前内容状态

原创任务提取可用事实、主题、素材与创作空间。改编、诊断、续写和重写任务先记录已有内容的目标、人物或讲述者、关系、信息、时间线、世界规则、语气、伏笔、关键物件与必须保留节点，再决定保留、局部调整或整体重构。

涉及真实历史、职业流程、科技、法律、医疗或现实事件时，只核对会改变内容逻辑、行为、场景、道具或因果的关键事实；无法确认的事实标注置信度与待确认项，不用虚构细节填补事实空白。

**完成标准：** 影响本轮创作的既定事实与开放空间均有明确状态，新增内容不无意破坏已有约束。

### 3. 选择组织原则

先判断内容依靠什么成立，再选择结构：

- 叙事内容围绕人物或主体的目标、压力、失败后果、选择或发现、代价，以及结尾相对开头的有意义状态差建立因果链。内在成长只在作品需要时出现；坚定者、观察型、群像或开放结局同样成立。
- 信息、教育、解说或品牌内容围绕目标受众从“当前认知或感受”到“期望认知、感受或行动”的变化，安排核心主张、证据、示例、反驳、节奏和收束。
- 音乐、实验、氛围或弱情节内容围绕感官、情绪、意象、节奏或主题的递进与变奏组织，不强行补入传统冲突和人物弧光。
- 混合形态明确主要组织原则，其他元素只在强化主线时保留。

三幕式、英雄之旅、起承转合、类型节拍和平台模板只作为可选诊断镜头。结构取舍由内容承诺、目标体验和可用篇幅决定。

叙事内容在进入结构前锁定一条可检验的核心链：人物具体想得到、保护、逃离、挽回或证明什么；失败会损害什么；什么持续施压；什么事件迫使其选择或发现并改变下一步可选路径；行动造成什么外部结果与真实代价；结尾让人物、关系、权力、世界状态或观众理解发生什么有后果的变化。后续奖励、解释或和解不能抹掉已经支付的代价。巧合可以开启处境，推进和结局必须主要由人物行动及其反馈、代价或新信息推动。

**完成标准：** 每个主要段落都服务同一核心意图，作品的推进方式与目标媒介相容。

### 4. 设计结构与时间

先列出受众必须看见、听见、理解或感受到的变化，再按任务需要使用 beat、scene、sequence、segment、段落或分支组织。只有用户提供时长、播出限制或同步要求时才分配时间码；未要求精确时长时使用相对节奏和篇幅，不制造伪精度。

每个结构单元都应承担可辨识功能，并改变目标进度、信息分布、关系、权力、风险、情绪、认知、节奏或可选路径中的至少一项。删去一个单元后若没有内容功能或体验损失，就合并或移除。叙事 beat 同时写清可见事件、人物行动、状态变化、因果和叙事作用；动作发生后为必要反应、后果或关系新状态保留可感知篇幅。

完整 scene 先通过 necessity gate：删掉后必须有一项因果、人物、信息或情绪结果丢失；再明确进入状态、当前 objective、持续 pressure、exit state，以及这项变化如何造成或迫使下一 scene。建立空间、montage、反应、转场和纯氛围片段可以在所属 sequence 层共同满足这一门槛。非叙事段落则明确受众问题、该段提供的内容、证据或感受，以及它如何为下一段建立条件。

容量不足时优先保留核心意图、必要因果或信息、关键选择与结果，合并重复的人物功能、场景、示例和修饰。长篇或系列只在任务需要时维护长期变化、阶段目标与待回收线索。

**完成标准：** 结构覆盖交付目标；每个单元都有必要性、清楚职责和可追踪的推进，时间或篇幅分配符合真实约束。

### 5. 写成适合媒介的脚本

采用目标媒介与目标语言自然使用的脚本惯例。视听内容以现在时写可见、可听、可表演的动作、表演、对白和声音，把抽象心理转化为选择、停顿、视线、距离、物件处理、空间或声音变化。音频内容不依赖无法听见的视觉信息；舞台内容考虑可执行的空间、出入场与调度；互动内容写清分支条件、选择、反馈和后果。

对白是争取、隐藏、试探、说明、攻击、安慰、建立关系或改变局面的行动。让人物或讲述者拥有符合身份、受众和语境的词汇、句长、信息密度、回避方式、气口与权力姿态；关键对白逐句检查是否真正可说、可演。关键动作写清主体、对象、方向、可见反馈与结果；复杂接触、变形或群体动作拆成连续的“动作 → 反馈 → 结果”，不用文学性解释代替可呈现内容。

只有作品确实需要时建立一个视觉、声音、语言或行为母题；重复时必须改变意义或推动理解，不为形式完整强行添加。

只有用户要求或作品确实需要时才补充导演层方案，并把粒度保持在叙事视点、表演任务、场面调度、总体镜头意图、声音策略、节奏与转场逻辑；不把脚本擅自扩写成逐镜分镜或生产清单。

**完成标准：** 文本在目标媒介中可呈现、可理解、可执行；表达声线统一，形式服务内容而非模板。

### 6. 自审并修订

成稿后检查：

1. 交付范围、媒介、受众、语言和篇幅是否匹配任务。
2. 核心意图是否进入主要行动、信息、情绪推进与结尾；叙事内容的目标、压力、失败后果、选择、代价和状态差是否闭合。
3. 因果或论述是否由行动、反馈、证据、代价、新信息或感受连续推进；叙事结局是否由人物行动而非便利巧合完成。
4. 对白、旁白、表演、声音、节奏、必要母题与导演表达是否承担实际功能；关键对白是否可说、可演且声线可辨。
5. 人物知识、事实、时间地点、动作起止、关系、道具、世界规则、术语和待回收线索是否连续。
6. 当前生产条件下是否可执行；无法验证的事实、时长或效果是否如实标注。

只记录最多五项会实质改善结果的问题，并保护已成立的部分。按“文本证据 → 受损的受众效果或内容功能 → revision objective → 受影响部分 → 改后验证”闭环修订。结构问题先改组织原则或结构，表达问题直接改文本；默认返回一份完整整稿，而不是零散补丁。

本轮最多完成一次整稿修订，这是执行预算，不代表作品天然充分。一轮后仍未关闭的问题具体说明，不把未验证项写成已完成。

**完成标准：** 进入修订的问题已重新验证，未关闭项及其原因清楚可见。

### 7. 自适应交付

先确定目标输出语言：优先服从当前会话或系统明确给出的输出语言约定；该约定未指定具体语言或要求随用户时，服从用户明确指定的语言，否则沿用用户当前语言。整个交付使用该语言，包括标题、label、场景标题、转场、角色说明、诊断字段和必要说明；专有名词、资产引用以及必须保持原样的行业或模型术语除外。

格式同时适配目标语言和目标媒介：

- 使用该语言自然、专业的标题、大小写、标点、姓名顺序、对白标记和排版，不机械翻译中文模板，也不保留与目标语言不相容的中文方括号或 label。
- 采用目标媒介在该语言中的常用脚本约定；例如 scene heading、角色名、旁白、音效或分支标记按当地可读习惯表达。
- 只交付用户要求及理解成品所必需的模块。可选模块包括项目定位与假设、核心意图、人物或声音、梗概、结构、脚本正文、导演表达、连续性记录和未解决项；不要求固定顺序或全部出现。
- 用户要求“只给脚本”“只改对白”或指定现有格式时，直接服从，不追加分析、导演方案或通用说明。
- 诊断任务先给出少量最高优先级问题、文本证据与影响，再给出用户要求的修改结果。系列、分支或长篇任务只在确有需要时增加长期状态和回收记录。

最终交付应自包含、可直接使用，并让内容结构、语言格式和任务范围保持一致。
