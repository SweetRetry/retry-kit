# AIGC Generation Director

## 1. 导演工作流：别一上来就写剧情，先立拍摄方案

AIGC 视频创作最容易犯的错：**先想一出剧情，脑补震撼场面，提示词最后补一句“电影感、大片运镜”，然后让模型抽卡，结果次次跑偏。**

工业级 AIGC 导演的顺序是**反过来的**：
`全片拍摄规矩 (风格锁) ➔ 人物/场景/道具长相 (资产建档) ➔ 摄影机调度与因果剧情 (剧本分镜) ➔ 下游精准生成`。

不是写文学小说，而是在给 AI 生成团队做一份**能拍、能听、能演、不会互相打架的施工蓝图**。

---

## 2. 导演控场六大铁律 (Directorial Heuristics)

### 铁律 1：开拍先立规矩（风格锁 STYLE LOCK）
别用“高级感、史诗大片”这种模型听不懂的形容词。先定下全片的**拍摄制度**：
- **怎么拍**：是 35mm 胶片实拍质感，还是手持手机纪实跟拍？是宽银幕还是竖屏？空气里有没有丁达尔烟尘？色温偏冷还是偏暖？
- **负向红线立在前面**：明确告诉下游“绝不要什么”（例如：坚决不能变成 2D 动画、不要塑料 CG 质感、不要游戏过场感）。
- 风格定了，全片所有镜头必须在同一套制度下跑。

### 铁律 2：机位路线比人物动作更早定好
人物还没动，摄影机摆在哪、怎么走必须先定好。运镜不是动作做完后加的修饰，运镜是在控制**观众什么时候知道答案**：
- 想做悬念：先拍空景 ➔ 低机位环绕转体渐露背影 ➔ 逆光抬头确认身份 ➔ 运镜拉开揭露远处的巨大威胁。
- 想做压迫：先贴地拍空旷荒野 ➔ 远景逐渐逼近模糊黑影 ➔ 观众产生危机感后，再切高空俯瞰群体规模。

### 铁律 3：参考图必须划分权限，说清“管什么、不管什么”
多图参考时，模型最容易“抢控制权”（比如姿势图改了主角长相，背景图把衣服颜色染脏）。
导演建档与分镜时，必须给每张参考图定规矩：
- **不仅说管什么**：角色图管脸和衣服，道具图管结构材质，场景图管透视空间。
- **更要说不管什么**：姿势图只管肢体动作和构图，**严禁改变角色的五官、发型与服饰**；场景图只管光线和方位，**严禁干预人物固有色**。

### 铁律 4：动作全写成受力因果链，禁止空洞形容词
剧本和分镜里禁止出现“激烈打斗、力量感碰撞、震撼变形”这种废话。AI 模型不懂抽象情绪，只认物理因果：
- **受力因果链**：重剑从什么角度劈来 ➔ 砍在弯刀的哪个接触点 ➔ 弯刀如何受力弯曲 ➔ 对手上半身如何向后仰 ➔ 双脚如何在地面滑出擦痕。
- **结构变形因果**：触发点激活 ➔ 卡扣脱开 ➔ 外壳分离 ➔ 机械结构翻折与齿轮咬合 ➔ 液压伸缩 ➔ 卡死就位。
- 力量有来路、有受力形变、有环境反馈，动作才可信。

### 铁律 5：声音同步叙事，它是空间和重量的探测器
声音不是成片后加的“震撼配乐”，它在分镜阶段就承担叙事任务：
- 金属撞击声告诉观众这东西有多重；回声与残响告诉观众空间有多空旷；远处传来的呼喊交代空间纵深；画面外巨物的低频轰鸣在它露面前就建立压迫感。
- 局部动作与声音一一咬合（抛掷声、蓄能声、翻折咬合声、锁止声）。

### 铁律 6：尾帧必须留落幅，连续动作绝不提前刹车
很多 AI 生成片段结尾很僵，是因为只管动作怎么开始，不管怎么结束。
- 每个镜头必须定死落幅构图：摄影机最后停在哪？人物最后停在什么姿态？武器在哪只手里？
- **动势接力**：如果下一个镜头是连续动作，前镜尾帧机位和主体必须**保留向前冲的运动惯性**，严禁让模型在最后 1 秒提前减速站定。

## 3. 任务路由与 References

根据用户具体推进到哪一步，按需读取对应专业规范：

- **立规则与世界观**（力量代价、社会秩序、地缘与历史矛盾）：读取 [world-building.md](references/world-building.md)。
- **写剧本与改因果**（故事大纲、场次推进、视听外化动作与潜台词）：读取 [scriptwriting.md](references/scriptwriting.md)。
- **资产建档与立不变量**（主角/配角、主场景、关键道具与状态演变）：读取 [asset-breakdown.md](references/asset-breakdown.md)。
- **分镜拆解与组接装配**（Scene/Beat/Shot 切分、机位轴线、Generation Assembly 接力）：读取 [storyboarding.md](references/storyboarding.md)。

## 4. 输出交付准则 (Delivery)

- **讲人话、重可拍性**：所有设定和分镜全部落到“镜头看得到、麦克风录得到”的实处，杜绝文学性脑补。
- **信息分流，避免废话**：如果已经有完整分镜板，给下游生成时文字只补图上看不到的受力和声音；如果做资产设定，文字详尽定死不变量。
- **盯死全链路一致**：角色名字、道具称谓、场景编号从头到尾严格统一；发现上下游设定打架时，直接挑明矛盾请用户裁决。
