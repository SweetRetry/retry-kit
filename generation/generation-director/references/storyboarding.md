# Storyboarding (分镜拆解与生成装配)

## 1. 核心思路：把剧本翻译成 AI 拍得出的视听说明书

分镜不是画孤立的好看图片，而是把故事拆成模型能连续生成的单元：
推进顺序：`场景 (Scene) → 叙事节拍 (Beat) → 镜头设计 (Shot) → 模型生成单元 (Generation Assembly)`。
分镜设计要盯死两件事：**看着得有电影感**，同时**动作必须在 AI 模型的能力边界内，不能让模型算崩**。

## 2. 电影级视听语言体系

拆解镜头时，按叙事需要组合景别、机位与运镜：

### 景别划分与叙事作用
- **大远景 / 全景 (EWS / WS)**：交代宏大环境、地形规模、双方势力对峙与整体世界观氛围。
- **中景 (MS)**：拍人物半身互动、二人对话与人物在环境中的站位关系。
- **近景 (MCU / CU)**：聚焦面部表情、眼神微变化与情感冲突爆发点。
- **特写 / 大特写 (CU / ECU)**：关键道具、伤口细节或重要线索揭露，用于制造悬念与戏剧强化。

### 机位角度与视点
- **客观视角 (Objective)**：中立记录，保持观察距离。
- **主观视角 (Subjective POV)**：摄影机变成角色的眼睛，体验压迫、眩晕或窥探。
- **仰角 (Low Angle)**：给主体赋予压迫感、威严或强大力量。
- **俯角 (High Angle)**：凸显主体的渺小、受困或被监视状态。
- **倾斜构图 (Dutch Angle)**：营造心理失衡、危机来临或秩序崩塌。
- **看点进画**：本镜看点是谁的反应，机位就放在看得见那张脸的一侧；用背面、侧面或越肩机位时，确认看点仍在画内。

### 运镜动力学
- **信息时序调度 (Information Revelation Pacing)**：运镜是在掌控观众何时获得答案。善用“先给空景 ➔ 局部引导 ➔ 辨认主体 ➔ 运镜拉开揭示巨大危机”，运镜自己就在讲故事。
- **固定镜头 (Static)**：强调稳定、凝视，让画面内的人和物动作成为唯一焦点。
- **推进 (Push-in / Dolly In)**：加大紧张感，引导观众盯紧关键抉择或人物心理剧变。
- **拉出 (Pull-out / Dolly Out)**：由近及远揭示隐藏的环境真相，展现孤独感。
- **摇镜头 (Pan / Tilt)**：横移或上下扫视，建立空间连续感，或靠突然转头制造惊吓。
- **跟随镜头 (Tracking / Steadicam)**：跟着人物跑动或潜行，强化身临其境的现场感。

## 3. 空间不乱跑的铁律 (场面调度与连续性)

几个镜头剪在一起绝不能跳戏，必须守住三条底线：

### 180° 轴线原则（千万别乱越轴）
- 两人对话或对打时，中间画一条假想轴线；摄影机只能在这条线的同一侧半圆内拍。
- 绝不能无交代直接跳到另一侧（剪出来人左右视线会反向错乱）；真要越轴，必须拍一个正对中轴的中性镜头，或者用摄影机连续划过去。
- 越肩镜头写明是哪一侧肩，与轴线同侧；环绕运镜写明绕行的一侧。

### 视线与进出画方向一致
- **视线要对得上**：前一镜主角往右边看，后一镜被看的人或反应镜头就得在左边、往左看。
- **运动方向别倒流**：人从画面右边跑出去了，下一个镜头必须从左边跑进来，才能保证是一直往前跑。
- **全片方向约定**：跨场次的同一段旅程（去程与回程、追逐与逃离）各定一个画面方向，全片沿用。

### 光影与状态严格承接
- 主光源（阳光/窗户）在同一个场景里必须保持一个方向，不能前一秒夕阳在左后一秒在右。
- 哪只手拿枪、哪条腿受伤、衣服上的血迹，下一镜必须老老实实继承前一镜结束时的样子。
- 复用其他单元的首帧或关键帧时，光线、道具与人物状态随之继承；选来源时让这些状态与本镜开头一致。

## 4. AI 视频生成装配防翻车守则 (Assembly Rules)

按目标模型与入口的时长、素材和动作控制能力确定生成单元；复杂动作的拆分服务可读性与可控性，不套用统一时长上限：

### 动作量按模型能力定
- **以目标模型的实际能力为准**：一个生成单元承载的动作数、时长与场景跨度，以目标模型的官方能力说明或实测为准。模型可靠时，连续动作链、多镜头与一镜到底放进同一单元，让运镜与表演做足。
- **参考图只给本单元用到的**：单次不超过 9 张，即使模型上限更高；本单元用不到的服装、状态与道具不上传。
- **超出可靠范围时才拆**：动作链超出目标模型的可靠范围时，在动作暂停或场景切换处拆成多镜组接。

### 剪辑点与装配策略
- **动作中途切镜 (Match on Action)**：在前一个镜头挥刀挥到一半时切近景继续挥完，靠剪辑动势让动作跨镜连贯。
- **遮挡转场 (Wipe Cut)**：利用人影或柱子擦过镜头黑屏的一瞬间切镜，无缝拼接前后两段生成。
- **声音先行与延续 (J-Cut / L-Cut)**：声音先于画面出来，或者画面切了声音继续飘着，让段落自然流畅。
- **关键帧锚定与动量延续 (Keyframe & Momentum)**：跨段生成时明确“前段尾帧 = 后段首帧”；如果下一镜是连续动作，前镜尾帧必须**保留向前冲的运动惯性动势**，严禁提前减速定格导致画面僵死。

## 5. 结构化分镜交付规范 (Standard Storyboard Output)

输出分镜时，按 `Scene → Beat → Shot` 结构化呈现，每个 Shot 必须提供六维完备要素：

```text
### Scene [编号] - [场景名] - [时段/天气]
[本场核心戏剧目标与情绪基调]

#### Beat 1: [节拍名 - 核心动力/信息转移]

- **Shot [编号] (如 Shot 1.1)**:
  - **[观看任务与叙事功能]**：建立环境 / 施加压迫 / 揭示线索 / 动作反馈
  - **[景别 / 机位 / 运镜]**：如 [全景 / 俯视 / 缓慢推近]、[特写 / 仰角平视 / 固定]
  - **[画面构图与视觉焦点]**：主体位置（三分线/居中）、前景遮挡、焦平面
  - **[主体物理动作与起止状态]**：
    - 起始状态：...
    - 动态过程：...
    - 结束状态：...
  - **[光影与环境动力学]**：主光方向、环境动态（烟雾/雨滴/飘动发丝）
  - **[声音与对白]**：对白内容、关键音效 (SFX)、环境氛围音 (Ambience)、音乐情绪
  - **[预估时长与生成装配]**：预估秒数（如 3s）；所属 Generation 单元（如 Gen 01）；连续性依赖（如“承接 Shot 1.0 尾帧站位”）
```
