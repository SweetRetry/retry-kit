# Storyboarding (分镜拆解与生成装配)

## 1. 核心心智模型 (Mental Model)

分镜（Storyboard）的本质是**视听语言的蒙太奇构筑与 AIGC 视频生成的工程装配（Assembly）**。
核心层级推进：`剧本场景 (Scene) → 叙事节拍 (Beat) → 镜头视听设计 (Shot) → 模型生成单元 (Generation Assembly)`。
分镜设计必须同时满足两大标准：**电影视听语法的叙事张力** + **AI 视频模型物理动力学的可控可生成性**。

## 2. 电影级视听语法矩阵 (Cinematic Visual Grammar)

拆解镜头时，按叙事功能组合景别、机位角度与运镜动线：

### 景别系统 (Shot Scales & Functions)
- **大远景 / 全景 (EWS / WS - Establishing)**：交代地理环境、空间规模、阵营势力对比与世界观氛围。
- **中景 (MS - Master / Two-Shot)**：展现人物上半身、肢体互动、二人对话与人物与环境的相对关系。
- **近景 (MCU / CU - Intimacy & Tension)**：聚焦面部表情、眼神微变化、情感高潮或戏剧冲突爆发点。
- **特写 / 大特写 (CU / ECU - Detail & Reveal)**：关键道具（Hero Prop）、关键伤痕、关键线索揭示，用于戏剧强调与关键帧锚定。

### 机位角度与视点 (Angles & POV)
- **客观观察视角 (Objective)**：中立记录，保持理性距离。
- **主观视角 (Subjective POV)**：摄影机即角色双眼，体验角色的压迫、眩晕、窥视或探索。
- **仰角 (Low Angle)**：赋予主体崇高感、压迫感、统治力或强大力量。
- **俯角 (High Angle)**：凸显主体的渺小、无助、受困或被监视状态。
- **荷兰角 / 倾斜构图 (Dutch Angle)**：营造心理失衡、危机降临、意识迷离或秩序崩塌。

### 运镜动力学 (Camera Dynamics)
- **固定镜头 (Static)**：强调稳定、压抑、审视或让画面内的角色动作成为唯一焦点。
- **推进 / 推近 (Push-in / Dolly In)**：强化戏剧张力，引导观众聚焦关键决策或人物心理剧变。
- **拉出 / 后退 (Pull-out / Dolly Out)**：揭示隐藏的环境真相、人物与宏大世界的孤立关系。
- **摇镜头 (Pan / Tilt)**：建立空间连续性，或通过视线转移制造突发惊吓/信息揭露。
- **跟随镜头 (Tracking / Steadicam)**：伴随人物奔跑、潜行，强化沉浸感与现场临场感。

## 3. 场面调度与空间连续性不变量 (Blocking & Continuity Invariants)

分镜绝非孤立图片的拼贴，必须保证时空连续性：

### 180° 轴线原则 (180-Degree Rule & Action Axis)
- 双人对话或对抗运动中，两主体之间建立一条虚拟轴线；摄影机机位必须始终保持在轴线的同一侧（180° 半圆内）。
- 严禁无过渡越轴（会导致剪辑后角色左右视线反向错乱）；越轴必须通过中轴正面镜头（Neutral Head-on Shot）、连续运镜划过轴线或插入第三者视点过渡。

### 视线匹配与进出画 (Eyeline Match & Screen Direction)
- **视线匹配**：前一镜头角色向画右看，后一反应镜头/被看对象必须位于画左或向画左看。
- **运动方向一致性**：角色从画右出画，下一镜头必须从画左入画以保持向同一方向前进。

### 光源与物理状态承接
- 主光源方向（如窗户光/夕阳）在同一场景的所有镜头中必须保持绝对一致。
- 角色的服装战损、持物手别（左手持枪/右手握刀）、血迹位置严格继承前一镜头结束状态。

## 4. AIGC 动力学边界与 Generation 装配 (AIGC Assembly & Risk Gate)

AI 视频模型（单次 4–15 秒）对剧烈复杂动作的物理收敛能力有限，分镜必须做工程级降风险：

### 单镜头单一动力学原则 (Single Dynamic Gate)
- **一个 Shot 只承担一个主要动力学任务**（例如：只做“拔刀突进”或只做“被击退倒地”）。
- 禁止在一个 Shot 内堆砌多个复合不可逆剧烈动作（如“起身、倒茶、打碎茶杯、拔枪射击”），必须拆分为多镜头组接。

### 剪辑点与装配策略 (Editing Points & Assembly)
- **动作匹配剪辑 (Match on Action)**：在前一个镜头动作进行到一半时切镜（如挥刀中途切到近景挥刀收尾），利用动势掩盖模型形变。
- **遮挡转场 (Wipe / Occlusion Cut)**：利用前景柱子、人影经过画框形成自然黑场/遮挡，完成 generation 无缝拼接。
- **声画对位 (J-Cut / L-Cut)**：声音先于画面出现（J-Cut）或画面切换后声音延续（L-Cut），增强段落流畅度。
- **关键帧锚定 (Keyframe Anchoring)**：在 Generation Assembly 的交接处明确“前段尾帧 (End Frame) = 后段首帧 (Start Frame)”，杜绝两段生成间的画面漂移。

## 5. 结构化分镜交付规范 (Standard Storyboard Output)

输出分镜时，按 `Scene → Beat → Shot` 结构化呈现，每个 Shot 必须提供六维完备要素：

```text
### Scene [编号] - [场景名] - [时段/天气]
[本场核心戏剧目标与情绪基调]

#### Beat 1: [节拍名 - 核心动力/信息转移]

- **Shot [编号] (如 Shot 1.1)**:
  - **[观看任务与叙事功能]**：建立环境 / 施加压迫 / 揭示线索 / 动作反馈
  - **[景别 / 机位 / 运镜]**：如 [全景 / 俯视 / 缓慢推近]、[特写 / 仰角平视 / 固定]
  - **[画面构图与视觉焦点]**：主体位置（三分线/居中）、前景遮挡、焦平面
  - **[主体物理动作与起止状态]**：
    - 起始状态：...
    - 动态过程：...
    - 结束状态：...
  - **[光影与环境动力学]**：主光方向、环境动态（烟雾/雨滴/飘动发丝）
  - **[声音与对白]**：对白内容、关键音效 (SFX)、环境氛围音 (Ambience)、音乐情绪
  - **[预估时长与生成装配]**：预估秒数（如 3s）；所属 Generation 单元（如 Gen 01）；连续性依赖（如“承接 Shot 1.0 尾帧站位”）
```
