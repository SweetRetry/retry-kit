# 剧本创作与导演决策：一手来源研究

研究日期：2026-07-28

## 研究问题与来源边界

目标是为短剧、叙事短视频和 AI 故事视频的创作流程提炼可复用、可检查的决策门槛，重点核对 dramatic question、character objective、stakes、turning points、scene causality、screen-time economy、visible-audible writing、continuity 与 revision gates。

本文只采用以下一手或机构原始材料：

- Academy Nicholl 官方 screenplay formatting guidance；
- BBC Writersroom 官方 screenplay format guide；
- WGA 官方 Screen Credits Manual；
- 职业编剧 John August 本人发布的工作方法，以及其官网刊载的 Scriptnotes 原始逐字稿（发言者包括 John August、Craig Mazin、Pamela Ribon 等职业编剧）。

WGA Screen Credits Manual 是署名判定规则，不是创作教材；本文只用它确认“修改价值取决于对整部 screenplay 的影响，而非改动数量”，不把署名规则外推为写作规范。

## 结论：八条可执行原则

### 1. 把外部结果问题与内在 dramatic question 分开，再验证二者互相服务

**事实：** John August 与 Craig Mazin 把 “what it is about” 与 “what it is really about” 区分为具体 plot premise 和 theme / central dramatic question；只有抽象主题，没有承载它的具体事件，不足以形成故事，二者必须互相服务。[Scriptnotes 610](https://johnaugust.com/2023/scriptnotes-episode-610-the-premise-transcript) John August 复盘《Big Fish》时，把 “父子能否在死亡前和解”视为贯穿故事的具体问题，并指出一个看似标准的 act break 若与此问题无关，就不是有效的中心结构节点。[Breaking Down Big Fish](https://johnaugust.com/2012/breaking-down-big-fish)

**推断：** dramatic question 不宜只写成抽象 topic，也不宜只剩任务型悬念。稳定的 story core 至少有两层：观众等待结果的外部问题，以及故事借这一结果检验的人性、关系或价值问题。

**建议门槛：** 在进入 beats 前能分别写出：

1. “此人能否在此压力和时限下达成什么具体结果？”
2. “这一结果将回答或重新定义什么人性 / 关系问题？”
3. 每个主要 turning point 至少改变其中一层，并最终让两层在结尾汇合。

### 2. 不把“主角必须转变”设为普遍硬规则；硬规则应是结尾产生有意义的状态差

**事实：** John August 以自己改编的《Charlie and the Chocolate Factory》说明，Charlie 不需要经历显著 arc；他保持原有品格，却改变了周围世界，另一个人物承担主要转变。[Scriptnotes 606](https://johnaugust.com/2023/scriptnotes-episode-606-character-and-story-fit-transcript) 在关于 ending 的讨论中，他进一步把完整结尾描述为：人物改变、环境改变，或开头提出的 narrative question 经历变化后被重新理解；结尾必须与开头形成可辨认差异，但不限定差异只能发生在标题角色内部。[Scriptnotes 647](https://johnaugust.com/2024/scriptnotes-episode-647-crafting-your-ending-transcript)

**推断：** “人物、关系或认知发生变化”适合作为强默认，但“指定主角必须完成内在成长”会误伤观察型、见证型、讽刺型、坚定者改变世界等故事。

**建议门槛：** 强制回答“结尾相对开头，谁或什么发生了不可逆且有意义的变化？”允许答案落在人物信念、人物选择能力、关系、权力、世界状态或观众理解；若主角不变，必须明确谁 / 什么因其行动而变，以及这种不变为何受到真正检验。

### 3. objective 与 stakes 是两个字段；stakes 必须可感知且与人物有关

**事实：** John August 直接区分 goal 与 stakes：goal 是人物瞄准的结果，stakes 是失败后会发生什么；观众需要理解失败后果，才能感到潜在损失。[Scriptnotes 146](https://johnaugust.com/2014/scriptnotes-ep-146-wet-hot-american-podcast-transcript) John August、Craig Mazin 还区分全片 stakes 与 scene / sequence stakes，并强调 scene 中的 jeopardy 要清楚到观众知道局面可能向哪边倾斜；每场戏仍要落回“谁此刻想要什么”。[Scriptnotes 402](https://johnaugust.com/2019/scriptnotes-ep-402-how-do-you-like-your-stakes-transcript)

**推断：** “想赢”“会失败”“世界毁灭”都不是充分 stakes。它必须说明失败具体损害人物的关系、自我认同、承诺、机会或生存状态；规模不等于力度。

**建议门槛：** 对全片和主要 scene 分别写成：`人物 + 当前可执行 objective + 阻力 / opposing force + 失败后可感知后果`。如果只写出了目标而说不出后果，stakes 尚未建立；如果后果巨大却与人物无个人联系，观众投入仍未建立。

### 4. turning point 的判定依据是因果与 choice-space 改变，不是页码或结构标签

**事实：** Craig Mazin 把有效 inciting incident 定义为针对特定人物的 stasis disruption：它使原有平衡无法继续，并迫使人物作出选择，而不只是发生一个巨大事件。[Scriptnotes 403](https://johnaugust.com/2019/scriptnotes-ep-403-how-to-write-a-movie-transcript) John August 对《Big Fish》的复盘也显示，一个节点即使形式上像 end of act one，若不推进 central dramatic question，其结构价值仍然有限。[Breaking Down Big Fish](https://johnaugust.com/2012/breaking-down-big-fish)

**推断：** turning point 的最小定义不是“反转”或“到了某个百分比”，而是前一行动 / 发现造成新事实，使人物不能原样继续，并改变下一步可选路径。

**建议门槛：** 每个主要 turning point 写清 `此前稳定状态 → 触发事件 → 人物反应 / 选择 → 新约束或新可能 → 因此必须发生的下一步`。删除节点后若人物仍会以同样理由采取同样下一步，它不是 turning point。

### 5. scene 先过 necessity gate，再过 objective / pressure / exit-state gate

**事实：** John August 的 scene 方法先问“本场必须发生什么”，再做 omission test：删掉后故事仍然成立的 scene 没有必要存在；他同时要求在写之前决定愿意给这场戏多少 screen time。[How to Write a Scene](https://johnaugust.com/2007/write-scene) 关于 scene causality，John August 认为人物应带着 goal 进入，并由自己的逐行动作、对白和反应造成 scene 的改变；作者可知道开头和结尾，但人物不能像执行既定 outline 一样被拖过去。[Scriptnotes 341](https://johnaugust.com/2018/scriptnotes-ep-341-knowing-vs-discovering-transcript) 对不工作的对话场景，Scriptnotes 的原始讨论把“各人物此刻分别想得到什么”与人物间或外部 pressure 视为关键诊断项。[Scriptnotes 655](https://johnaugust.com/2024/scriptnotes-episode-655-conflict-and-stakes-compendium-transcript)

**推断：** objective / pressure / turn 是强 scene 默认，但不应机械要求每个极短 establishing fragment、montage 片段或反应镜头都拥有独立对手和完整反转；这些片段应在其所属 sequence 层共同通过门槛。`turn` 也不等于惊奇，而是 exit state 与 entry state 有叙事相关差异。

**建议门槛：** 对完整 scene 检查：

- necessity：删掉后哪项因果、人物、信息或情绪结果会丢失？
- objective：本场由谁驱动，他此刻试图改变什么？
- pressure：什么人、环境、时限、秘密或内在冲突阻止顺利完成？
- exit state：目标进度、知识、关系、权力、风险、情绪或选择空间至少哪一项发生了变化？
- handoff：这项变化如何造成或迫使下一 scene / sequence？

### 6. screen-time economy 以 scene / sequence 的功能与 timing 为准，不以页数公式为准

**事实：** John August 要求在写 scene 前决定愿意分配的 screen time，并警告同一功能可能用三页，也可能只需八分之二页。[How to Write a Scene](https://johnaugust.com/2007/write-scene) 他后来用 761 部 screenplay 与成片 runtime 的比较说明，一页一分钟只在聚合上勉强成立，不能可靠预测单一项目；更实际的是逐 scene 做 script timing，且最终 runtime 仍受剪辑影响。[How Accurate Is the Page-per-Minute Rule?](https://johnaugust.com/2020/how-accurate-is-the-page-per-minute-rule-2) BBC Writersroom 的官方格式指引建议 scene action 每段约四至五行，并把每段当成一个重要 action beat。[BBC Screenplay Format](https://downloads.bbc.co.uk/writersroom/scripts/screenplay.pdf)

**推断：** 精确到秒的 beat 表在写作期只能是估算。短视频尤其不能把页数、字数或对白行数直接兑换成 runtime；动作复杂度、停顿、反应、镜头保持与声音都会改变时长。

**建议门槛：** 每个 beat / scene 同时记录叙事功能与预计时长；用 omission / merge test 压缩重复功能；明确 timing 是估算。需要严格时长时，通过朗读、blocking / animatic 或逐 scene timing 验证，而不是用页数公式伪造精度。

### 7. screenplay 正文只写可呈现证据；导演决策只保留影响观看结果的部分

**事实：** BBC Writersroom 明确要求 scene action 只处理屏幕上发生的事，不写多余的小说式思想或 backstory，并要求角色标识在全文保持一致。[BBC Screenplay Format](https://downloads.bbc.co.uk/writersroom/scripts/screenplay.pdf) Academy Nicholl 指南说明 submission script 通常以 master scenes 写作，少用或不用 camera shot designations；其官方资源也把冗长 description 列为可能造成负面第一印象的格式问题。[Academy Nicholl Screenwriting Resources](https://www.oscars.org/nicholl/screenwriting-resources) John August 还指出，纸面正常的 dialogue 可能实际难以说清，必须朗读并在 fresh eyes 下复查。[Dialogue Is Meant to Be Spoken](https://johnaugust.com/2010/what-you-see-vs-what-you-say)

**推断：** visible-audible 不是“只写物理动作”，而是把内在状态转成演员、摄影、声音和剪辑可以执行且观众可以感知的证据。导演层也不应罗列每个镜头；只有叙事视点、信息释放、表演任务、空间关系、声音或转场会改变观众理解时，才值得进入交付。

**建议门槛：** 对每句心理说明追问“观众通过什么看见或听见？”；关键动作写清主体、对象、方向、结果与反应；对白至少朗读一次；camera / sound / transition 指令必须能说明其叙事作用，不能只表达风格偏好。

### 8. revision 应按问题目标闭环；“一次整稿修订”只能是执行预算，不是质量规律

**事实：** John August 的 revision 方法是先确定本轮要达成的目标，再定位需要改变及支持该目标的 scenes，一次处理一个问题。[How to Rewrite](https://johnaugust.com/2005/how-to-rewrite) 他区分 rewriting 与 polishing，并要求先让 scene 完成功能，再做措辞级 polish；处理反馈时应追问问题为何发生，而不是照抄对方提出的解法。[Rewriting Based on Other People’s Notes](https://johnaugust.com/2004/rewriting-based-on-other-peoples-notes) WGA Screen Credits Manual 从署名影响角度确认，修改的重要性不由改了多少行决定，而由其对 dramatic construction、scenes、characterization / relationships 和整部 screenplay 的影响决定。[WGA Screen Credits Manual](https://www.wga.org/contracts/credits/manuals/screen-credits-manual)

**事实：** 本次查阅的一手材料没有给出“完成一次整稿修订即可达到质量标准”的依据。相反，John August 明确把职业写作描述为从第二稿到更多稿次持续重写的过程。[Rewriting Based on Other People’s Notes](https://johnaugust.com/2004/rewriting-based-on-other-peoples-notes)

**推断：** 限制一次 full revision 可以控制 agent sprawl、token 与时间，但不能被表述成创作质量规律。真正可检查的是：问题有证据、修改有目标、改后重新验证、残留问题被诚实列出。

**建议门槛：** 一次自审最多选少量高影响问题；每项写成 `文本证据 → 破坏的观众效果 / 故事功能 → revision objective → 涉及 scenes → 修改后验证结果`。先修 structure / causality / character function，再修 dialogue 与 prose。若预算只允许一轮，交付时说明这是本轮执行上限，并列出仍未关闭的问题，不能宣称一轮天然足够。

## Continuity 的独立检查面

**事实：** Scriptnotes 对 plot holes 的归类包括：人物获得或遗忘了没有来源的信息、时间与地理不成立、依赖无法预见的同时事件、道具前后状态不一致；把事件绑定到人物动机通常会比随机巧合更可信。[Scriptnotes 384](https://johnaugust.com/2019/scriptnotes-ep-384-plot-holes-transcript) 关于 character knowledge 的专题进一步要求区分作者、人物与观众分别知道什么、人物如何获得知识，以及人物是否无理由隐瞒本该共享的信息。[Scriptnotes 641](https://johnaugust.com/2024/scriptnotes-episode-641-what-characters-know-transcript)

**推断与建议：** continuity 不应只检查名字、服装和道具外观，还应逐 scene 维护以下状态：`人物在场 / 可见范围、人物知识及来源、时间与地理、伤痕与体力、服装道具持有者与状态、关系 / 承诺、世界规则、待回收 setup`。每次删场、移场或合并场景后，都要重跑 knowledge provenance 与时间地理检查，因为删除解释性场景是 continuity hole 的常见来源。

## 对当前方向的含义

现有方向中，story core、人物目标 / 需要 / 压力 / 代价、beat 状态变化、visible-audible、连续性与结构优先修订均有充分一手依据。最值得补强的不是新增结构流派，而是把现有文字压成以下五个可观察 gate：

1. 外部结果问题与内在问题是否互相服务；
2. 结尾是否相对开头产生有意义状态差，而非强迫指定主角成长；
3. 主要 scene 是否有 necessity、objective、pressure、exit state 与 causal handoff；
4. timing 是否被明确标作估算，并在严格时长任务中经过实际验证；
5. revision 是否按问题目标闭环，并诚实区分“一轮预算”与“质量已充分”。

## 局限

- 这些来源主要来自英语电影 / 电视 screenplay 实践；竖屏平台节奏、互动叙事及具体生成模型的约束不在其直接证据范围内。
- Academy 与 BBC 材料主要解决 submission / format，不证明某种故事结构必然优秀。
- Scriptnotes 与 John August 的文章是职业创作者的一手实践，但仍是具体创作者的方法论，不是普适科学定律；本文将其收敛为诊断门槛时均标记为推断。
- 本次没有找到高可信一手材料支持固定的一次 revision 上限，也没有找到能够从文本稳定预测短视频精确秒数的通用公式。
