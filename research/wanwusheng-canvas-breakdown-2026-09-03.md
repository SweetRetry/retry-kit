# 《万物生》创作画布提示词工程体系拆解

- 日期：2026-09-03
- 问题：《万物生》公开的创作画布揭示了哪些与常规 AIGC 视听提示词反直觉的工业级原则？对仓库的 `generation` 系列（`generation-director`、`video-prompt`、`image-prompt`）有哪些可吸收的决策增量？
- 来源范围：南鸢 nuyoah（@nanyuan0412）2026-09-03 发布的深度复盘文章《拆完〈万物生〉的创作画布，我总结了几个作者的创作理念》（一手实战拆解）。

## 1. 核心事实与理念提炼

### 1.1 反向创作顺序（拍摄方案而非画面描述）
- 常规流程习惯先写主体与情节，末尾追加“电影感、大片感、史诗运镜”等抽象词。
- 画布采用逆向顺序：**拍摄规则（风格锁 + 摄影机调度制度） ➔ 实体基准（人物/道具/场景外观） ➔ 单镜动作与因果发生**。提示词本质是一份分层拍摄方案。

### 1.2 STYLE LOCK（风格特征化与负向红线）
- 拒绝使用“高级、震撼、电影感”等主观形容词，转译为全片共同遵守的拍摄制度（如实拍感 vs CG、宽银幕 vs 手机记录、空气尘雾、色温与噪点形态）。
- 风格特征化：如“手机感”细化为边缘畸变、防抖补偿失真、局部过曝与数码压缩感。
- **负向排他红线**：显式禁止转为动画、禁止塑料 CG 感、禁止游戏过场感。

### 1.3 摄影机调度先行（运镜承担叙事信息控制）
- 摄影机在主体行动前已规划好起点、轨迹、速度、晃动与落幅。
- 运镜的核心是**时序信息控制（观众何时获得答案）**：通过“遮蔽/空景 ➔ 局部引导 ➔ 身份确认 ➔ 揭示宏大威胁/环境”，实现戏剧张力。
- 运镜与动作在同一时间轴上紧密咬合，而非孤立修饰。

### 1.4 多参考素材权限隔离与负向约束（Negative Permissions）
- 参考图数量过多易引发模型内部控制权冲突（如姿势图污染五官与服装，环境图污染主体固有色）。
- 画布对每张图显式界定**“负责什么”与“严禁控制什么”**（如：姿势图只控制姿态构图，严禁改变人脸发型与服饰）。

### 1.5 动作微观受力因果链（Force-Reaction Chain）
- 拒绝“激烈打斗、强烈碰撞”等空洞标签。
- 打击感转化为微观物理闭环：**施力方向 ➔ 接触点 ➔ 受力物形变 ➔ 重心与躯干位移 ➔ 地面擦痕与反作用力**。
- 机械变形转化为状态递进因果：触发点 ➔ 部件脱扣 ➔ 咬合翻折 ➔ 液压伸缩 ➔ 锁死到位。

### 1.6 声音制度化与物理空间叙事
- 声音不是成片后附加的包装，而是在设计镜头时同步规划的物理探测器。
- 声音分工：金属撞击声交代物体密度与质量，环境残响交代空间规模，低频轰鸣赋予未入画实体压迫感。
- 微观动作与音效逐一咬合（抛掷-蓄能-翻折-锁定）。手机纪实风格保留环境风噪与收音失真。

### 1.7 镜头落幅与尾帧动势延续
- 重视结尾落幅状态：机位落点、主体停滞构图、装备最终状态。
- 尾帧需锁定不可漂移的特征，并在连续动作段落中**保留运动惯性动量（不要提前刹车站定）**，为下一镜头提供剪辑动势接力。

### 1.8 信息分流与提示词瘦身（Information Offloading）
- 提示词长度取决于外部载体已承担的信息量：
  - 角色设定图：长文本严密建立不变量标准；
  - 单镜视频：聚焦摄影机与主体互动；
  - 完整故事板/分镜图存在时：文字提示词极简，只补充图纸未表达的媒介、身份与声音。

## 2. 推断

- AI 视频模型（如 Seedance 2.x、MiniMax-H3）在多图输入模式下，文本中的“负向排他约束”（明确素材不影响哪些维度）能有效降低交叉污染。
- 视频提示词中的“动作僵死”与“滑步”，主要源于缺乏微观受力过程和尾帧动量保留。
- 纯粹的正向提示词无法完全杜绝风格漂移，在风格层引入极简的“负向红线”（反塑料 CG、反动画）是必要的护栏。

## 3. 建议落地

1. **`video-prompt/SKILL.md`**：
   - 素材映射表增设“禁止干预的维度（排他防污染约束）”，并指导多图参考时的隔离声明。
   - 全局稳定设定升级为“拍摄制度 / 风格锁 (Style Lock)”，增加负向风格红线。
   - 六维物理状态中，深化动作描写为“受力-形变-反作用因果链”，将声音定义为“空间与物理密度刻画工具”。
   - 跨段承接明确尾帧“动量延续”。
2. **`generation-director/references/storyboarding.md`**：
   - 运镜动力学中增加“时序信息揭露（Information Revelation Pacing）”。
   - 分镜装配强调尾帧保持运镜/主体运动惯性，避免提前刹车。
3. **`image-prompt/SKILL.md`**：
   - 补充资产基准图（立标准、高约束）与分镜插图（重图纸、文字轻量化）的策略差异。

## 4. 局限

- 该分析基于《万物生》实战创作画布的反向工程与博主总结，实际各专有模型（Seedance、Runway、Kling、Sora）底层注意力机制对负向排除语句的遵循度存在差异。
- 复杂受力因果链过长时可能受到各模型 prompt context 窗口与权重衰减限制，需按目标模型动态适配压缩。
