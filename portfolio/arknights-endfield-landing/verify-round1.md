## 0. 事实核查

- **确认**：「奇象巡展」真实存在，是 2026「夏日嘉年华」的游戏内限时活动（2026-08-08 至 09-04），"INTERACTIVE EXHIBITION" 是活动 KV 的虚构展会叙事包装，非线下展。

## 2. 主 agent 原图复核（竖版海报，会话内直接观察）

子 agent 标「存疑」的条目，经主 agent 对用户提供的竖版海报原图复核：

- **技术线稿（桁架/布幔/设备箱）**：**确认存在**。竖版海报中部主体即白色桁架 + 垂坠布幔 + 设备箱的黑色细线技术制图，是竖版独有主体（横版 KV 改为 3D 瓷砖块阵）。
- **荧光黄绿长曝光光带**：**确认存在**（左侧大涂抹 + 右侧细光带，水平方向）。
- **运动模糊/glitch 水平条纹**：**确认存在**（线稿被水平切断错位）。
- **半调网点**：**确认存在**（左下黄色块、布幔暗部为 halftone dots 渐变），但同时背景也有柔和光晕渐变——**第 7 节"避免平滑渐变"规则推翻**，改为：允许大面积柔和光晕做氛围，信息性渐变用半调/硬切。
- **微文字 monospace**：**修正**——标题上方灰色大字距小字为无衬线；贴纸内为涂鸦伪文字。落地页实现时选用 monospace 承载技术标注是设计决策，非复刻。

## 3. 品牌签名 vs 一次性处理

- **IP 稳定签名**：黑白灰基底 + 高饱和 accent 点缀；网格/模块化排版；蓝图式技术标注 + 大字距微文字；「明日方舟」刀切 logotype；黑色 pill 标签系统。
- **本次活动一次性处理**：glitch 切片标题、全色谱棱镜色散、流体气泡 + 星爆贴贴纸系统、cyan×酸性黄绿×热粉多 accent 组合、通栏粉色底条。

## 4. 对 design.md 的约束结论

1. 竖版海报（用户参考）= 主要风格来源；横版 KV 的实测色值用于校准取色。
2. 多 accent（cyan / 热粉 / 酸性黄绿）是本次活动签名，可保留，但需明确语义映射，不能各元素随机分色。
3. 终末地侧叠加黄黑警示条纹、三角形、工业徽章母题（见 research-endfield.md）。
