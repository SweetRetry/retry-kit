# Round 1 分析：明日方舟「奇象巡展 INTERACTIVE EXHIBITION」海报视觉拆解

> 分析者：主 agent，基于用户提供的参考图直接目视拆解。
> 用途：作为 design.md 的风格依据，后续 round 由子 agent 交叉验证。

## 1. 整体调性

- 高调白（high-key）：背景为近白（#FAFAFA–#FFFFFF），带极淡的青绿色角部光晕（左下、右上）。
- 印刷品 + 屏幕 glitch 的混合质感：轻噪点、半调网点（halftone dots）渐变、运动模糊条纹、色散（chromatic aberration）边缘。
- 主题语义：一张"展会导览 / 技术图鉴"式海报——展位空间被当作建筑制图对象来描绘，再叠加荧光标注。

## 2. 构图

- 垂直三段：顶部 logo 带（左侧一排淡化的合作方 logo，右侧「明日方舟 ARKNIGHTS」官方 logotype）→ 中部主体图形（展位线稿 + cyan 流体色块 + 黑色环形 logomark）→ 底部超大双行展示标题 + 黑色 pill 中文标题。
- 居中对称主体 + 大量留白；微文字行（超大字距的 INTERACTIVE EXHIBITION）作为主体与标题之间的节奏分隔。

## 3. 图形语言

- **技术线稿**：黑色细线（1–2px 视觉）勾勒桁架（truss）、垂坠白布幔、设备箱、脚架；轴测/立面混合的建筑制图感；线稿被水平 glitch 条纹切断。
- **流体色块**：不规则有机 cyan 大色块（水滴/细胞形），边缘带 magenta 色散残影与黄色叠影，内部叠黑色环形螺旋 logomark。
- **光带**：荧光黄绿色水平涂抹条（左侧大、右侧细），像长曝光光绘。
- **标注贴纸系统**：
  - cyan 圆角 pill 标签，内部黑色 monospace 微文字（左上角）；
  - 黄色锯齿星爆贴（爆炸贴形），内部黑色微文字（右下、中部）；
  - 虚线、小箭头，把画面当导览图标注。
- **半调网点**：左下黄色块、布幔暗部使用 halftone dots 渐变，而非平滑渐变。

## 4. 色彩系统（目测近似值）

| 角色 | 色值（近似） | 用途 |
|---|---|---|
| 基底 | #FFFFFF / #F4F5F4 | 背景 |
| 墨色 | #111111 | 线稿、大标题、logomark |
| 主 accent cyan | #2ECFDD–#35D6E6 | 流体色块、pill 标签、色散 |
| 次 accent magenta | #E85AA4 类 | 色散残影、字母切片短杠 |
| 次 accent acid 黄绿 | #DDF53C–#E4FF4F | 光带、星爆贴、角部光晕 |
| 辅助 teal/green | 淡青绿 | 角部环境光晕 |

规则感：黑 + 白承载结构，cyan 是唯一大面积 accent，magenta / 黄绿只以"残影、切片、贴纸"等小面积高饱和形式出现。

## 5. 字体系统

- **展示标题**：定制几何无衬线（接近 stencil/模块化构成），字母被水平切片位移（glitch cut），切片处穿插 magenta/cyan/黄绿短斜杠；全大写、超紧凑行距、两行排列。
- **微文字 / label**：monospace，全大写，超大字距（≈0.4–0.5em），浅灰或黑。
- **CJK 标题**：「奇象巡展」白色粗黑/圆体置于黑色圆角 pill，pill 带 cyan/magenta 色散错位投影。
- **品牌 logotype**：「明日方舟」官方定制字体（尖锐、刀切感的衬线化造型），仅作品牌资产出现。

## 6. 质感与"动"的处理

- 运动模糊：水平条纹扫过线稿与色块（左右方向）。
- 色散：所有大图形边缘有 cyan/magenta 错位残影，像镜头像差。
- glitch cut：标题字形被水平切断错位。
- 噪点/半调：让白底不死白，有印刷颗粒。

## 7. 对落地页的可迁移规则（初步假设，待验证）

1. Light mode 高调白为底，黑线稿 + 单一大面积 cyan accent + magenta/黄绿小面积残影。
2. "技术图鉴 / 展会导览"叙事：用线稿、标注贴纸、monospace 微文字组织信息层级。
3. 标题处理 = 超大黑色几何无衬线 + glitch 切片 + 彩色短杠。
4. 图形处理 = 色散边缘 + 半调网点 + 水平运动条纹（motion 上可转化为 scroll/hover 微交互）。
5. 避免平滑渐变；渐变一律以半调网点或硬切色带表达。
