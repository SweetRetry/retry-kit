# AI 视频 Prompt 生成器

为任意类型视频生成专业 AI 视频 prompt，采用紧凑流式格式，便于直接复制使用。

## I. 工作流程

### 标准流程（多镜头）

1. **收集信息** — 确认视频类型、视觉风格、主体、剧情/展示内容、画幅比例、时长、镜头数
2. **类型分支** — 根据视频类型加载对应节奏模板和景别偏好（见§II 类型决策表）
3. **建立主体锚点** — 为核心主体创建固定描述，确保跨镜头一致性
4. **处理图片输入**（如有）— 确认用途并融入工作流（见§IV）
5. **设计分镜** — 按类型节奏模板拆分镜头，规划景别、运动、转场
6. **生成 Prompt** — 按紧凑流式格式输出（见§VI）
7. **质量检查** — 核心 5 项必检 + 扩展项按需检（见§VII）

### 单镜头快速模式

当用户只需要 **1 个镜头**时，跳过分镜设计：

1. **收集信息** — 确认视觉风格、主体、画面内容、画幅比例
2. **建立主体锚点** — 创建固定描述
3. **处理图片输入**（如有）
4. **直接生成单条 Prompt** — 输出简化格式（无时间轴）
5. **质量检查** — 仅核心 5 项

**单镜头输出格式：**

```markdown
风格: [视觉风格]

[景别+运动] 主体描述 -> 动作/变化. 光影氛围. 补充细节.
```

## II. 类型决策表

根据用户内容确定视频类型，引导不同的节奏/景别/风格选择。各类型的深度指导（叙事结构、节奏模板、景别偏好、转场、示例）见 [type-profiles.md](references/type-profiles.md)。

| 类型 | 叙事驱动力 | 典型节奏 | 推荐风格（首选） | 核心景别偏好 |
|------|-----------|---------|----------------|------------|
| 动漫叙事 | 角色情感/冲突弧线 | 快切+慢放交替 | 动漫赛璐璞 / 中国风水墨 | 全景别自由 |
| 电影真人 | 人物故事/情感张力 | 中等节奏，长镜头 | 电影真人实拍 / 复古胶片 | 中景-近景为主 |
| 产品广告 | 产品卖点递进 | 匀速递进→高潮定帧 | 产品摄影棚拍 / 极简时尚 | 中景-特写为主 |
| 纪录片风光 | 环境氛围/时间流逝 | 缓慢+延时 | 纪录片自然风光 | 远景-大远景为主 |
| MV / Vlog | 节拍/情绪同步 | 跟音乐节拍切换 | 按内容选择 | 全景别自由 |

## III. 信息收集清单

开始前向用户确认：

- **视频类型**：动漫叙事 / 电影真人 / 产品广告 / 纪录片风光 / MV / Vlog / 其他
- **视觉风格**：参见 [visual-styles.md](references/visual-styles.md)（含类型→风格映射表），或用户自定义
- **核心主体**：角色（外貌、服装、标志特征）/ 产品（材质、颜色、形态）/ 场景（地理、天气、氛围）
- **内容概要**：关键事件 / 展示流程 / 情绪弧线 / 高潮点
- **画幅比例**：16:9 / 9:16 / 1:1 / 其他（具体约束见 [camera-and-effects.md § 画幅比例约束](references/camera-and-effects.md#画幅比例约束)）
- **总时长**：用户期望的视频时长（秒）
- **镜头数量**：用户期望的分镜数量（1 = 进入单镜头快速模式）
- **图片输入**（如有）：确认用途（见§IV）

如信息不完整，主动询问缺失项再开始生成。

## IV. 图片输入处理

当用户提供图片时，**必须先确认用途**再继续：

> 你提供了一张图片，请确认它的用途：
>
> - **(A) 视觉参考** — 我从中提取风格、色调、构图等特征，融入 prompt 描述
> - **(B) 首帧起始** — 以这张图作为视频第一帧，prompt 描述后续运动和变化

**模式 A — 视觉参考：**

1. 分析图片的色调、光影、构图、材质、氛围
2. 将提取的视觉特征写入风格行和主体锚点
3. 正常生成完整 prompt

**模式 B — 首帧输入（图生视频）：**

1. 分析图片内容，建立主体锚点
2. 镜头 01 的 prompt 描述"从当前画面开始"的运动和变化，不重复描述静态内容
3. 后续镜头正常生成

## V. 主体锚点

为核心主体建立固定描述，在所有镜头 prompt 中严格复用。

**规则：**

- 每个镜头必须包含主体锚点关键特征（可根据景别精简：特写聚焦核心细节，全景聚焦整体轮廓）
- 2-3 个最显著特征在所有镜头中必须出现
- **字符限制**：单个 prompt ≤ 1000 字符

模板格式、锚点示例、词汇可生成性判断方法详见 [ai-tools-guide.md](references/ai-tools-guide.md)（§主体一致性策略 + §AIGC 词汇可生成性指导）。

## VI. 输出格式

### 输出语言（硬约束）

所有输出默认**全程使用单一语言**。默认跟随用户对话语言，用户明确要求时按指定语言。

中文输出时，镜头术语、景别、光影、风格、特效默认使用中文（推镜头、近景、体积光、赛璐璞、冲击波）。

仅在以下场景允许白名单混用术语：

- 用户明确要求保留特定外语术语
- 品牌名/专有名词必须保留原文
- 混用术语占比应尽量控制在 10% 以内，且同类术语保持一致（避免中英混写同一概念）

```
❌ 风格: 电影实拍，anamorphic lens flare，青橙色调
✅ 风格: 电影实拍，变形宽银幕光晕，青橙色调
```

### 紧凑流式格式

```markdown
风格: [全局视觉风格]
情绪: [整体情绪基调]

镜头 01 (开始s-结束s): [景别+运动] 主体描述 -> 动作触发特效. 补充细节.
镜头 02 (开始s-结束s): [景别+运动] 主体动作 + 同时特效. 转场提示.
镜头 03 (开始s-结束s): [景别+运动] 主体动作. 收尾特效.
```

**格式说明：**

| 元素 | 含义 | 示例 |
|------|------|------|
| `风格:` | 全局风格定义（只出现一次） | `风格: 电影实拍，变形宽银幕，青橙色调` |
| `情绪:` | 情绪基调（帮助 AI 理解氛围） | `情绪: 史诗、激昂` |
| `镜头 XX` | 镜头序号 | `镜头 01`, `镜头 02` |
| `(Xs-Ys)` | 时间轴 | `(0-3s)`, `(3-7s)` |
| `[景别+运动]` | 画面范围+镜头运动 | `[近景 跟拍]`, `[远景 横摇]` |
| `->` | 动作触发/结果 | `举剑 -> 青色灵气爆发` |
| `+` | 同时发生 | `火花飞溅 + 冲击波扩散` |

## VII. 质量检查

### 核心 5 项（每次必检）

- [ ] 主体锚点关键特征完整
- [ ] 否定词已避免（不使用"不要"/"没有"等否定式描述）
- [ ] 单个 prompt ≤ 1000 字符
- [ ] 镜头运动与情绪匹配
- [ ] 图片输入已按确认模式处理（如适用）

### 扩展 5 项（多镜头时追加）

- [ ] 镜头间叙事逻辑连贯
- [ ] 景别变化合理（避免连续相同景别）
- [ ] 时间轴总和等于总时长
- [ ] 多主体镜头已标注屏幕方位 + 景深层次（朝向信息仅作辅助，不作为主约束）
- [ ] 单镜头内同时运动的独立主体/群体不超过 2-3 组

### AI 可生成性评估

对每个镜头逐条评估以下三个维度，标注 🟢 / 🟡 / 🔴：

| 维度 | 🟢 高可生成性 | 🟡 有风险 | 🔴 大概率翻车 |
|------|-------------|----------|-------------|
| **主体复杂度** | 1 个主体或 2 个主体清晰分区 | 3 个主体同框 | 4+ 主体同框，或群体各有独立动作 |
| **运动复杂度** | 单一主动作 + 镜头运动 | 2 组并行动作（如主体动 + 特效动） | 3+ 组独立运动同时发生 |
| **空间清晰度** | 每个主体有明确屏幕方位 + 景深 | 有方位但层次较密（多主体挤在同一景深） | 依赖朝向关系、相对距离或背对镜头 |

**处理规则：**

- 全 🟢：直接输出
- 含 🟡：在该镜头 prompt 后加 `⚠️ 建议备选：[简化方案]`，给用户降级选项
- 含 🔴：**必须重写**，拆分镜头或简化至 🟡 以内，不允许输出 🔴 镜头

### 规则冲突优先级

当多条规则冲突时，按以下顺序决策：

1. 可生成性（先保证能稳定生成）
2. 叙事完整性（再保证故事表达）
3. 术语纯度（最后优化语言/术语一致性）

### 量化评分（执行口径）

每个维度按颜色计分：🟢=2 分，🟡=1 分，🔴=0 分。单镜头满分 6 分。

- 5-6 分：直接输出
- 3-4 分：可输出，但必须给 `⚠️ 建议备选`
- 0-2 分：必须重写，不允许直接输出

**评估输出格式（附在 prompt 输出之后）：**

```
## AI 可生成性评估

| 镜头 | 主体 | 运动 | 空间 | 总分 | 备注 |
|------|------|------|------|------|------|
| 01   | 🟢   | 🟢   | 🟢   | 6    |      |
| 02   | 🟡   | 🟢   | 🟢   | 5    | 3 主体同框，已分区 |
| 03   | 🟢   | 🟡   | 🟢   | 5    | ⚠️ 建议备选：去掉粒子特效，聚焦主体动作 |
```

## VIII. 输出示例

### 动漫对抗（双人武斗）— 格式参照

**角色锚点：**

```
称呼：凌霄
描述：青年男子，二十出头，剑眉星目面容冷峻，黑色长发束高马尾，白色丝质仙袍金色云纹刺绣，腰佩青玉坠，右手持寒光玉剑

称呼：夜无殇
描述：中年男子，三十余岁，刀疤横贯左颊，赤红短发向后梳起，黑色铠甲表面刻有红色发光纹路，双手持火焰形宽刃大剑
```

```markdown
风格: 东方奇幻动漫，影院级赛璐璐渲染，戏剧性光影，体积感烟尘与火花
情绪: 凶猛、对峙、张力递增

镜头 01 (0-4s): [远景 缓推] 凌霄画面左侧，侧身剪影，白色丝质仙袍金色滚边，玉剑垂于身侧 — 夜无殇画面右侧，侧身处于阴影中，黑色铠甲红色发光纹路，火焰大剑扛于肩上。两人之间荒凉岩石高台，风卷尘土。远处风暴云层。静止中凝聚张力。
镜头 02 (4-7s): [中景 从左向右跟拍] 凌霄前景向右突进，玉剑拖出青色弧光 — 夜无殇背景持剑架挡，火焰大剑向上横扫 -> 双剑在画面中央碰撞 + 冲击波向外扩散。火花飞溅。
镜头 03 (7-10s): [近景 快速切换两张面孔] 凌霄画面左侧，青色灵气映在微眯双眼中，高马尾飞扬 — 切至夜无殇画面右侧，赤红光芒照亮刀疤，咬紧牙关。每次切换镜头震动。背景闪电。
镜头 04 (10-14s): [大远景 摇臂上升] 凌霄偏左腾空而起拖出青色光尾 — 夜无殇偏右跃起迎击，身后拖曳火焰。双方在画面中央半空碰撞 -> 巨大能量光罩向外扩展。镜头拉远露出荒凉高台。闪白。
```
