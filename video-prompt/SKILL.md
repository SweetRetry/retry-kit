# AI 视频 Prompt 生成器

## 流程

1. **收集信息** — 类型、风格、主体、内容、画幅、时长、镜头数
2. **建立主体锚点** — 固定描述，2-3 核心特征跨镜头复用
3. **处理图片**（如有）— 确认用途：(A) 视觉参考提取风格 (B) 首帧起始只描述动作和运镜
4. **生成 Prompt** — 按下方格式输出
5. **质量检查** — 见末尾检查项

单镜头时跳过分镜设计，直接输出单条 prompt。

## 万能公式

```
主体 + 动作 + 场景 + 光影 + 镜头语言 + 风格 + 画质标签 + 约束
```

权重从左到右递减。主体和动作最重要，画质与约束放末尾。

## 输出格式

```markdown
风格: [全局视觉风格]
情绪: [整体情绪基调]

镜头 01 (0s-3s): [景别+运动] 主体描述 -> 动作. 光影. 画质标签. 稳定约束.
镜头 02 (3s-7s): [景别+运动] 主体动作 + 特效. 画质标签. 稳定约束.
```

**符号**：`->` 因果触发，`+` 同时发生，`—` 分隔多主体

**单镜头格式**：省略时间轴和镜头编号，其余相同。

**语言**：默认跟随用户语言，术语统一中文或英文，不混写。

## 硬约束

- **角色稳定**：人物 prompt 必须末尾加 `五官清晰，面部稳定，不扭曲`；多镜头加 `同一角色，服装一致`
- **画质标签**：每条 prompt 末尾加 `4K，超高清，细节丰富，锐度清晰，电影质感`（动漫用 `线条锐利，影院级渲染`）
- **单条 ≤ 1000 字符**
- **禁止否定词**（不要/没有），只描述画面中有什么
- **动作偏缓慢连续**（缓缓、轻轻、渐渐），剧烈动作拆为多镜头慢动作
- **空间用构图表达**（画面左侧/右侧/前景/背景），不用朝向指令（面对面/背靠背）
- **避免复杂多人互动**（2+ 人精确互动易出错），多主体时标注屏幕方位+景深
- 图生视频模式下**不重复描述图片静态内容**，聚焦动作和运镜

## 类型速查

| 类型 | 节奏 | 景别偏好 | 推荐风格 |
|------|------|---------|---------|
| 动漫叙事 | 快切+慢放交替 | 全景别自由 | 赛璐璐 / 水墨 |
| 电影真人 | 中等，长镜头 | 中景-近景 | 电影实拍 / 胶片 |
| 产品广告 | 匀速递进→定帧 | 中景-特写 | 棚拍 / 极简 |
| 纪录片风光 | 缓慢+延时 | 远景-大远景 | 自然风光 |
| MV / Vlog | 跟节拍切换 | 全景别自由 | 按内容选 |

各类型的叙事结构、节奏模板、完整示例见 [type-profiles.md](references/type-profiles.md)。

## 质量检查

**每次必检：**

- [ ] 主体锚点关键特征完整
- [ ] 角色稳定标签 + 画质标签已附加
- [ ] 无否定词，无模糊词，无矛盾要求
- [ ] 单条 ≤ 1000 字符
- [ ] 镜头运动与情绪匹配

**多镜头追加：**

- [ ] 相邻镜头有因果/递进，景别有变化
- [ ] 时间轴总和 = 总时长
- [ ] 多主体已标注方位+景深

**可生成性评估**（附在输出后）：按主体复杂度/运动复杂度/空间清晰度三维度评 🟢🟡🔴，含 🔴 必须重写。
