# AI 视频 Prompt 生成器

为任意类型视频生成专业 AI 视频 prompt，采用紧凑流式格式，便于直接复制使用。

## 工作流程

1. **收集信息** — 确认视频类型、视觉风格、主体、剧情/展示内容、时长、镜头数
2. **建立主体锚点** — 为核心主体（角色/产品/场景）创建固定描述，确保跨镜头一致性
3. **处理图片输入**（如有）— 确认用途并融入工作流
4. **设计分镜** — 按叙事节奏拆分镜头，规划景别、运动、转场
5. **生成 Prompt** — 按紧凑流式格式输出
6. **审查优化** — 完整性自查 + AI 可生成性逐镜头评估，🔴 镜头必须重写

## 信息收集清单

开始前向用户确认：

- **视频类型**：电影叙事 / 动漫短片 / 产品广告 / 纪录片风光 / Vlog / MV / 教程演示 / 其他
- **视觉风格**：参见 [visual-styles.md](references/visual-styles.md) 中的 10 种分类，或用户自定义
- **核心主体**：角色（外貌、服装、标志特征）/ 产品（材质、颜色、形态）/ 场景（地理、天气、氛围）
- **内容概要**：关键事件 / 展示流程 / 情绪弧线 / 高潮点
- **画幅比例**：16:9 横屏 / 9:16 竖屏 / 1:1 方形 / 其他（直接影响构图，见下方"画幅比例约束"）
- **总时长**：用户期望的视频时长（秒）
- **镜头数量**：用户期望的分镜数量
- **图片输入**（如有）：确认用途（见下方"图片输入处理"节）

如信息不完整，主动询问缺失项再开始生成。

**软建议（非硬约束）：**

- 节奏参考：每 10 秒约 2-3 个镜头
- 单个镜头建议 2-5 秒，避免过短（<1s）或过长（>8s）

## 输出语言（硬约束）

所有输出**必须全程使用单一语言，严禁中英夹杂**。默认跟随用户对话语言，用户明确要求时按指定语言。

中文输出时，所有镜头术语、景别、光影、风格、特效均用中文（推镜头、近景、体积光、赛璐璐、冲击波），不夹杂英文术语。

```
❌ 风格: 电影实拍，anamorphic lens flare，青橙色调
✅ 风格: 电影实拍，变形宽银幕光晕，青橙色调
```

## 图片输入处理

当用户提供图片时，**必须先确认用途**再继续：

> 你提供了一张图片，请确认它的用途：
>
> - **(A) 视觉参考** — 我从中提取风格、色调、构图等特征，融入 prompt 描述
> - **(B) 首帧起始** — 以这张图作为视频第一帧，prompt 描述后续运动和变化

**模式 A — 视觉参考：**

1. 分析图片的色调、光影、构图、材质、氛围
2. 将提取的视觉特征写入风格行和主体锚点
3. 正常生成完整多镜头 prompt

**模式 B — 首帧输入（图生视频）：**

1. 分析图片内容，建立主体锚点
2. 镜头 01 的 prompt 描述"从当前画面开始"的运动和变化，不重复描述静态内容
3. 后续镜头正常生成

## 主体锚点

为核心主体建立固定描述，在所有镜头 prompt 中严格复用。模板格式和示例详见 [ai-tools-guide.md § 主体一致性策略](references/ai-tools-guide.md#主体一致性策略)。

**规则：**

- 每个镜头必须包含主体锚点关键特征（可根据景别精简：特写聚焦核心细节，全景聚焦整体轮廓）
- 2-3 个最显著特征在所有镜头中必须出现
- **字符限制**：单个 prompt 不超过 1000 字符
- **词汇注意**：避免复合幻想词汇（如"血色符文"→"红色发光纹路"）。详见 [ai-tools-guide.md § AIGC 词汇可生成性指导](references/ai-tools-guide.md#aigc-词汇可生成性指导)

## 分镜设计规范

### 画幅比例约束

画幅比例决定构图空间，必须在设计分镜前确定。不同比例对景别和镜头运动有硬约束：

| 比例 | 适合 | 避免 |
|------|------|------|
| **16:9 横屏** | 大远景、横摇、多主体左右并排、宽银幕电影感 | — |
| **9:16 竖屏** | 单主体纵向构图、仰拍/俯拍、近景特写、上下分层构图 | 大远景横摇（画面太窄无法展开）、3+ 主体横排（挤成一团） |
| **1:1 方形** | 居中对称构图、单主体聚焦、社交媒体展示 | 宽银幕运动、左右对峙构图（空间不足） |

**prompt 中标注方式：** 在风格行末尾追加比例，如 `风格: 东方奇幻动漫，赛璐璐渲染，16:9`

### AI 工具空间能力边界

AI 视频工具对空间的理解以**画面构图**（屏幕上谁在哪、多大）为主，对**主体朝向和相对空间关系**理解极弱。写 prompt 时必须基于这个认知。

**可靠的（AI 能执行）：**

- 屏幕方位：画面左侧 / 画面右侧 / 画面中央
- 景深层次：前景 / 中景 / 背景
- 主体尺寸暗示：高大身影 / 远处小小的剪影
- 视觉侧影：侧身轮廓 / 剪影 / 背影（单主体时成功率较高）

**不可靠的（AI 高概率忽略或误解）：**

- 主体间朝向关系：面对面 / 背靠背 / 面朝对方
- 相对距离：相距五十米 / 相距百步
- 背对镜头 — AI 倾向将主体正面朝向镜头
- 复杂空间指令："A 站在 B 的左后方，面向东南"

**核心原则：用构图位置和视觉特征传达叙事关系，不依赖朝向指令。**

### 空间布局

多主体同框时，必须明确每个主体的**屏幕方位和景深层次**。用画面构图传达关系，不依赖朝向描述。

**方位描述词速查：**

| 词汇 | 说明 |
|------|------|
| 画面左侧 | 主体位于画面左 1/3 |
| 画面右侧 | 主体位于画面右 1/3 |
| 画面中央 | 主体位于画面中心 |
| 前景 | 靠近镜头，通常较大 |
| 中景 | 画面中层 |
| 背景 | 远离镜头，通常较小 |
| 对角线构图 | 主体分布在对角线两端 |

**多主体交互构图模板：**

- **对峙型**（双人对立）：A 画面左侧侧身剪影处于阴影中，B 画面右侧侧身轮廓被光照亮 — 用侧身轮廓 + 光影对比传达对立
- **追逐型**（前后追击）：A 前景大，B 背景小 — 用前景/背景尺寸差传达追击
- **包围型**（一对多）：A 画面中央，B/C/D 分布在画面边缘 — 用画面边缘分布传达围逼
- **并行型**（同方向）：A 和 B 并排侧身，向画面右侧移动 — 用侧身轮廓 + 运动方向传达同向

**规则：**

- 当 2+ 主体同框时，prompt 必须包含每个主体的**屏幕方位**和**景深层次**。
- **不写朝向指令**（面朝左/面朝右/面对面），改用侧身轮廓、剪影、光影对比等视觉手段传达关系。
- 多主体场景的第一个镜头建议用静态或慢速镜头建立构图关系，后续镜头保持一致的左右/前后布局。
- **必须明确主体层级**：多元素同框时，必须标注谁是"画面主体"（占据主要面积）、谁是"背景元素"（虚化烘托）。未标注时 AI 会自行决定尺寸，极易导致核心角色被缩成远景小人。避免用"小小"、"渺小"等缩小词修饰核心角色（除非叙事意图就是渺小感）。
- **景别与主体尺寸联动**：核心角色需要清晰可辨时，景别不应大于中景。大远景/远景天然缩小人物，仅适用于环境建立或刻意的渺小感。

### 节奏参考

根据用户指定的总时长和镜头数灵活分配。以下为通用节奏参考：

| 功能 | 建议景别 | 建议时长占比 |
|------|---------|------------|
| 建立/开场 | 大远景/远景/产品全貌 | 15-20% |
| 展开/互动 | 中景/全景/产品特写 | 25-35% |
| 铺垫/转折 | 中近景/近景/细节微距 | 20-30% |
| 高潮/核心 | 特写+多景别/核心卖点 | 20-30% |
| 收束/定格 | 远景/特写/品牌标志定帧 | 10-15% |

**注意：** 镜头数少于 5 时可合并功能，多于 5 时可拆分展开和高潮段。

### 紧凑流式格式

**标准输出格式：**

```markdown
风格: [全局视觉风格]
情绪: [整体情绪基调]

镜头 01 (开始s-结束s): [景别+运动] 主体描述 -> 动作触发特效. 补充细节.
镜头 02 (开始s-结束s): [景别+运动] 主体动作 + 同时特效. 转场提示.
镜头 03 (开始s-结束s): [景别+运动] 主体动作. 收尾特效.
```

**格式说明：**

| 元素 | 含义 | 示例 |
|------|------|------|
| `风格:` | 全局风格定义（只出现一次） | `风格: 电影实拍，变形宽银幕，青橙色调` |
| `情绪:` | 情绪基调（帮助 AI 理解氛围） | `情绪: 史诗、激昂` |
| `镜头 XX` | 镜头序号 | `镜头 01`, `镜头 02` |
| `(Xs-Ys)` | 时间轴 | `(0-3s)`, `(3-7s)` |
| `[景别+运动]` | 画面范围+镜头运动 | `[近景 跟拍]`, `[远景 横摇]` |
| `->` | 动作触发/结果 | `举剑 -> 青色灵气爆发` |
| `+` | 同时发生 | `火花飞溅 + 冲击波扩散` |

## 输出示例

### 示例 1：动漫对抗（双人武斗）

**角色锚点：**

```
称呼：凌霄
描述：青年男子，二十出头，剑眉星目面容冷峻，黑色长发束高马尾，白色丝质仙袍金色云纹刺绣，腰佩青玉坠，右手持寒光玉剑

称呼：夜无殇
描述：中年男子，三十余岁，刀疤横贯左颊，赤红短发向后梳起，黑色铠甲表面刻有红色发光纹路，双手持火焰形宽刃大剑
```

```markdown
风格: 东方奇幻动漫，影院级赛璐璐渲染，戏剧性光影，体积感烟尘与火花
情绪: 凶猛、对峙、张力递增

镜头 01 (0-4s): [远景 缓推] 凌霄画面左侧，侧身剪影，白色丝质仙袍金色滚边，玉剑垂于身侧 — 夜无殇画面右侧，侧身处于阴影中，黑色铠甲红色发光纹路，火焰大剑扛于肩上。两人之间荒凉岩石高台，风卷尘土。远处风暴云层。静止中凝聚张力。
镜头 02 (4-7s): [中景 从左向右跟拍] 凌霄前景向右突进，玉剑拖出青色弧光 — 夜无殇背景持剑架挡，火焰大剑向上横扫 -> 双剑在画面中央碰撞 + 冲击波向外扩散。火花飞溅。
镜头 03 (7-10s): [近景 快速切换两张面孔] 凌霄画面左侧，青色灵气映在微眯双眼中，高马尾飞扬 — 切至夜无殇画面右侧，赤红光芒照亮刀疤，咬紧牙关。每次切换镜头震动。背景闪电。
镜头 04 (10-14s): [大远景 摇臂上升] 凌霄偏左腾空而起拖出青色光尾 — 夜无殇偏右跃起迎击，身后拖曳火焰。双方在画面中央半空碰撞 -> 巨大能量光罩向外扩展。镜头拉远露出荒凉高台。闪白。
```

## 质量检查

### 完整性自查

每次生成完成后逐项确认：

- [ ] 每个镜头包含主体锚点关键特征
- [ ] 镜头之间叙事逻辑连贯
- [ ] 景别变化合理（避免连续相同景别）
- [ ] 镜头运动与情绪匹配
- [ ] 时间轴总和等于总时长
- [ ] 单个 prompt ≤ 1000 字符
- [ ] 否定词已避免（不使用"不要"/"没有"等否定式描述）
- [ ] 图片输入已按用户确认的模式正确处理（如适用）
- [ ] 多主体镜头已标注屏幕方位 + 景深层次（无朝向指令）
- [ ] 单镜头内同时运动的独立主体/群体不超过 2-3 组（超出时考虑拆分镜头或让部分主体静止）

### AI 可生成性评估

对每个镜头逐条评估以下三个维度，标注 🟢 / 🟡 / 🔴：

| 维度 | 🟢 高可生成性 | 🟡 有风险 | 🔴 大概率翻车 |
|------|-------------|----------|-------------|
| **主体复杂度** | 1 个主体或 2 个主体清晰分区 | 3 个主体同框 | 4+ 主体同框，或群体各有独立动作 |
| **运动复杂度** | 单一主动作 + 镜头运动 | 2 组并行动作（如主体动 + 特效动） | 3+ 组独立运动同时发生 |
| **空间清晰度** | 每个主体有明确屏幕方位 + 景深 | 有方位但层次较密（多主体挤在同一景深） | 依赖朝向关系、相对距离或背对镜头 |

**处理规则：**

- 全 🟢：直接输出
- 含 🟡：在该镜头 prompt 后加 `⚠️ 建议备选：[简化方案]`，给用户降级选项
- 含 🔴：**必须重写**，拆分镜头或简化至 🟡 以内，不允许输出 🔴 镜头

**评估输出格式（附在 prompt 输出之后）：**

```
## AI 可生成性评估

| 镜头 | 主体 | 运动 | 空间 | 备注 |
|------|------|------|------|------|
| 01   | 🟢   | 🟢   | 🟢   |      |
| 02   | 🟡   | 🟢   | 🟢   | 3 主体同框，已分区 |
| 03   | 🟢   | 🟡   | 🟢   | ⚠️ 建议备选：去掉粒子特效，聚焦主体动作 |
```
