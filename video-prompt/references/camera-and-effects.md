## 镜头景别

| 景别 | 适用场景 |
|------|---------|
| 大远景 | 世界观建立、环境交代、史诗感开场 |
| 远景 | 场景全貌、人物与环境关系 |
| 全景 | 展示人物全身、动作场景 |
| 中景 | 对话场景、日常互动 |
| 中近景 | 情感表达、角色反应 |
| 近景 | 面部表情、情绪高潮 |
| 特写 | 眼神、关键道具、微表情 |
| 过肩镜头 | 对话、对峙、跟随视角 |
| 俯拍 | 渺小感、全局、战场俯瞰 |
| 仰拍 | 压迫感、权威、角色气场 |
| 荷兰角 | 不安、紧张、心理扭曲 |

## 镜头运动

| 运动 | 效果说明 |
|------|---------|
| 推镜头 | 聚焦、紧张感递增 |
| 拉镜头 | 揭示环境、释放压力 |
| 横摇 | 环境扫描、跟随运动 |
| 纵摇 | 仰望展示、俯视全貌 |
| 跟拍 | 跟随角色移动、沉浸感 |
| 环绕 | 角色展示、戏剧性增强 |
| 摇臂 | 从低到高的壮观展示 |
| 手持 | 紧迫感、真实感、追逐 |
| 稳定器滑移 | 流畅穿越、梦幻感 |
| 急速推进 | 震惊、发现、喜剧效果 |
| 无人机视角 | 宏大场景、追逐、航拍 |
| 转台旋转 | 产品 360° 展示、角色全身展示 |
| 慢动作 | 关键动作、情感放大、战斗细节 |
| 延时 | 时间流逝、环境变化 |

## 转场方式

| 转场 | 适用场景 |
|------|---------|
| 硬切 | 快节奏、动作场景 |
| 淡入淡出 | 开场、结尾、时间跳跃 |
| 交叉溶解 | 平滑过渡、回忆 |
| 擦除 | 场景切换、平行叙事 |
| 匹配剪辑 | 相似形状/动作连接两个场景 |
| 跳切 | 时间压缩、不安感 |
| 闪白 | 爆炸、觉醒、闪回起始 |
| 闪黑 | 悬念、突然终止 |
| 物体遮挡 | 自然过渡、物理遮挡 |
| 缩放穿越 | 微观到宏观、维度穿越 |
