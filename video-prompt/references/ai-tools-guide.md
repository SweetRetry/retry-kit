## 通用 Prompt 原则

以下原则适用于所有 AI 视频生成工具。当用户未指定具体模型时，按此通用规范生成 prompt。

### Prompt 结构公式

```
[主体描述] + [动作/动态] + [场景环境] + [镜头语言] + [光影氛围] + [画面风格] + [特效/后期]
```

### 权重排序

AI 视频工具通常对 prompt 开头的描述赋予更高权重。按重要性排序：

1. **主体**（谁/什么）— 最重要
2. **动作**（在做什么）— 核心动态
3. **环境**（在哪里）— 提供上下文
4. **镜头**（怎么拍）— 视觉表现
5. **风格**（什么调性）— 美学方向
6. **特效**（附加效果）— 锦上添花

### 注意事项

- 避免否定词（"不要"/"没有"等否定式描述），AI 难以理解否定
- 使用具体数量、颜色、方向等明确描述
- 每个 prompt 聚焦单一主要动作，避免过多并行事件
- 时长越短，prompt 越聚焦；时长越长，可加入更多动态变化
- 多主体同框时，必须明确每个主体的屏幕方位和景深层次，避免依赖朝向指令（详见下方"AI 空间能力边界"）

### AI 空间能力边界

AI 视频工具对空间的理解以**画面构图**（屏幕上谁在哪、多大）为主，对**主体朝向和相对空间关系**理解极弱。写 prompt 时必须基于这个认知。

**可靠的（AI 能执行）：**

- 屏幕方位：画面左侧 / 画面右侧 / 画面中央
- 景深层次：前景 / 中景 / 背景
- 主体尺寸暗示：高大身影 / 远处小小的剪影
- 视觉侧影：侧身轮廓 / 剪影 / 背影（单主体时成功率较高）

**不可靠的（AI 高概率忽略或误解）：**

- 主体间朝向关系：面对面 / 背靠背 / 面朝对方
- 相对距离：相距五十米 / 相距百步
- 背对镜头 — AI 倾向将主体正面朝向镜头
- 复杂空间指令："A 站在 B 的左后方，面向东南"

**核心原则：用构图位置和视觉特征传达叙事关系，不依赖朝向指令。**

### 通用 Prompt 结构模板

**角色类（动漫/真人叙事）：**

```
[景别]. [主体描述] 在 [环境] 中 [执行动作]. [镜头运动]. [光影与氛围]. [视觉风格]. [附加特效].
```

**产品类（产品广告/展示）：**

```
[景别]. [产品描述（材质/表面处理）] 在 [背景/台面] 上 [运动：旋转/悬浮/组装]. [镜头运动]. [棚拍灯光]. [视觉风格].
```

**场景类（纪录片/风光/氛围）：**

```
[景别]. [环境描述（天气/季节）] [自然运动：波浪/云层/野生动物]. [镜头运动]. [自然光线]. [色调/情绪].
```

## 主体一致性策略

### 跨镜头保持主体一致

AI 视频工具目前难以自动保持主体一致。以下策略按主体类型分别适用：

### 1. 固定主体描述锚点

为每个主体建立固定描述短语，在每个镜头 prompt 中严格复用。

**角色锚点示例：**

```
二十出头的青年男子，五官棱角分明，黑色长发束成高马尾，白色丝质仙袍金色滚边
```

**产品锚点示例：**

```
磨砂黑无线耳机，玫瑰金装饰环，椭圆紧凑充电盒，前缘 LED 指示灯带
```

**场景锚点示例：**

```
薄雾黎明中的高山湖泊，雪山倒映静水，岩石岸线稀疏松林
```

### 2. 特征锚点标记

- 选择 2-3 个最显著的视觉特征在每个 prompt 中重复
- 角色例：始终提及"白色仙袍金色滚边"+"高马尾"+"玉剑"
- 产品例：始终提及"磨砂黑外壳"+"玫瑰金装饰环"+"LED 灯带"
- 场景例：始终提及"高山湖泊"+"雪山倒影"+"松林"

### 3. 分镜连接语

- 可使用"同一角色"/"延续上一镜头"等连接提示
- 虽然工具可能不完全理解，但有助于保持描述一致性

### 主体描述模板

**角色模板：**

```
[称呼/性别/年龄], [面部特征], [发型发色], [服装主体], [服装细节/配饰], [标志性道具]
```

示例：

```
二十出头的青年男子，五官棱角分明，眼神锐利，黑色长发束成高马尾，身穿白色丝质仙袍，衣领和袖口金色刺绣，颈戴玉坠，手持发光玉剑
```

**产品模板：**

```
[产品名称/类别], [材质/表面处理], [核心外观特征], [尺寸/比例印象], [品牌标识元素]
```

示例：

```
无线耳机，磨砂黑聚合物外壳搭配玫瑰金装饰环，椭圆紧凑充电盒，前缘一条细长 LED 指示灯带，盒盖压印极简标志
```

**场景模板：**

```
[地理环境], [天气/时间/季节], [核心自然元素], [氛围关键词], [色彩基调]
```

示例：

```
海拔 3000 米的高山湖泊，薄雾黎明中第一缕阳光越过雪山山脊，静水倒映山峰剪影，岩石岸线上稀疏松林，宁静原始氛围
```

## AIGC 词汇可生成性指导

AI 视频工具对词汇的理解能力参差不齐。以下不是"一律替换"的保守表，而是帮你**判断一个词是否需要改写**的方法。

### 判断逻辑

核心问题：**这个词能否在 AI 脑中唤起一个明确的视觉画面？**

- 能唤起具体画面 → 保留
- 画面模糊或需要文化背景才能理解 → 考虑拆分
- 一个词塞了多层概念 → 必须拆分

### 🟢 可直接使用 — 保持原样

AI 对以下类型词汇有较好识别度，无需替换：

| 类型 | 示例 |
|------|------|
| 具象名词 | 玉剑、丝质仙袍、马尾 |
| 常见风格词 | 仙袍、赛璐璐、水墨 |
| 单一属性词 | 深红、金色、磨砂黑、发光、半透明 |
| 常见面部/体态描述 | 剑眉星目、刀疤横贯左颊、棱角分明 |
| 标准光影/特效术语 | 体积光、丁达尔光、粒子效果 |

### 🟡 建议拆分或补充 — 视情况改写

这类词不是"错"的，但 AI 可能只理解其中一部分，或产出不稳定：

| 类型 | 原始 | 改写建议 | 原因 |
|------|------|----------|------|
| 复合幻想词 | 血色符文 | 红色发光纹路 | "血色"+"符文"两层概念叠加，AI 可能只渲染其一 |
| 多重修饰堆叠 | 焰形阔刃重剑 | 火焰形宽刃大剑 | 拆解为可逐一渲染的属性 |
| 文言复合词 | 覆刻 | 表面刻有 | 直译更明确 |
| 纯情绪词用作锚点 | 面容冷峻（写在锚点中） | 移至具体镜头描述 | 锚点应聚焦可视特征，情绪/表情适合在镜头中按需使用 |

**注意**：短小、常见的情绪词（如"面容冷峻"）放在镜头 prompt 中是可以的，只是不建议作为永久锚点的核心特征。

### 🔴 必须替换 — 大概率无法正确渲染

| 类型 | 原始 | 改写方法 |
|------|------|----------|
| 长复合概念（4+ 层信息） | 灵气缠绕周身化为金甲 | 拆为两步："金色灵气环绕全身" + "灵气凝聚为金色铠甲" |
| 否定式描述 | 不要出现人物 / 没有云 | 改为肯定描述：只描述画面中**有**什么 |
| 精确空间朝向指令 | 面朝右方 / 背对镜头 | 改用视觉手段：侧身轮廓、剪影、前景-背景构图 |
| 抽象比喻 | 眼中倒映星河 | 拆为具象：眼中映出明亮星光 |

### 实操建议

1. **写完锚点后自检**：逐词扫描，问自己"AI 看到这个词会画出什么？"
2. **复合词拆分法**：把一个词拆成"形状 + 颜色 + 材质 + 动态"的独立属性
3. **不确定时做 A/B 测试**：用原词和改写词各生成一次，看哪个更稳定
4. **保留有识别度的文化词**：如"剑眉星目""仙袍"等，AI 有一定训练数据支撑，不必强改
