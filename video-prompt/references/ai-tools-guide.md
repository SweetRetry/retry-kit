# AI 视频工具 Prompt 适配指南

## AI 空间能力边界

**可靠**：屏幕方位（画面左/右/中央）、景深层次（前景/中景/背景）、尺寸暗示、侧身轮廓/剪影

**不可靠**：主体间朝向（面对面/背靠背）、相对距离、背对镜头、复杂空间指令

核心原则：用构图位置传达叙事关系，不依赖朝向指令。

## 主体锚点模板

**角色**：`[性别/年龄], [面部特征], [发型发色], [服装主体+细节], [标志性道具]`

```
二十出头青年男子，五官棱角分明，黑色长发束高马尾，白色丝质仙袍金色滚边，手持发光玉剑
```

**产品**：`[类别], [材质/表面处理], [核心外观], [品牌标识]`

```
磨砂黑无线耳机，玫瑰金装饰环，椭圆充电盒，前缘 LED 指示灯带
```

**场景**：`[地理环境], [天气/时间], [核心自然元素], [氛围]`

```
高山湖泊，薄雾黎明，雪山倒映静水，岩石岸线稀疏松林
```

**规则**：2-3 个最显著特征每个镜头必须出现。锚点只放可视特征，情绪/表情在具体镜头中用。

## 词汇可生成性判断

核心问题：**这个词能否唤起一个明确的视觉画面？**

| 信号 | 处理 | 示例 |
|------|------|------|
| 🟢 具象单一概念 | 保留 | 玉剑、磨砂黑、体积光、剑眉星目 |
| 🟡 复合概念（2层） | 拆分属性 | 血色符文 → 红色发光纹路 |
| 🔴 4+层/否定/抽象比喻 | 必须改写 | 灵气缠绕周身化为金甲 → 拆两步 |

**改写方法**：拆成「形状+颜色+材质+动态」的独立属性。否定式改肯定式。朝向指令改构图位置。
