# Composition

## 内容关系先于组件

- 确定当前视区的主导焦点、阅读路径和主操作。辅助信息通过位置、字号与对比度退让；对等紧急分支可并列，不把每个区块都做成主角。
- 根据关系选择表达：顺序用排列，比较用对齐与共享刻度，层级用位置与占比，关联用分组或连接。
- 重复或等宽结构只承载语义、结构与操作同级的对象。不同权重用排序、非对称分配或密度体现，不默认套等大卡片矩阵。
- 数值编码保持共同基准与真实比例，数值就地标注；不用装饰图表或视觉面积暗示不存在的差异。

## 空间与密度

- 相关元素先形成组，再安排组间距；组间明显大于组内，标题更接近其内容。沿用项目间距档位，兄弟间距由父容器控制，不靠逐项补 margin 修缝。
- 表单与阅读区按字段、行长限制宽度；表格、画布与编辑器优先保留比较和操作空间。全宽导航不要求所有内容同宽。
- 先用对齐、排版、间距与负空间建立分组；仅在表达独立语义、状态或可供性时增加表面、边框、图标与装饰。
- 内容不足如实保留空缺；密集内容先重组与取舍，不靠缩小正文或控件硬塞。专业工具保留必要扫描密度，不统一稀疏化。
- 窄屏重排主辅关系、分组和操作；需要横向核对的数据可保留横向滚动。避免截断决定所需内容或用缩字号维持桌面构图。

## 判断完成

- **眯眼检查**：细节模糊后仍能辨认焦点、分组和阅读路径。
- **同级检查**：重复结构确实承载同级对象；结构差异体现内容权重。
- **移除检查**：去掉装饰不损失含义或操作识别时，保持移除。
- **移植检查**：若布局可仅换文案套到无关任务，核对它是否遗漏当前内容的关系；通用外壳和稳定复用模式可保留。
- 在完整页面与窄屏检查，而非只看孤立组件。
