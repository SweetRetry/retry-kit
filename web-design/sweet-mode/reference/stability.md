# 尺寸稳定

状态变化保留空间定位，防止布局位移与视觉抖动。

## 1. 异步加载防跳动

- **首次加载**：
  - 结构固定（卡片、表格、媒体）：声明固定比例（`aspect-*`）或 1:1 骨架屏，禁止加载前高度为 0。
  - 动态长流（文章、评论）：仅保留基础行高（`min-h-[1lh]`），不预设过大空白（防返回空数据时二次坍塌）。
- **二次交互（翻页、筛选、刷新）**：保持旧数据渲染（`opacity-60`），加载反馈转嫁给触发控件（按钮内 Spinner、Tab、边缘细进度条），不卸载已有内容。搜索词清空或重置视图时直接清空。
- **控件尺寸锁定**：按钮进入加载或禁用状态时锁定宽高，不因文案替换为 Spinner 导致物理尺寸缩水。

## 2. 卡片与网格等高对齐

网格内的卡片（Grid / Flex Cards）禁止因内容长短不一导致高低参差：

- **卡片撑满**：卡片根节点声明 `h-full flex flex-col`，统一拉伸至行高。
- **动态文案控高**：标题限制行数（`line-clamp-2`）或设最小高度；正文区设 `flex-1` 吸收高度差。
- **操作沉底对齐**：卡片底部的操作栏或 Footer 添加 `mt-auto`，确保同排卡片的按钮底边对齐。
- **媒体固定比例**：图片与视频显式声明比例（如 `aspect-video w-full object-cover`），禁止依赖自然尺寸。

## 3. 空值与提示防推挤

- **空数据结构化兜底**：列表 `[]` 渲染固定体量的 Empty State；缺失文本保留最小行高（`min-h-[1lh]` / `min-h-5`）或占位符（`"—"`）。占位表达真实状态，区分未加载、空、缺失与失败，不用默认值掩盖缺口。
- **表单报错预留高度**：字段提示区预留最小高度（`min-h-5`）或受控平滑展开，防止报错文字突现推挤主按钮造成误触。
- **弹性容器防穿孔**：包含动态文本或代码的 Flex/Grid 子项必须添加 `min-w-0`，超长文本声明 `truncate` 或 `line-clamp-*`。

## 4. 关闭动画期间内容不变

Dialog、Sheet、Popover 关闭时仍有退出动画。关闭回调里只关闭，不重置视图层级（文件夹、步骤）、选择与草稿，否则内容在动画中途变化，容器高度跳变。重置放到重新打开时。

## 验收清单

- [ ] **加载平稳**：首屏具备比例或骨架屏；翻页/筛选保留旧内容并转嫁 Loading，主区无闪烁。
- [ ] **卡片整齐**：网格卡片 `h-full flex flex-col`，操作区 `mt-auto` 水平齐平。
- [ ] **媒体受控**：异步图片声明了宽高比与 `object-cover`。
- [ ] **控件锁定**：按钮 Loading 物理尺寸恒定。
- [ ] **空值与报错**：空数据不塌陷，表单错误未推挤提交按钮。
- [ ] **关闭稳定**：关闭回调只关闭，状态在重新打开时重置。
- [ ] **边界安全**：Flex/Grid 子项具备 `min-w-0`，长文本正常截断。
