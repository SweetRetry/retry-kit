# Prompt 工程优化：缓存设计与注意力机制

## 缓存设计（Prompt Caching）

### 核心原理

LLM API 普遍支持将请求稳定前缀缓存到服务端。前缀一致即命中，减少重复 prefill。

**收益**
- 命中缓存降低重复前缀的输入 token 成本（折扣以平台文档为准）
- 降低 TTFT
- 适用：System Prompt 固定、大量 RAG 文档、长对话 history 重复部分

### 黄金法则

**放入可缓存前缀（稳定、体积大）**
- Persona 定义
- 固定领域知识 / RAG 文档
- Few-Shot 示例
- 全局 constraints 和 rules
- 工具定义（function calling schema）

**不放入前缀（动态变化）**
- 当前时间戳、请求 ID
- 用户个性化数据
- 当轮对话 history
- 动态业务数据

### 结构设计原则

**原则一：稳定内容前置**
```
[固定 — 可缓存] persona / 固定 context / examples
        ↓ 缓存边界
[动态 — 不缓存] 当轮用户查询背景 / user message
```

**原则二：最小化前缀变化**
- 缓存按前缀完全匹配，改 1 字符即 miss
- 使用参数化插槽，避免内联拼接动态值
- 固定内容中不插时间戳、请求 ID

**原则三：缓存边界选择**
- 各平台字段名不同，思路一致：在「最大稳定块末尾」标记边界
- 优先在体积最大的稳定内容末尾设置

### 自检
- 稳定内容是否集中顶部？
- 动态内容是否隔离到底部或 user message？
- 固定内容是否混入动态值？
- 缓存边界是否在最大稳定块末尾？
- history 是否只缓存已确认不变的部分？

## 注意力机制设计（Attention Management）

### 核心原理

Transformer 注意力对 token 位置的关注度不均匀：
- **近端偏置**：靠近输出端权重更高
- **Lost in the Middle**：长上下文中间内容易被稀释
- **重复强化**：多位置重复的指令注意力累加

### 关键原则

**原则一：重要指令首尾锚定（三明治结构）**
```
[开头] 核心任务 + 最重要约束      ← 高注意力
[中间] 背景 / 文档 / 详细规则     ← 辅助信息
[结尾] 任务摘要重述 + 输出格式    ← 高注意力（紧邻输出）
```

**原则二：长文档分块 + 路标注释**

在文档前后加 `<!-- 文档开始 -->` / `<!-- 文档结束 -->` 类路标：
- 帮助模型识别文档边界，避免与指令混淆
- 文档末尾再次激活注意力，防止淹没后续指令

**原则三：关键约束多位置重复**

对必须严格遵守的约束（安全红线、输出格式），在 constraints / task / format 三处重复声明。

**原则四：分隔符强化语义边界**

对「指令 vs 数据」的场景使用强分隔符（`--- 用户输入开始/结束 ---` 或 XML 标签）。同时是防 prompt injection 的基本手段。

**原则五：Token 预算管理**

过长 prompt 会稀释核心指令注意力、超 context 被截断、增加延迟成本。

| 内容 | 建议占比 |
|------|----------|
| System Prompt（四要素） | 10-20% |
| RAG / 检索文档 | 40-60% |
| 对话 History | 20-30% |
| 当轮用户输入 | 5-10% |

当 System Prompt > 2000 token：审查冗余描述；Few-Shot 从 3-5 减到 2-3；领域文档移到 RAG 动态检索。

### 自检
- 最重要任务指令是否位于首/尾（非中间）？
- Format 是否紧邻末尾？
- 大量文档是否有开始/结束路标？
- 必须严格遵守的约束是否重复 ≥ 2 次？
- 用户输入是否有分隔符防 injection？
- 总 token 是否合理？

## 缓存 × 注意力协同

```
[固定前缀 — 可缓存]
  persona / 固定文档（带路标）/ examples / constraints（重复一）
        ↓ 缓存边界
[动态后缀 — 不缓存]
  task（含核心约束重复二）/ format（紧邻末尾）
[User Message]
  --- 用户输入开始 ---
  {{user_input}}
  --- 用户输入结束 ---
```

同时实现：固定内容缓存命中、关键约束首尾重复、动态输入有边界防 injection。
